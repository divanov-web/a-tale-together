# A Tale Together («Общая история»)

Асинхронная многопользовательская текстовая RPG с ИИ-мастером в Telegram. Go + PostgreSQL + Telegram Bot API + LLM API.

- [Руководство игрока](guide/README.md): команды и как играть, со стороны пользователя.
- [Документация](docs/README.md): концепт, roadmap, архитектура, ADR, правила игры, LLM, среда.
- [Среда разработки](docs/dev/environment.md): WSL, Go, Postgres, `make`.
- Система промптов Claude Code: `CLAUDE.md` и `.claude/`.
