# Инвентарь

Предметы персонажа. Сейчас инвентарь задаётся архетипом при создании и по ходу игры не меняется: предметы не находятся, не теряются и не передаются (не реализовано).

## Стартовые предметы

| Архетип | Предметы |
|---|---|
| Воин | Меч, Щит |
| Плут | Кинжал, Отмычки |
| Маг | Посох, Фолиант |
| Дипломат | Печать гильдии, Кошель |
| Следопыт | Лук, Верёвка |

## Что делают предметы

Часть предметов добавляет кубики к одному навыку. Бонус работает, только когда бросается именно этот навык.

| Предмет | Бонус |
|---|---|
| Меч | +1 кубик к бою |
| Отмычки | +1 кубик к воровству |
| Фолиант | +1 кубик к внимательности |
| Печать гильдии | +1 кубик к убеждению |
| Верёвка | +1 кубик к выживанию |
| Щит, Кинжал, Посох, Кошель, Лук | бонуса нет; рассказчик может упомянуть их в сцене, на бросок не влияют |

| Правило | Значение |
|---|---|
| Суммарный бонус предметов | не больше +2 кубиков на одну проверку |
| Предмет без навыка | если проверка идёт по одной характеристике («выбить (Сила)»), предметы не помогают |
| Вместимость | до 6 предметов (пока не проверяется: предметы не появляются) |

Пример. Плут с отмычками отпирает дверь: Ловкость 4 + воровство 3 + отмычки 1 = 8 кубиков. Тот же плут выбивает дверь: только Сила 2, кинжал и отмычки не при чём.

## Не реализовано

- Находки при осмотре и обмен между персонажами.
- Оружие в столкновениях (+1 к урону при успехе), броня.
- Сброс инвентаря между сезонами сериала.
