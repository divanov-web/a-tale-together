# Инвентарь

Предметы персонажа. Сейчас инвентарь задаётся архетипом при создании и по ходу игры не меняется: предметы не находятся, не теряются и не передаются (не реализовано).

## Стартовые предметы

| Архетип | Предметы |
|---|---|
| Воин | Меч, Щит |
| Плут | Кинжал, Отмычки |
| Маг | Посох, Фолиант |
| Дипломат | Печать гильдии, Кошель |
| Следопыт | Лук, Верёвка |

## Что делают предметы

Стартовые предметы к шансу ничего не прибавляют. Они объясняют, почему вам доступен подход (отмычки у плута, меч у воина), и рассказчик упоминает их в сцене. 80 % взлома у плута уже учитывают обычные отмычки. Бонусные предметы, которые добавляют +1 или +2 к параметру одного навыка, появятся позже (не реализовано).

| Правило | Значение |
|---|---|
| Суммарный бонус предметов | не больше +2 к параметру одной проверки, то есть +20 % (когда появятся бонусные предметы) |
| Предмет без навыка | бонус привязан к навыку: в проверке по одной характеристике предметы не помогают |
| Вместимость | до 6 предметов (пока не проверяется: предметы не появляются) |

Пример. Плут отпирает дверь: Ловкость 5 + воровство 3 = 8, шанс 80 %; отмычки сверх этого ничего не добавляют. Тот же плут выбивает дверь: Сила 2 + атлетика 0 = 2, шанс 20 %, кинжал и отмычки ни при чём.

## Не реализовано

- Бонусные предметы к параметру.
- Находки при осмотре и обмен между персонажами.
- Оружие в столкновениях (+1 к урону при успехе), броня.
- Сброс инвентаря между сезонами сериала.
