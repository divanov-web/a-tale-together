# Навыки

Навык — выученное умение поверх природной характеристики. В броске он прибавляется к характеристике: Ловкость 3 и воровство 2 дают пять кубиков на взлом замка. Без навыка бросается одна характеристика.

| Навык | Характеристика | Когда пригодится |
|---|---|---|
| Воровство | Ловкость | отпереть замок, срезать кошель, обезвредить ловушку |
| Внимательность | Разум | осмотреть предмет, заметить скрытое, прочитать надпись |
| Выживание | Разум | найти дорогу, развести огонь, понять следы |
| Скрытность | Ловкость | прокрасться, спрятаться, подслушать незамеченным |
| Бой | Сила | ударить в ближнем бою (столкновения не реализованы, навык пока не бросается) |
| Убеждение | Воля | уговорить, запугать, сторговаться (разговоры с жителями мира не реализованы) |

## Числа

| Правило | Значение |
|---|---|
| Диапазон | от 0 до 3 |
| Очков на старте | 6, не больше 3 в один навык |
| Навык 0 | бросается только характеристика |
| Навык 3 | мастер: плюс три кубика к характеристике |

## Распределение по архетипам

| Архетип | Навыки |
|---|---|
| Воин | бой 3, выживание 2, внимательность 1 |
| Плут | воровство 3, скрытность 2, внимательность 1 |
| Маг | внимательность 3, убеждение 2, выживание 1 |
| Дипломат | убеждение 3, внимательность 2, воровство 1 |
| Следопыт | выживание 3, скрытность 2, бой 1 |

При ручном распределении пары вводятся одной строкой, навыки по-русски: `воровство 3 скрытность 2 внимательность 1`.

## Как навык попадает в бросок

1. У предложенного варианта навык написан через косую черту: «отпереть (Ловкость/воровство, сложность 2)». Бросаются Ловкость + воровство.
2. Для своего действия бот подбирает характеристику и, если подходит, навык. «Прислушиваюсь у двери» — Разум + внимательность; «пробую плечом» — только Сила.
3. Если есть предмет с бонусом к этому навыку, он добавляет кубики: [инвентарь](inventory.md).

Пример. Леголас (Ловкость 3, воровство 0) отпирает дверь: три кубика. Плут (Ловкость 4, воровство 3, отмычки +1): восемь кубиков. Разница в шансах огромная, поэтому в сцене с запертой дверью стоит уступить замок плуту, а самому помочь ему или заняться другим.

## Не реализовано

- Навыки как «черты» без чисел в режиме «повествование».
- Рост навыков за опыт.
