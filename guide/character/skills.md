# Навыки

Навык — выученное умение поверх природной характеристики. В параметре он прибавляется к характеристике: Ловкость 3 и воровство 2 дают параметр 5 на взлом замка. Без навыка параметр равен одной характеристике.

| Навык | Характеристика | Когда пригодится |
|---|---|---|
| Атлетика | Сила | выбить дверь, сдвинуть плиту, удержать верёвку, залезть |
| Воровство | Ловкость | отпереть замок, срезать кошель, обезвредить ловушку |
| Внимательность | Разум | осмотреть предмет, заметить скрытое, прочитать надпись |
| Выживание | Разум | найти дорогу, развести огонь, понять следы |
| Скрытность | Ловкость | прокрасться, спрятаться, подслушать незамеченным |
| Бой | Сила | ударить в ближнем бою (столкновения не реализованы, навык пока не используется) |
| Убеждение | Воля | уговорить, запугать, сторговаться (разговоры с жителями мира не реализованы) |

## Числа

| Правило | Значение |
|---|---|
| Диапазон | от 0 до 3 |
| Очков на старте | 6, не больше 3 в один навык |
| Навык 0 | параметр равен характеристике |
| Навык 3 | мастер: плюс три очка к характеристике, то есть +30 % к шансу |

## Распределение по архетипам

| Архетип | Навыки |
|---|---|
| Воин | атлетика 3, бой 3 |
| Плут | воровство 3, скрытность 3 |
| Маг | внимательность 3, убеждение 2, выживание 1 |
| Бард | убеждение 3, внимательность 2, выживание 1 |
| Следопыт | выживание 3, скрытность 2, бой 1 |

Навыки персонаж получает по архетипу при создании; ручной выбор пока выключен и появится позже.

## Как навык попадает в бросок

1. У предложенного варианта навык написан через косую черту: «отпереть (Ловкость/воровство, сложность 5)». Параметр — Ловкость + воровство.
2. Для своего действия бот подбирает характеристику и, если подходит, навык. «Прислушиваюсь у двери» — Разум + внимательность; «пробую плечом» — Сила + атлетика.
3. Предмет с бонусом к этому навыку добавил бы очки, но у стартовых предметов бонуса нет: [инвентарь](inventory.md).

Пример. Воин (Ловкость 3, воровство 0) отпирает дверь сложности 5: параметр 3, шанс 30 %. Плут (Ловкость 5, воровство 3): параметр 8, шанс 80 %. Поэтому в сцене с запертой дверью стоит уступить замок плуту, а самому выбивать дверь (Сила 5 + атлетика 3 = 8, те же 80 %) или помочь плуту.

## Не реализовано

- Навыки как «черты» без чисел в режиме «повествование».
- Рост навыков за опыт.
