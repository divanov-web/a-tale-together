# Описание персонажа

Персонаж — это вы в истории. У каждого игрока один персонаж на игру. Создаётся в личке с ботом командой `/create` после входа в игру по ссылке.

## Как проходит создание

Бот задаёт вопросы по одному; ответ — обычным сообщением. Прервать: `/cancel`.

| Шаг | Вопрос | Что ответить |
|---|---|---|
| 1 | Фракция | номер одной из двух сторон конфликта игры |
| 2 | Никнейм | имя персонажа, 2–30 символов, в игре уникально |
| 3 | Архетип | воин, плут, маг, дипломат или следопыт |
| 4 | Распределение очков | `1` — автоматически по архетипу, `2` — вручную |
| 5 | Характеристики (только вручную) | четыре числа по порядку, например `4 3 2 3` |
| 6 | Навыки (только вручную) | пары «навык значение», например `бой 3 выживание 2 внимательность 1` |
| 7 | Открытое описание | до 100 символов, можно пропустить |
| 8 | Скрытое описание | до 100 символов, можно пропустить |

После последнего шага бот присылает карточку персонажа.

## Из чего состоит персонаж

| Часть | Что это | Где меняется |
|---|---|---|
| Никнейм | имя в хронике; под ним вас видят другие игроки, рядом бот ставит `(@ваш_username)` | только при создании |
| Архетип | заготовка: рекомендуемые характеристики, навыки и стартовые предметы; после создания сам по себе ни на что не влияет | только при создании |
| Фракция | сторона конфликта; видна всем; рассказчик учитывает отношения фракций в подаче сцен. Смена фракции по сюжету (не реализовано) | только при создании |
| Открытое описание | кто ваш персонаж внешне и по характеру; видно всем; рассказчик опирается на него, когда вводит вас в историю | `/bio <текст>` |
| Скрытое описание | ваша тайна или мотив; видит только рассказчик и подаёт вашу линию с оглядкой на него, но в хронике не раскрывает. Фактов мира описание не создаёт: «у меня ключ от всех дверей» ключа не даст | `/secret <текст>` |
| Характеристики и навыки | числа, из которых складываются шансы в испытаниях: [характеристики](attributes.md), [навыки](skills.md) | только при создании |
| Инвентарь | предметы: [инвентарь](inventory.md) | пока не меняется |
| HP и состояния | здоровье и временные помехи: [статусы и состояния](statuses.md) | по ходу игры |
| Статус | присутствуете ли вы в истории: [статусы и состояния](statuses.md) | по ходу игры |
| Локация | где персонаж сейчас; действовать можно только с тем, что есть в этой локации | заявкой `/act иду …` |
| Знания | факты, которые персонаж узнал: осмотрел статую — получил факт о надписи на щите. Знания личные: другие игроки их не видят, пока вы не расскажете сами в чате | по ходу игры |
| Группа | объединение персонажей с общей сюжетной линией (не реализовано: пока все персонажи одной локации действуют вместе) | — |

## Карточка `/character`

```
Леголас — Воин, фракция «Орден Рассвета», статус active
Игра «Похождения добряков»; локация: Подвал башни
HP 8; состояния: exhausted
Характеристики: Сила 4, Ловкость 3, Разум 2, Воля 3
Навыки: Бой 3, Выживание 2, Внимательность 1
Инвентарь: Меч, Щит
Открытое описание: нет (/bio <текст>)
Скрытое описание: нет (/secret <текст>)
Знания:
• На щите статуи выцарапана стрелка вниз
```

| Строка | Как читать |
|---|---|
| статус `active` | вы в истории; другие значения в [статусах](statuses.md) |
| локация | откуда вы действуете в ближайшем раунде |
| HP 8 | здоровье; максимум равен 4 + Сила |
| состояния `exhausted` | помехи к броскам: `exhausted` истощён, `wounded` ранен ([статусы](statuses.md)) |
| Знания | последние пять фактов; старые остаются у персонажа, но в карточке не показываются |

## Что персонаж даёт в игре

- Рассказчик пишет про вас по никнейму, описаниям, архетипу и тому, что вы сделали в раунде. Чем конкретнее открытое описание, тем узнаваемее персонаж в хронике.
- Любое действие с риском решается [испытанием](../checks/checks.md): берётся характеристика, иногда навык и предмет, бросаются кубики. Карточка — это и есть ваши шансы.
- Опыт и рост характеристик (не реализовано): опыт за раунды не начисляется, числа карточки остаются стартовыми.
