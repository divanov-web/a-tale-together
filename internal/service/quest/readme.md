# service/quest
- Назначение: чистые правила квестов и целей фракций (пункт 28, [world.md](../../../docs/game/world.md) «Квесты», [ADR-0020](../../../docs/decisions/0020-quests.md), S17): `Plan(Input) Tasks` — новый квест фракции (нет активного сюжетного → сразу; иначе порог `model.IssueThreshold` от числа активных и счётчик `ExploredSinceReset`, тип по свободным слотам с чередованием сюжетный → побочный → сюжетный, одно задание на фракцию), привязка первого незакрытого этапа без клетки к клетке персонажа фракции на расстоянии ≥ `Distance` от клетки предыдущего этапа (первый — от стартовой; одна клетка на этап, первая по снимку; клетка логова сил зла пропускается, ADR-0031), пересмотр цели (фракция без цели или сюжетный квест закрыт после текущей версии); `Check(state, quests) []Done` — условия привязанных этапов по снимку после свёртки: `object_state` (объект клетки этапа в состоянии; клетка в снимке), `fact` (факт у персонажа фракции), `visited`; закрывается первый незакрытый этап, последний — `QuestDone`; шаблоны `TemplateQuest` (из `genres.template.story_quest`, иначе запасной трёхэтапный), `TemplateGoal`, `TemplateStage` (объект «след» с подходом без броска, условие — его факт); `Distance` по сетке.
- Без I/O: строки, события (`quest_issued`, `quest_stage_placed`, `quest_stage_done`, `quest_done`, `goal_revised`) и счётчики пишет `app/round` (`quests.go`); квесты в снимок раунда не входят.
- Связи: `model` (`quest.go`), потребители `app/round`, `service/narrator` (шаблоны и валидация размещения).
- Тесты: `quest_test.go` — выдача по порогам и лимитам, привязка по расстоянию, условия и завершение, шаблоны.
