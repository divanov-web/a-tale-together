# service/party
- Назначение: чистые правила групп персонажей (пункт 19, [группы](../../../docs/game/parties.md)): `Leader(members, admin)` — лидер по правилу «персонаж администратора игры, иначе первый созданный, выбывшие последними»; `SplitLeader(members)` — лидер отделившихся по наибольшей Воле (`model.LeaderAttribute`); `NextName(templates, taken)` — имя новой группы из шаблона жанра, иначе «Группа N»; `ValidateName`; `Nearest(locations, from, candidates)` — ближайшая клетка по расстоянию на сетке (|dx| + |dy|, пункт 27); `Assign(active, locations, at, max)` — правило входа персонажа без группы (группа локации → новая в пределах лимита → ближайшая с переходом в её локацию; ADR-0017); `Stale(parties, chars)` — группы без присутствующих к роспуску; `Active`, `Find`.
- Зависимости: только `model`. Потребители: `service/engine` (лидер отделившихся, имя новой группы), `app/game` (вход нового персонажа), `app/round` (группа по умолчанию при `/begin`, присутствующие без группы при заморозке, смена лидера и роспуск после раунда).
- Правило: лидер на этом этапе скрыт от игроков (решение руководителя 2026-10-11); функции не знают о БД и Telegram.
