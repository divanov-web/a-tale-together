# service/party
- Назначение: чистые правила групп персонажей (пункт 19, [группы](../../../docs/game/parties.md)): `Leader(members, admin)` — лидер по правилу «персонаж администратора игры, иначе первый созданный, выбывшие последними»; `SplitLeader(members)` — лидер отделившихся по наибольшей Воле (`model.LeaderAttribute`); `NextName(templates, taken)` — имя новой группы из шаблона жанра, иначе «Группа N»; `ValidateName`; `Nearest(locations, from, candidates)` — ближайшая локация по выходам (поиск в ширину); `Active`, `Find` (по имени или `#id`).
- Зависимости: только `model`. Потребители: `service/engine` (лидер отделившихся, имя новой группы), `app/game` (вход нового персонажа, `/party`), `app/round` (группа по умолчанию при `/begin`, смена лидера после раунда).
- Правило: лидер на этом этапе скрыт от игроков (решение руководителя 2026-10-11); функции не знают о БД и Telegram.
