# service/narrator
- Назначение: вызов 2 из 2 на раунд ([round-calls.md](../../../docs/llm/round-calls.md), [narrator.md](../../../docs/llm/narrator.md), [ADR-0011](../../../docs/decisions/0011-narrator-call.md)): контекст из состояния после свёртки и событий `public`/`location` (`context.go`: сцены по группам внутри локаций — `scene_id`, `party` (пусто у персонажей без группы), координаты, стадия и местность клетки, выходы по направлениям с карточками неописанных соседей, лидер не передаётся (пункт 19, [ADR-0016](../../../docs/decisions/0016-parties.md)); присутствующие, описания как данные, события словами, выжимка последних хроник; числа броска только в «механике»; блок `generate` с заданиями на достройку мира при их наличии), системный промпт `assets/prompts/narrator/v4.md`, схема ответа (`schema.go`: `{chronicle, scenes[{scene_id, text, event_seqs}], world{cells, neighbors}}`; код подставляет локацию и подпись «Группа (Локация)» в `NarrationScene.Party`), проверка (`validate.go`: сцены по `scene_id` и `seq` из входа, пара перехода — одно упоминание, секреты не в тексте, без цифр в «повествовании», объём) → один дозапрос с замечаниями → дописывание пропусков кодом (`Narration.Patched`); утечка → `ErrLeak`, бюджет → `ErrBudget`.
- Пакет мира (`world.go`, пункт 27, [ADR-0019](../../../docs/decisions/0019-world-generation.md)): `PlanTasks(state, exists)` — занятые карточки → `CellTask` (до `model.MaxCellsPerRound`, остальные `Overflow`), недостающие соседи занятых клеток → `NeighborTask`; `validateWorld` принимает клетки и соседей только из заданий, нормализует ключи объектов в snake_case, режет по лимитам, подходы проверяет по модели персонажа (`validateApproach`: действие, характеристика, навык, сложность 1–9, `reveal` на скрытый объект клетки, состояние из списка), пропущенное закрывает шаблоном (`TemplateWorld`, `templateCell` «Дорога», `templateNeighbor` «Неизведанные земли»); замечания к пакету в `Result.Issues`, дозапроса по ним нет; `WorldPackage.Templated` для метрик.
- Варианты следующего раунда: `Options(state, def, mode)` (подходы объектов: сложность по пресету режима плюс локация, шанс каждого присутствующего по параметру — для личных подсказок; затем переходы по направлениям к соседям — `Option.Move`, `Object = MoveObject`, `Idx` — номер направления) и `OptionsText` — блок «Варианты» в группу: пункт на подход с новой строки, характеристика и сложность, без шансов (B6), в «повествовании» сложность словами (`rules.DifficultyWords`), переходы «идти на север: Лес»; слова событий `Describe` (у `party_split` и `party_held` актёр — группа, направление и желавшие иначе названы, лидер нет; `cell_discovered`, `cell_generated`, `object_created` словами для журнала и уведомлений), `StateWords`, `ConditionWords`, `OutcomeWords`, `StatusWords` — общие с шаблонами `app/round`. Исчерпанные подходы (`engine.ApproachDone`, B8) не предлагаются.
- Завязка и стартовый пакет (`opening.go`, [ADR-0018](../../../docs/decisions/0018-opening-scene.md), ADR-0019): `Service.Opening(ctx, OpeningParams) (OpeningResult, error)` — один вызов при `/begin` с ролью `opening`, промпт `assets/prompts/narrator/opening-v2.md` (`OpeningSystemPrompt`, `OpeningPromptVersion`), схема `OpeningSchema` `{text, start, neighbors}`; вход `BuildOpeningInput`: мир, фракции, стартовая клетка шаблона с названиями объектов (`OpeningStart`), задания на соседей (`NeighborTask`), ключи модели персонажа, персонажи без скрытых описаний; замечания к тексту кодом (объём 80–3000 символов, цифры вне «механики», никнеймы) → один дозапрос, объём вне границ после него → `ErrOpening`; пакет (`validateOpeningWorld`): клетка `Start` (nil без валидных объектов — остаются объекты шаблона), `Neighbors` по направлениям заданий (пропущенные — шаблон). `Params.Opening` идёт первой строкой выжимки `world.previous` (до 1200 символов).
- Публичный вход: `New(LLM, logger)`, `Service.Narrate(ctx, Params) (Result, error)` (`Result.World`), `Service.Opening`, `BuildInput`, `BuildOpeningInput`, `PlanTasks`, `TemplateWorld`, `Options`, `OptionsText`, `MoveObject`, `Describe`, `Schema`, `OpeningSchema`, `PromptVersion`, `OpeningPromptVersion`, `SystemPrompt`, `OpeningSystemPrompt`; типы `Tasks`, `CellTask`, `NeighborTask`, `WorldPackage`, `GeneratedCell`, `GeneratedNeighbor`; интерфейс `LLM` (`Complete(ctx, model.LLMRequest)`), у вызывающего — обёртка над `app/llm.Complete` с ролью `narrator` и сохранением ответа по ключу задания.
- Контекст сцены несёт отметку входа персонажа `entry` (`new`/`returned`, из снимка, B1); промпт `narrator/v4` (`assets/prompts/narrator/v4.md`: `v3` + сетка, выходы по направлениям, раздел «Достройка мира» с правилами пакета `world`) требует ввести нового и вернуть отсутствовавшего, описав его действие, и описывать прибытие в новую клетку в согласии с её пакетом.
- Правило: модель описывает, факты и исходы не меняет; текст игрока и описания персонажей — данные; при любой ошибке вызывающий публикует шаблонную хронику.
- Тесты: `narrator_test.go`, `opening_test.go`, `world_test.go` (задания, пакет мира, шаблон) на фейковом LLM; живой прогон `make eval-narrator` (`cmd/eval-narrator`, `assets/prompts/narrator/eval/cases.json`, случай `world_generation` с ожиданиями к пакету), завязка и стартовый пакет — `EVAL_ARGS="-opening"`.
