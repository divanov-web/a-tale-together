# service/narrator
- Назначение: вызов 2 из 2 на раунд ([round-calls.md](../../../docs/llm/round-calls.md), [narrator.md](../../../docs/llm/narrator.md), [ADR-0011](../../../docs/decisions/0011-narrator-call.md)): контекст из состояния после свёртки и событий `public`/`location` (`context.go`: сцены по группам внутри локаций — `scene_id`, координаты, стадия и местность клетки, выходы по направлениям с карточками неописанных соседей, лидер и имя группы не передаются (пункт 19, [ADR-0016](../../../docs/decisions/0016-parties.md)); присутствующие, описания как данные, события словами, выжимка последних хроник; числа броска только в «механике»; блок `quests` с активными квестами для подсказок и блок `generate` с заданиями на достройку мира и по квестам при их наличии), системный промпт `assets/prompts/narrator/v6.md`, схема ответа (`schema.go`: `{chronicle, scenes[{scene_id, text, event_seqs}], world{cells, neighbors, quests, stages, goals}}`; код подставляет локацию и внутреннюю подпись «Группа (Локация)» в `NarrationScene.Party`; поле `scene.Party` не сериализуется), проверка (`validate.go`: сцены по `scene_id` и `seq` из входа, пара перехода — одно упоминание, секреты не в тексте, без цифр в «повествовании», объём) → один дозапрос с замечаниями → дописывание пропусков кодом (`Narration.Patched`); утечка → `ErrLeak`, бюджет → `ErrBudget`.
- Пакет мира (`world.go`, пункт 27, [ADR-0019](../../../docs/decisions/0019-world-generation.md)): `PlanTasks(state, exists)` — занятые карточки → `CellTask` (до `model.MaxCellsPerRound`, остальные `Overflow`), недостающие соседи занятых клеток → `NeighborTask`; `validateWorld` принимает клетки и соседей только из заданий, нормализует ключи объектов в snake_case, режет по лимитам, подходы проверяет по модели персонажа (`validateApproach`: действие, характеристика, навык, сложность 1–9, `reveal` на скрытый объект клетки, состояние из списка), пропущенное закрывает шаблоном (`TemplateWorld`, `templateCell` «Дорога», `templateNeighbor` «Неизведанные земли»); замечания к пакету в `Result.Issues`, дозапроса по ним нет; `WorldPackage.Templated` для метрик.
- Квесты (`quests.go`, пункт 28, [ADR-0020](../../../docs/decisions/0020-quests.md)): задания `Tasks.Quests` (`QuestTask`: фракция, тип, цель, границы этапов, порог, обязательность), `Tasks.Stages` (`StageTask`: квест, этап, вид условия, клетка и её объекты), `Tasks.Goals` (`GoalTask`: текущая цель, закрытый квест, запасной текст), `Tasks.StoryTemplate`; контекст `Params.Quests` (`QuestInfo` с ближайшим этапом `QuestStageInfo`, `ConditionWordsFor`); `validateQuests` (фракция из задания, этапы по `model.StageBounds`, ключи snake_case, расстояние 1–3, каталог условий; без этапов — шаблон для обязательного), `validateStages` (объекты по `validateObjects` без повтора ключей клетки, условие только достижимое подходом — `validateCondition`, `reachableState`, `reachableFact`, `firstReachable`; пропущено — `quest.TemplateStage`), `validateGoals`; `TemplateQuests` при сбое; результат в `WorldPackage.Quests` / `Stages` / `Goals` (`GeneratedQuest`, `GeneratedStage`, `GeneratedGoal`).
- Варианты следующего раунда: `Options(state, def, mode)` (подходы объектов: сложность по пресету режима плюс локация, шанс каждого присутствующего по параметру — для личных подсказок; затем переходы по направлениям к соседям — `Option.Move`, `Object = MoveObject`, `Idx` — номер направления) и `OptionsText` — блок «Варианты» в группу: пункт на подход с новой строки, характеристика и сложность, без шансов (B6), в «повествовании» сложность словами (`rules.DifficultyWords`), переходы «идти на север: Лес»; слова событий `Describe` (у `party_split` и `party_held` актёр — группа, направление и желавшие иначе названы, лидер нет; `cell_discovered`, `cell_generated`, `object_created` словами для журнала и уведомлений), `StateWords`, `ConditionWords`, `OutcomeWords`, `StatusWords` — общие с шаблонами `app/round`. Исчерпанные подходы (`engine.ApproachDone`, B8) не предлагаются.
- Завязка и стартовый пакет (`opening.go`, [ADR-0018](../../../docs/decisions/0018-opening-scene.md), ADR-0019): `Service.Opening(ctx, OpeningParams) (OpeningResult, error)` — один вызов при `/begin` с ролью `opening`, промпт `assets/prompts/narrator/opening-v3.md` (`OpeningSystemPrompt`, `OpeningPromptVersion`), схема `OpeningSchema` `{text, factions[{code, goal, quest}], start, neighbors}`; вход `BuildOpeningInput`: мир, фракции, стартовая клетка шаблона с названиями объектов (`OpeningStart`), задания на соседей (`NeighborTask`), на цель и сюжетный квест каждой фракции (`OpeningParams.Quests`, `Goals`, `Template`; пункт 28), ключи модели персонажа, персонажи без скрытых описаний; замечания к тексту кодом (объём 80–3000 символов, цифры вне «механики», никнеймы) → один дозапрос, объём вне границ после него → `ErrOpening`; пакет (`validateOpeningWorld`): клетка `Start` (nil без валидных объектов — остаются объекты шаблона), `Neighbors` по направлениям заданий (пропущенные — шаблон), `Quests` и `Goals` по `validateQuests` / `validateGoals` (пропущенные — шаблон жанра). `Params.Opening` идёт первой строкой выжимки `world.previous` (до 1200 символов).
- Публичный вход: `New(LLM, logger)`, `Service.Narrate(ctx, Params) (Result, error)` (`Result.World`), `Service.Opening`, `BuildInput`, `BuildOpeningInput`, `PlanTasks`, `TemplateWorld`, `TemplateQuests`, `ConditionWordsFor`, `Options`, `OptionsText`, `MoveObject`, `Describe`, `Schema`, `OpeningSchema`, `PromptVersion`, `OpeningPromptVersion`, `SystemPrompt`, `OpeningSystemPrompt`; типы `Tasks`, `CellTask`, `NeighborTask`, `QuestTask`, `StageTask`, `GoalTask`, `QuestInfo`, `WorldPackage`, `GeneratedCell`, `GeneratedNeighbor`, `GeneratedQuest`, `GeneratedStage`, `GeneratedGoal`; интерфейс `LLM` (`Complete(ctx, model.LLMRequest)`), у вызывающего — обёртка над `app/llm.Complete` с ролью `narrator` и сохранением ответа по ключу задания.
- Контекст сцены несёт отметку входа персонажа `entry` (`new`/`returned`, из снимка, B1); промпт `narrator/v6` (`assets/prompts/narrator/v6.md`: `v5` без названий групп — модель не получает и не придумывает их, `party_split` без имени новой группы, `parties` задания на клетку — никнеймы вошедших; `v5` = `v4` + раздел «Квесты»: намёки на ближайший этап без слова «квест», правила `world.quests`, `world.stages`, `world.goals`) требует ввести нового и вернуть отсутствовавшего, описав его действие, и описывать прибытие в новую клетку в согласии с её пакетом.
- Правило: модель описывает, факты и исходы не меняет; текст игрока и описания персонажей — данные; при любой ошибке вызывающий публикует шаблонную хронику.
- Тесты: `narrator_test.go`, `opening_test.go`, `world_test.go` (задания, пакет мира, шаблон), `quests_test.go` (пакет квестов, достижимость условий, шаблоны, завязка с квестами) на фейковом LLM; живой прогон `make eval-narrator` (`cmd/eval-narrator`, `assets/prompts/narrator/eval/cases.json`, случаи `world_generation` и `quest_generation` с ожиданиями к пакету), завязка и стартовый пакет с целями и квестами — `EVAL_ARGS="-opening"`.
