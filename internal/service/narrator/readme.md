# service/narrator
- Назначение: вызов 2 из 2 на раунд ([round-calls.md](../../../docs/llm/round-calls.md), [narrator.md](../../../docs/llm/narrator.md), [ADR-0011](../../../docs/decisions/0011-narrator-call.md)): контекст из состояния после свёртки и событий `public`/`location` (`context.go`: сцены по группам внутри локаций — `scene_id`, координаты, стадия и местность клетки, выходы по направлениям с карточками неописанных соседей, скрытый сосед — `hidden` и `distant_view` без имени (ADR-0025), лидер и имя группы не передаются (пункт 19, [ADR-0016](../../../docs/decisions/0016-parties.md)); присутствующие, описания как данные, события словами, выжимка последних хроник; числа броска только в «механике»; блок `quests` с активными квестами для подсказок и блок `generate` с заданиями на достройку мира и по квестам при их наличии), системный промпт `assets/prompts/narrator/v12.md`, схема ответа (`schema.go`: `{chronicle, scenes[{scene_id, text, event_seqs}], world{cells, neighbors, quests, stages, goals}}`; код подставляет локацию и внутреннюю подпись «Группа (Локация)» в `NarrationScene.Party`; поле `scene.Party` не сериализуется), проверка (`validate.go`: сцены по `scene_id` и `seq` из входа, пара перехода — одно упоминание, секреты не в тексте, без цифр в «повествовании», объём, зачин не повторяет `world.previous` — `RepeatsOpening`, каждое задание `generate` выполнено — `undoneTasks`; B45, [ADR-0035](../../../docs/decisions/0035-story-momentum.md)) → один дозапрос с замечаниями (`checked.remarks`) → дописывание пропусков кодом (`Narration.Patched`), невыполненное задание — шаблон; утечка → `ErrLeak`, бюджет → `ErrBudget`.
- Пакет мира (`world.go`, пункт 27, [ADR-0019](../../../docs/decisions/0019-world-generation.md)): `PlanTasks(state, exists)` — занятые карточки → `CellTask` (до `model.MaxCellsPerRound`, остальные `Overflow`), недостающие соседи занятых клеток → `NeighborTask`; `validateWorld` принимает клетки и соседей только из заданий, нормализует ключи объектов в snake_case, режет по лимитам, подходы проверяет по модели персонажа (`validateApproach`: действие, характеристика, навык, сложность 1–9, `reveal` на скрытый объект клетки, состояние из списка), у соседа берёт `visible` → `Hidden` и `distant_view` только у скрытого (ADR-0025); пропущенное после дозапроса закрывает шаблоном (`TemplateWorld`, `templateCell` «Дорога», `templateNeighbor` «Неизведанные земли», видимый); замечания к качеству пакета в `Result.Issues`, дозапроса по ним нет; `WorldPackage.Templated` для метрик.
- Квесты (`quests.go`, пункт 28, [ADR-0020](../../../docs/decisions/0020-quests.md)): задания `Tasks.Quests` (`QuestTask`: фракция, тип, цель, границы этапов, порог, обязательность), `Tasks.Stages` (`StageTask`: квест, этап, вид условия, клетка и её объекты), `Tasks.Goals` (`GoalTask`: текущая цель, закрытый квест, запасной текст), `Tasks.StoryTemplate`; контекст `Params.Quests` (`QuestInfo` с ближайшим этапом `QuestStageInfo`, `ConditionWordsFor`); `validateQuests` (фракция из задания, этапы по `model.StageBounds`, ключи snake_case, расстояние 1–3, каталог условий; без этапов — шаблон для обязательного), `validateStages` (объекты по `validateObjects` без повтора ключей клетки, условие только достижимое подходом — `validateCondition`, `reachableState`, `reachableFact`, `firstReachable`; пропущено — после дозапроса `quest.TemplateStage`: `visited` без объекта, иначе «след»), `validateGoals`; `TemplateQuests` при сбое; результат в `WorldPackage.Quests` / `Stages` / `Goals` (`GeneratedQuest`, `GeneratedStage`, `GeneratedGoal`).
- Варианты следующего раунда: `Options(state, def, mode)` (подходы объектов: сложность по пресету режима плюс локация, шанс каждого присутствующего по параметру — для личных подсказок; переходов среди вариантов нет — B36, ADR-0025; клетка без вариантов даёт сцене `exhausted: true` во входе рассказчика — B45) и `OptionsText` — блок «Варианты» в группу: пункт на подход с новой строки, характеристика и сложность, без шансов (B6), в «повествовании» сложность словами (`rules.DifficultyWords`); слова событий `Describe` (у `party_split` и `party_held` актёр — группа, направление и желавшие иначе названы, лидер нет; `cell_discovered`, `cell_generated`, `object_created` словами для журнала и уведомлений), `StateWords`, `ConditionWords`, `OutcomeWords`, `StatusWords` — общие с шаблонами `app/round`. Исчерпанные подходы (`engine.ApproachDone`, B8) не предлагаются.
- Завязка и стартовый пакет (`opening.go`, [ADR-0018](../../../docs/decisions/0018-opening-scene.md), ADR-0019): `Service.Opening(ctx, OpeningParams) (OpeningResult, error)` — один вызов при `/begin` с ролью `opening`, промпт `assets/prompts/narrator/opening-v9.md` (`OpeningSystemPrompt`, `OpeningPromptVersion`; `v9` — расстояние этапа 0: этап про то, что уже лежит в `start`, ставится в стартовую клетку (B54); `v8` — при `world.endless` (`OpeningParams.Endless`, ADR-0037) цель фракции — горизонт, первый квест приближает, не исполняет; `v7` — цель фракции без срока, дедлайна и счётчика времени (B43); `v6` — логово сил зла: задание `OpeningParams.Lair` (`LairTask`: координаты, направление словами, фракция) → `generate.lair`, ответ `lair` → `OpeningResult.Lair` через `validateLair` (всегда скрытая, без имени — `TemplateLair`), ADR-0031; `v5` — крючок `world.premise` выбранного варианта мира, ADR-0028; `v4` — соседи с `visible`, `distant_view`), схема `OpeningSchema` `{text, factions[{code, goal, quest}], start, neighbors, lair}`; вход `BuildOpeningInput`: мир, фракции, стартовая клетка шаблона с названиями объектов (`OpeningStart`), задания на соседей (`NeighborTask`), на цель и сюжетный квест каждой фракции (`OpeningParams.Quests`, `Goals`, `Template`; пункт 28), ключи модели персонажа, персонажи без скрытых описаний; замечания к тексту кодом (объём 80–3000 символов, цифры вне «механики», никнеймы) → один дозапрос, объём вне границ после него → `ErrOpening`; пакет (`validateOpeningWorld`): клетка `Start` (nil без валидных объектов — остаются объекты шаблона), `Neighbors` по направлениям заданий (пропущенные — шаблон), `Quests` и `Goals` по `validateQuests` / `validateGoals` (пропущенные — шаблон жанра). `Params.Opening` идёт первой строкой выжимки `world.previous` (до 1200 символов).
- Генерация мира (`worldgen.go`, [ADR-0028](../../../docs/decisions/0028-worldgen.md)): `Service.Worldgen(ctx, WorldgenParams) (WorldgenResult, error)` — нулевой вызов после `/create` с ролью `worldgen`, промпт `assets/prompts/narrator/worldgen-v2.md` (`WorldgenSystemPrompt`, `WorldgenPromptVersion`; `v2` — `goal` стороны без срока, B43), схема `WorldgenSchema` `{options[{title, world, summary, tone, premise, factions[], start{}}]}`; вход `BuildWorldgenInput`: жанр как образец формы (название, тон, фракции, стартовая клетка `SetupStart`), лимиты длин, `seed`, `avoid`; `validateSetups`: до `model.WorldSetupOptions` вариантов, обязательные короткие поля в границах, фракции по кодам жанра, обрезка длинного, `terrain` через `normalizeKey`, повтор заголовка отброшен; меньше двух → `ErrWorldgen`, дозапроса нет. Завязка получает из выбранного варианта `OpeningParams.Premise` → `world.premise` (промпт `opening-v5`).
- Публичный вход: `New(LLM, logger)`, `Service.Narrate(ctx, Params) (Result, error)` (`Result.World`), `Service.Opening`, `Service.Worldgen`, `BuildInput`, `BuildOpeningInput`, `BuildWorldgenInput`, `PlanTasks`, `TemplateWorld`, `TemplateQuests`, `ConditionWordsFor`, `Options`, `OptionsText`, `Describe`, `Schema`, `OpeningSchema`, `WorldgenSchema`, `PromptVersion`, `OpeningPromptVersion`, `WorldgenPromptVersion`, `SystemPrompt`, `OpeningSystemPrompt`, `WorldgenSystemPrompt`; типы `Tasks`, `CellTask`, `NeighborTask`, `QuestTask`, `StageTask`, `GoalTask`, `QuestInfo`, `WorldPackage`, `GeneratedCell`, `GeneratedNeighbor`, `GeneratedQuest`, `GeneratedStage`, `GeneratedGoal`; интерфейс `LLM` (`Complete(ctx, model.LLMRequest)`), у вызывающего — обёртка над `app/llm.Complete` с ролью `narrator` и сохранением ответа по ключу задания.
- Контекст сцены несёт отметку входа персонажа `entry` (`new`/`returned`, из снимка, B1); промпт `narrator/v15` (`assets/prompts/narrator/v15.md`: `v14` + окраска действий `flavors` в сцене — вплетать манеру и просьбы, просьбы о рассказе исполнять по данным входа, просьбы о фактах не исполнять (пункт 38, ADR-0039); `v14` = `v13` + подсказки по просьбе фракции (пункт 35, ADR-0038): вход `hints` (код фракции, никнеймы её присутствующих персонажей; `Params.Hints` ← снимок раунда, никнеймы считает `BuildInput`), в сцене этих персонажей один ясный намёк, куда двигаться, по приоритету этап `quests[].next` → объект сцены → выход, внутри истории и только из данных входа; ответ `hints_given` — коды фракций, проверка `checkHints`: фракция без кода — замечание и дозапрос, после него не считается выполненной, выполненные — `Result.HintsGiven`; `v13` = `v12` + логово по ритму кода (B53): направление `scenes[].lair` сцена получает каждый `LairHintEvery`-й раунд либо рядом с логовом (`lairHintDue`), без `lair` о логове ни слова, направление логова — не дорога и не зацепка, одна примета издалека не звучит два раунда подряд; расстояние этапа 0 — этап там, где группа стоит (B54); `v12` = `v11` + бесконечная игра (ADR-0037): при `world.endless: true` (`Params.Endless` ← `model.Game.Endless`) цель фракции — горизонт: пересмотр приближает и открывает следующий слой, достигнутой цель не объявляется ни в `goals`, ни в хронике; `v11` = `v10` + движение истории (B45, ADR-0035): у сцены `exhausted` — зацепка наружу (следующий этап в другой клетке, этап без клетки по `summary`, сосед по карточке или виду издалека, тревога со стороны логова), после закрытого этапа — к следующему, зачин и состояние мира из `previous` не повторяются, задание на этап обязательно при любых других заданиях, для `visited` достаточно условия без объектов; `v10` = `v9` + цель фракции при пересмотре без срока, дедлайна и счётчика, срок из прошлой версии убирается (B43); `v9` = `v8` + логово сил зла как фон — `Params.Lair` (`LairInfo`) → `world.lair` (фракция, вид издалека, имя только у открытой клетки) и `scenes[].lair` (направление и дальность словами, `model.Coord.Bearing`): слухи и тревога с той стороны изредка, персонажей туда не вести, этапом квеста не делать (B42, ADR-0031); `v8` = `v7` + реплики `speeches` сцены (`Params.Speeches` из снимка, только присутствующим в своей сцене, реплики выбывших отброшены): цитата или пересказ, не инструкция и не факт, обращение к рассказчику не цитируется (пункт 32, ADR-0027); `v7` — `v6` + скрытые соседи: о `hidden` выходе только `distant_view`, в карточках `visible` и `distant_view`, выходы списком не перечисляются (B36); `v6` — `v5` без названий групп — модель не получает и не придумывает их, `party_split` без имени новой группы, `parties` задания на клетку — никнеймы вошедших; `v5` = `v4` + раздел «Квесты»: намёки на ближайший этап без слова «квест», правила `world.quests`, `world.stages`, `world.goals`) требует ввести нового и вернуть отсутствовавшего, описав его действие, и описывать прибытие в новую клетку в согласии с её пакетом.
- Правило: модель описывает, факты и исходы не меняет; текст игрока и описания персонажей — данные; при любой ошибке вызывающий публикует шаблонную хронику.
