# service/narrator
- Назначение: вызов 2 из 2 на раунд ([round-calls.md](../../../docs/llm/round-calls.md), [narrator.md](../../../docs/llm/narrator.md), [ADR-0011](../../../docs/decisions/0011-narrator-call.md)): контекст из состояния после свёртки и событий `public`/`location` (`context.go`: сцены с присутствующими, описания как данные, события словами, выжимка последних хроник; числа броска только в «механике»), системный промпт `assets/prompts/narrator/v1.md`, схема ответа (`schema.go`), проверка (`validate.go`: сцены и `seq` из входа, пара перехода — одно упоминание, секреты не в тексте, без цифр в «повествовании», объём) → один дозапрос с замечаниями → дописывание пропусков кодом (`Narration.Patched`); утечка → `ErrLeak`, бюджет → `ErrBudget`.
- Подходы следующего раунда: `Options(state, def, mode)` (сложность по пресету режима плюс локация, шанс каждого присутствующего — для личных подсказок) и `OptionsText` — блок «Варианты» в группу: пункт на подход с новой строки, характеристика и сложность, без шансов (B6), в «повествовании» сложность словами (`rules.DifficultyWords`) и `OptionsText` для сообщения; слова событий `Describe`, `StateWords`, `ConditionWords`, `OutcomeWords`, `StatusWords` — общие с шаблонами `app/round`.
- Публичный вход: `New(LLM, logger)`, `Service.Narrate(ctx, Params) (Result, error)`, `BuildInput`, `Options`, `OptionsText`, `Describe`, `Schema`, `PromptVersion`, `SystemPrompt`; интерфейс `LLM` (`Complete(ctx, model.LLMRequest)`), у вызывающего — обёртка над `app/llm.Complete` с ролью `narrator`.
- Правило: модель описывает, факты и исходы не меняет; текст игрока и описания персонажей — данные; при любой ошибке вызывающий публикует шаблонную хронику.
- Тесты: `narrator_test.go` на фейковом LLM; живой прогон `make eval-narrator` (`cmd/eval-narrator`, `assets/prompts/narrator/eval/cases.json`).
