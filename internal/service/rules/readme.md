# service/rules
- Назначение: правила игры как данные. Модель персонажа (`character.go`): валидация характеристик и навыков по `model.CharacterModelDef`, автораспределение по архетипу, формула HP вида `N + attribute`, разбор ответов игрока, поиск архетипа. Испытания (`checks.go`, «Прямой шанс», ADR-0014): `Version` = 1, параметр (`Param`: характеристика + навык + бонус предметов ≤ 2 − штрафы состояний + помощь ≤ 2), `ChancePct` = 50 + 10 × (параметр − сложность) в границах 5–95 (`ChanceMin`/`ChanceMax`), `Success` (бросок d100 ≤ шанс), `ChanceWords`, `DifficultyWords`, таблица риска `RiskDifficulty` (5 / 7 / 9), пресеты режимов `Preset` и `Difficulty` с потолком, `RoundsPerDay` и `DeathRounds` для ненастоящей смерти. Каталог (`catalog.go`): `Catalog`/`Entry` с поддержкой по пунктам плана, `ParseTyped` — типовые команды «глагол цель [force]» без LLM.
- Публичный вход: `ValidateAttributes`, `ValidateSkills`, `ValidateDraft`, `AutoDistribute`, `HP`, `ParseAttributes`, `ParseSkills`, `FindArchetype`, `ErrInvalid`; `Param`, `ChancePct`, `Success`, `ChanceWords`, `DifficultyWords`, `RiskDifficulty`, `Preset`, `Difficulty`, `RoundsPerDay`, `DeathRounds`, `Risks`, `ValidRisk`, `Conditions`, `ValidCondition`, `FreeDamageMax`, `Catalog`, `Entry`, `ParseTyped` (запасной разбор при сбое интерпретатора).
- Правило: чистые функции без I/O; ключи только из модели; описание модели в [docs/game/models](../../../docs/game/models/README.md).
