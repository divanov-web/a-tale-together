# service/rules
- Назначение: правила игры как данные. Модель персонажа (`character.go`): валидация характеристик и навыков по `model.CharacterModelDef`, автораспределение по архетипу, формула HP вида `N + attribute`, разбор ответов игрока, поиск архетипа. Испытания (`checks.go`, пункт 07): `Version`, пул (`Pool`: характеристика + навык + бонус предметов ≤ 2 − штрафы состояний + помощь ≤ 2, не меньше 1), `ChancePct` по биному (таблица `checks.md`), `ChanceWords`, таблица риска `RiskDifficulty`, пресеты режимов `Preset` и `Difficulty` с потолком, `RoundsPerDay` и `DeathRounds` для ненастоящей смерти. Каталог (`catalog.go`): `Catalog`/`Entry` с поддержкой по пунктам плана, `ParseTyped` — типовые команды «глагол цель [force]» без LLM.
- Публичный вход: `ValidateAttributes`, `ValidateSkills`, `ValidateDraft`, `AutoDistribute`, `HP`, `ParseAttributes`, `ParseSkills`, `FindArchetype`, `ErrInvalid`; `Pool`, `ChancePct`, `ChanceWords`, `RiskDifficulty`, `Preset`, `Difficulty`, `RoundsPerDay`, `DeathRounds`, `Risks`, `ValidRisk`, `Conditions`, `ValidCondition`, `FreeDamageMax`, `Catalog`, `Entry`, `ParseTyped` (запасной разбор при сбое интерпретатора).
- Правило: чистые функции без I/O; ключи только из модели; описание модели в [docs/game/models](../../../docs/game/models/README.md).
- Позже: встречные и совместные проверки (пункт 12), доступность действий по режиму.
