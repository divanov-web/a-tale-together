# model
- Назначение: общие сущности без поведения с I/O: идентификаторы (`ids.go`), пользователь, чат и статус бота в нём, игра с настройками, участник, сезон, фракция, жанр с шаблоном, модель персонажа как данные, персонаж и черновик персонажа, группа (`party.go`: `Party`, `SnapshotParty`, причины удержания, исход `OutcomeHeld`, `LeaderAttribute`; ADR-0016), состояние диалога, входящие Telegram и нажатия кнопок (`telegram.go`: `Incoming.Callback`, `Keyboard`, `Button`, грамматика данных кнопки `CallbackCommand`/`CallbackAnswer`/`ParseCallbackData`, ADR-0015), раунд со снимком v4 (клетки с `hidden` и `distant_view`, подпись `Glimpse`, `Exit.Title`, `ExitTo` по имени только видимого соседа, `UnknownTerritory`; ADR-0025; группы, лимиты, резерв `new_party_ids`, имена групп; занятые клетки и соседи с координатами, стадией, посещением и открывшими фракциями, выходы `Exits`/`ExitTo`), хроникой, попытками и метриками (`round.go`: `RoundMetrics` с `llm_reused`, `world_cells`, `world_templated`, `quests_issued`, `stages_placed`, `stages_done`; `MaxRoundAttempts`, `SnapshotSchemaVersion`), события и намерения (`engine.go`: в том числе `party_split`, `party_held`, `cell_discovered`, `cell_generated`, `object_created`, `GenerationEvents`), сетка мира (`world.go`, пункт 27, ADR-0019: `Direction` с `Offset`/`Opposite`/`Title`/`Toward`, `ParseDirection`, `LocationStage`, лимиты генерации, шаблонные имена клеток, `GenerationJob` — сохранённый ответ модели по ключу задания), квесты (`quest.go`, пункт 28, ADR-0020: `Quest` с этапами `QuestStage` (`Current`, `Previous`), `StageCondition` с каталогом `ConditionKinds`, `StageReward`, `FactionGoal` по версиям, `QuestTemplate`, лимиты этапов и длин, `IssueThreshold`, `StageBounds`; настройки `GameSettings.MaxStoryQuests` / `MaxSideQuests` с `QuestLimits`; события `quest_issued`, `quest_stage_placed`, `quest_stage_done`, `quest_done`, `goal_revised` в `GenerationEvents`; шаблон жанра: `FactionTemplate.Goal`, `GenreTemplate.StoryQuest`), запись журнала чатов (`chatlog.go`), сентинелы (`errors.go`: `ErrNotFound`, `ErrSendRejected`, `RetryAfterError` для классификации ошибок доставки, ADR-0013).
- Правило: без логики и зависимостей на слои; JSONB-структуры со `schema_version`; изменения согласованы с [моделью данных](../../docs/architecture/data-model.md).
