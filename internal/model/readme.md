# model
- Назначение: общие сущности без поведения с I/O: идентификаторы (`ids.go`), пользователь, чат и статус бота в нём, игра с настройками, участник, сезон, фракция, жанр с шаблоном, модель персонажа как данные, персонаж и черновик персонажа, состояние диалога, входящие Telegram и нажатия кнопок (`telegram.go`: `Incoming.Callback`, `Keyboard`, `Button`, грамматика данных кнопки `CallbackCommand`/`CallbackAnswer`/`ParseCallbackData`, ADR-0015), раунд со снимком, хроникой, попытками и метриками (`round.go`: `RoundMetrics`, `MaxRoundAttempts`), события и намерения (`engine.go`), запись журнала чатов (`chatlog.go`), сентинелы (`errors.go`: `ErrNotFound`, `ErrSendRejected`, `RetryAfterError` для классификации ошибок доставки, ADR-0013).
- Правило: без логики и зависимостей на слои; JSONB-структуры со `schema_version`; изменения согласованы с [моделью данных](../../docs/architecture/data-model.md).
