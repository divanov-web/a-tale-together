# model
- Назначение: общие сущности без поведения с I/O: идентификаторы (`ids.go`), пользователь, чат и статус бота в нём, игра с настройками, участник, сезон, фракция (с координатами логова `Lair`, ADR-0031), жанр с шаблоном, модель персонажа как данные, персонаж и черновик персонажа (с внешностью `Appearance`, B41), группа (`party.go`: `Party`, `SnapshotParty`, причины удержания, исход `OutcomeHeld`, `LeaderAttribute`; ADR-0016), состояние диалога, входящие Telegram и нажатия кнопок (`telegram.go`: `Incoming.Callback`, `Keyboard`, `Button`, грамматика данных кнопки `CallbackCommand`/`CallbackAnswer`/`ParseCallbackData`, ADR-0015), раунд со снимком v5 (реплики `speeches` для рассказчика, `Speech`, `SnapshotSpeech`, ADR-0027; клетки с `hidden` и `distant_view`, подпись `Glimpse`, `Exit.Title`, `ExitTo` по имени только видимого соседа, `UnknownTerritory`; ADR-0025; логово сил зла: `Coord` с `Bearing` словами, `LairCorners`, `TemplateLair*`, ADR-0031; группы, лимиты, резерв `new_party_ids`, имена групп; занятые клетки и соседи с координатами, стадией, посещением и открывшими фракциями, выходы `Exits`/`ExitTo`), хроникой, попытками и метриками (`round.go`: `RoundMetrics` с `llm_reused`, `world_cells`, `world_templated`, `quests_issued`, `stages_placed`, `stages_done`; `MaxRoundAttempts`, `SnapshotSchemaVersion`), события и намерения (`engine.go`: в том числе `party_split`, `party_held`, `cell_discovered`, `cell_generated`, `object_created`, `GenerationEvents`), сетка мира (`world.go`, пункт 27, ADR-0019: `Direction` с `Offset`/`Opposite`/`Title`/`Toward`, `ParseDirection`, `LocationStage`, лимиты генерации, шаблонные имена клеток, `GenerationJob` — сохранённый ответ модели по ключу задания), квесты (`quest.go`, пункт 28, ADR-0020: `Quest` с этапами `QuestStage` (`Current`, `Previous`), `StageCondition` с каталогом `ConditionKinds`, `StageReward`, `FactionGoal` по версиям, `QuestTemplate`, лимиты этапов и длин, `IssueThreshold`, `StageBounds`; настройки `GameSettings.MaxStoryQuests` / `MaxSideQuests` с `QuestLimits`; события `quest_issued`, `quest_stage_placed`, `quest_stage_done`, `quest_done`, `goal_revised` в `GenerationEvents`; шаблон жанра: `FactionTemplate.Goal`, `GenreTemplate.StoryQuest`), перезарядки действий (`cooldown.go`, ADR-0033: `Cooldown`, `CooldownAction` — `bio`, `secret`, `rename`, `hint`, `CooldownOwner` — персонаж или фракция; `Faction.HintRound` и `SnapshotHint` (`RoundSnapshot.Hints`, снимок v6), событие `hint_given` — подсказка по просьбе фракции (пункт 35, ADR-0038)), учёт LLM (`llm.go`, ADR-0032: `LLMUsage` — токены по видам с `TotalIn`, `LLMResponse` с `Usage`, `CostUSD`, `ProviderCostUSD`, `LLMRun` с разбивкой и `Usage()`, `LLMPrice` с `Cost`, `LLMPriceTable` — поиск по имени и префиксу снимка, `Estimate`), запись журнала чатов (`chatlog.go`, в `ChatLogCall` токены по видам и обе оценки), разметка сообщений (`text.go`, ADR-0029, ADR-0030: `FormattedText` с `Cut`, `TextEntity` со смещениями в рунах и тегами JSON для outbox, `TextBuilder` с `Key` / `Header` для ключей и заголовков жирным (B40), `Append`, `Len`; `Plain`; `Plural` — форма слова к числу; `OutboxMessage.Entities` и `Formatted`), сентинелы (`errors.go`: `ErrNotFound`, `ErrSendRejected`, `RetryAfterError` для классификации ошибок доставки, ADR-0013).
- Правило: без логики и зависимостей на слои; JSONB-структуры со `schema_version`; изменения согласованы с [моделью данных](../../docs/architecture/data-model.md).
- `Intent.Flavor` — окраска действия (пункт 38, [ADR-0039](../../../docs/decisions/0039-action-flavor.md)): безмеханическая часть заявки для рассказчика; движок не читает; хранится в `resolved_actions.intent`.
