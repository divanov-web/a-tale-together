# adapter/telegram
- Назначение: Telegram Bot API через `go-telegram/bot` (ADR-0004): long polling (`message`, `my_chat_member`, `callback_query`), разбор команд и нажатий кнопок, отправка текста с inline-кнопками (ADR-0015), меню команд, проверка админа группы.
- Публичный вход: `New(ctx, Settings, logger)`, `Client.Run(ctx, Handler)`, `Client.SendText` (ответы на команды), `Client.SendKeyboard` (ответ с кнопками), `Client.SendReplyKeyboard` (ответ в личку с reply-клавиатурой под полем ввода или её снятием; ADR-0021) — все три принимают `model.FormattedText`: разметка уходит как `entities`, смещения из рун пересчитываются в UTF-16 (`entities`, ADR-0029), `parse_mode` не используется; `Client.Send` (простой текст с клавиатурой, возвращает `message_id`, для воркера outbox), `Client.SendFormatted` (то же с разметкой), `Client.ClearKeyboard` (снять кнопки с сообщения; отказ 400 не ошибка), `Client.SetCommands` (меню личек и групп), `Client.SetMemberCommands` (меню участника чата областью `chat_member`, пустой список снимает; B20), `Client.IsChatAdmin`, `Client.CreateInviteLink` (`createChatInviteLink` с именем «A Tale Together», основная ссылка группы не отзывается; ADR-0022), `Client.Username`.
- Входящие: текстовые сообщения → `model.Incoming` с командой без `@bot` (чужие `/cmd@other_bot` отбрасываются); нажатие кнопки → `model.Incoming` с `Callback` (чат и сообщение из `callback_query`, команда или ответ шага из данных по `model.ParseCallbackData`, время из `Settings.Now`), после обработки `answerCallbackQuery` без текста; `my_chat_member` → `model.ChatMemberChange` со статусом бота `member/admin/left`.
- Ошибки библиотеки в лог; 409 Conflict означает второй экземпляр с тем же токеном. `Send` классифицирует ошибки для воркера outbox (ADR-0013, `classify`): `ErrorForbidden`, `ErrorBadRequest`, `ErrorNotFound`, `ErrorUnauthorized`, переезд чата → `model.ErrSendRejected`; `TooManyRequestsError` → `model.RetryAfterError` с `retry_after` (без него минута); остальное — временная ошибка.
- Тесты: `command_test.go` (разбор команд), `client_test.go` (классификация ошибок, разбор нажатия и сборка клавиатуры, перевод entities в UTF-16).
- Длинные игровые тексты делятся на части сценарием при постановке в outbox (`app/round.splitParts`, ADR-0011), адаптер отправляет части как отдельные сообщения. Планируется: webhook по отдельному ADR.
