# adapter/postgres
- Назначение: хранилище на `pgx/v5` (`pgxpool`): подключение, встроенные миграции goose, транзакции через контекст (`tx.go`, ADR-0008), репозитории по сущностям: `updates.go`, `users.go`, `chats.go` (чаты и модераторы), `dialogs.go`, `genres.go` (жанры и модели персонажа), `games.go` (игры, сезоны, фракции, участники), `characters.go` (персонажи и `character_stats`, активность), `rounds.go` (раунды с `attempts` и `metrics`, заявки, `LockGame` под `FOR UPDATE SKIP LOCKED`, `DueGameIDs`, `DeleteGameProgress` для сброса игры в dev), `outbox.go` (очередь исходящих: `EnqueueOutbox` с дедупом, `ClaimOutbox`, `FinishOutbox`), `llm.go` (профили LLM, `app_settings`, профиль игры, `llm_runs`), `locations.go` (клетки сетки с координатами и стадией, объекты `world_objects`, открытия по фракциям со счётчиком `AddDiscovery`, `ResetWorld`, сохранённые ответы модели `generation_jobs`: `SaveGenerationJob` пишет через пул вне транзакции; пункт 27, ADR-0019), `events.go` (`world_events` с `NextEventSeq`, `resolved_actions`), `parties.go` (группы: `CreateParty` с явным зарезервированным id, `UpdateParty`, `ListParties`, `SetCharacterParty`, `ReservePartyIDs` из последовательности `parties.id`; пункт 19); `characters.go` также `SaveCharacterState` (состояние после свёртки событий, включая `party_id`). `DeleteGameProgress` удаляет и группы, и `generation_jobs`.
- Публичный вход: `New(ctx, Settings, logger)`, `Store.Migrate`, `Store.Close`, `Store.InTx(ctx, func(ctx) error)`, методы репозиториев; `fake/` — хранилище в памяти с тем же контрактом для тестов.
- Правило: SQL в константах рядом с методом, через `Querier` из `db(ctx)`; игровые таблицы только с `game_id`; `model.ErrNotFound` для отсутствующих записей.
- Тесты: интеграционные с тегом `integration` на `DATABASE_URL_TEST` (`make test-integration`): дедупликация, пользователи, `TestGameFlow` (чат → игра → участник → персонаж, откат транзакции, диалоги, раунды и заявки, блокировка игры, outbox, профили LLM и `llm_runs`, клетки по координатам и объекты, открытия и счётчик фракции, сохранённые ответы модели, события, итоги заявок, состояние персонажа, группы).
- Связи: `migrations/`, `.claude/rules/postgres.md`, [модель данных](../../../docs/architecture/data-model.md).
