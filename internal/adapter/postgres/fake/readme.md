# adapter/postgres/fake
- Назначение: хранилище в памяти с теми же методами, что у `postgres.Store`, для тестов `app/*` без БД; предзаполнено жанром `fantasy` и моделью `basic_fantasy` (копия сидов миграции 00003).
- Публичный вход: `New(now func() time.Time)`, поле `Err` для имитации сбоя, поле `LLMPrices` — тарифы для `ListLLMPrices` (пусто — все модели без цены, ADR-0032), `BasicFantasy()`, `FantasyTemplate()`; `InTx` откатывает состояние при ошибке или панике (снимок карт и срезов, как транзакция Postgres; вложенный вызов — та же транзакция); раунды, заявки и outbox в `rounds.go` (`LockGame` без блокировки, `ListOutbox` для проверок, `DeleteGameProgress`); профили LLM, настройки и `llm_runs` в `llm.go` (без стартового профиля: тесты создают свои); клетки, объекты, открытия, `ResetWorld` и сохранённые ответы модели (`jobs` вне снимка транзакции: переживают откат, как запись через пул в Postgres) в `engine.go`; квесты с этапами, цели фракций по версиям и счётчик исследования в `quests.go` (пункт 28); перезарядки `ListCooldowns` / `SetCooldown` в `store.go` (ADR-0033; `DeleteGameProgress` их удаляет); группы в `parties.go` (явный id, уникальность имени активной группы, `ReservePartyIDs`). Шаблон жанра в `seed.go` содержит стартовую клетку (сокращённая копия миграции `00023`), имена групп по умолчанию (миграция `00019`), цели фракций и сюжетный квест `story_quest` (миграция `00024`).
- Правило: при добавлении метода в `postgres.Store` добавить его и сюда; уникальные ключи БД воспроизводятся проверками.
