# adapter/postgres/fake
- Назначение: хранилище в памяти с теми же методами, что у `postgres.Store`, для тестов `app/*` без БД; предзаполнено жанром `fantasy` и моделью `basic_fantasy` (копия сидов миграции 00003).
- Публичный вход: `New(now func() time.Time)`, поле `Err` для имитации сбоя, `BasicFantasy()`, `FantasyTemplate()`; раунды, заявки и outbox в `rounds.go` (`LockGame` без блокировки, `ListOutbox` для проверок); профили LLM, настройки и `llm_runs` в `llm.go` (без стартового профиля: тесты создают свои); локации, события и итоги заявок в `engine.go`. Шаблон жанра в `seed.go` содержит три локации (сокращённая копия миграции `00010`).
- Правило: при добавлении метода в `postgres.Store` добавить его и сюда; уникальные ключи БД воспроизводятся проверками.
