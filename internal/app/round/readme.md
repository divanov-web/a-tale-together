# app/round
- Назначение: жизненный цикл раунда (пункты 05 и 07, [ADR-0009](../../../docs/decisions/0009-round-scheduler.md)): `/begin` (стартовая сцена, первый раунд), открытие раундов по игровому окну (`window.go`), приём заявок, заморозка со снимком v2 и seed или пропуск без кворума с переносом заявок, статусы персонажей по пропускам и счётчик ненастоящей смерти, разрешение в той же транзакции (`resolve.go`: `rules.ParseTyped` → `engine.Resolve` → `world_events`, `resolved_actions`, свёртка `engine.Apply` в состояние персонажей и объектов, статус `published`, хроника и приватные итоги шаблоном в outbox), пауза, dev-команды `/next` и `/replay`; игровые тексты (`texts.go`) только через outbox.
- Публичный вход: `New(Store, Rights, Clock, logger)`; поле `AnnounceSkipped` (сообщение о пропуске в группу, `cmd` включает в dev); `Begin`, `Pause`, `Next`, `Submit`, `Info`, `Replay`, `Tick(ctx, now)` для планировщика; `FormatTime`, `SkippedText`.
- Интерфейсы потребителя: `Store` (`adapter/postgres`: игры под `LockGame`, раунды, заявки, персонажи, outbox), `Rights` (`app/game.CanAdmin`), `Clock`.
- Ошибки для ответа игроку: `ErrForbidden`, `ErrAlreadyStarted`, `ErrNotActive`, `ErrPaused`, `ErrFinished`, `ErrNoCharacters`, `ErrNoOpenRound`, `ErrEmpty`, `ErrTooLong`, `ErrAlreadyActed`, `ErrTooFrequent` (замена только при `settings.allow_resubmit`), `ErrDead`, `ErrNoRound`, `ErrNotResolved`.
- Правило: каждая игра обрабатывается в своей транзакции под блокировкой строки; состояние только в БД; `games.next_round_at` — единственный таймер; рассказчик заменит шаблонные тексты в пункте 09, интерпретатор свободного текста — пункт 08.
- Тесты: сценарии на `adapter/postgres/fake` с управляемыми часами (`service_test.go`).
