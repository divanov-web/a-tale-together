# app/game
- Назначение: сценарии игры: создание мира в чате (игра `draft`, сезон 1, фракции и локации из шаблона жанра, админ), параметры `/set` и диалога настройки (`settings.go`), вход по коду, текущая игра пользователя, сводка `/status`, персонаж (`character.go`: модель жанра, валидация никнейма и описаний, создание с HP, стартовым инвентарём с бонусами предметов и стартовой локацией, описания; в идущей игре новичок получает группу — `assignParty`: группа стартовой локации, иначе новая в пределах `max_parties` с ним как лидером, иначе ближайшая по выходам с входом в её локацию), группы (`parties.go`, пункт 19, [ADR-0016](../../../docs/decisions/0016-parties.md): `Parties` с участниками, `CreateParty`, `JoinParty` (в идущей игре только в своей локации), `LeaveParty`; выход меняет лидера по `service/party.Leader` или распускает пустую группу; лидер игрокам не отдаётся); `Locations` — локации игры.
- Публичный вход: `New(Store, Rights, Clock, logger)`; поле `Defaults` — настройки нового мира (`cmd` ставит кворум 1 в dev); `Create`, `Set`, `Params`, `Join`, `Current`, `Of`, `Select`, `OfChat`, `ByCode`, `Get`, `CanAdmin`, `Status`, `Factions`, `Genre`, `CharacterModel`, `Character`, `CreateCharacter`, `ValidateNickname`, `ValidateBio`, `SetBio`, `Parties`, `CreateParty`, `JoinParty`, `LeaveParty`.
- Интерфейсы потребителя: `Store` (`adapter/postgres`, транзакция через контекст по ADR-0008), `Rights` (`app/chat`), `Clock`.
- Ошибки для ответа игроку: `ErrForbidden`, `ErrGameExists`, `ErrNoGame`, `ErrGameFinished`, `ErrNotMember`, `ErrHasCharacter`, `ErrNoCharacter`, `ErrNicknameTaken`, `ErrChooseGame`, `ErrBadValue`, `ErrNoParty`, `ErrPartyNotFound`, `ErrPartyLimit`, `ErrPartyNameTaken`, `ErrSameParty`, `ErrPartyFar`.
- Правило: границы транзакций здесь; правила персонажа в `service/rules`; SQL и Telegram не используются.
- Тесты: сценарии на фейковом хранилище `adapter/postgres/fake`.
