# app/game
- Назначение: сценарии игры: создание мира в чате (игра `setup`, сезон 1, фракции и стартовая клетка `(0,0)` из шаблона жанра, админ; остальной мир достраивает рассказчик, пункт 27), параметры `/set` и диалога настройки (`settings.go`), завершение настройки `FinishSetup` (`setup` → `draft` и личное «можно создать персонажа» участникам без персонажа через outbox в той же транзакции, `SetupDoneNotice`; ADR-0023), вход по коду (в `setup` участник записывается, персонаж не создаётся — `ErrGameSetup`), текущая игра пользователя, сводка `/status`, персонаж (`character.go`: модель жанра, валидация никнейма и описаний, создание с HP, стартовым инвентарём с бонусами предметов и стартовой локацией, описания; в идущей игре новичок получает группу — `assignParty` по `service/party.Assign`: группа стартовой локации, иначе новая в пределах `max_parties` с ним как лидером, иначе ближайшая по сетке с входом в её клетку; группы без присутствующих распускаются), группы (`parties.go`, пункт 19, [ADR-0016](../../../docs/decisions/0016-parties.md), [ADR-0017](../../../docs/decisions/0017-party-mandatory.md): `Parties` с участниками для карточки; команд создания, входа и выхода нет; лидер игрокам не отдаётся); `Locations` — клетки игры; `Quests`, `Goals` — квесты и цели фракций для `/quests` (пункт 28).
- Публичный вход: `New(Store, Rights, Clock, logger)`; поле `Defaults` — настройки нового мира (`cmd` ставит кворум 1 в dev); `Create`, `FinishSetup`, `SetupDoneNotice`, `Set`, `Params`, `Join`, `Current`, `Of`, `Select`, `OfChat`, `ByCode`, `Get`, `CanAdmin`, `Status`, `Factions`, `Genre`, `CharacterModel`, `Character`, `CreateCharacter` (в той же транзакции объявление `character_joined` в outbox группы по `JoinedNotice`, без скрытого описания; B25, ADR-0022), `Chat`, `ValidateNickname`, `ValidateBio`, `SetBio`, `Parties`, `Quests`, `Goals`.
- Интерфейсы потребителя: `Store` (`adapter/postgres`, транзакция через контекст по ADR-0008), `Rights` (`app/chat`), `Clock`.
- Ошибки для ответа игроку: `ErrForbidden`, `ErrGameExists`, `ErrNoGame`, `ErrGameFinished`, `ErrNotMember`, `ErrHasCharacter`, `ErrNoCharacter`, `ErrNicknameTaken`, `ErrChooseGame`, `ErrBadValue`, `ErrGameSetup`.
- Правило: границы транзакций здесь; правила персонажа в `service/rules`; SQL и Telegram не используются.
- Тесты: сценарии на фейковом хранилище `adapter/postgres/fake`.
