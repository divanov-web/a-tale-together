# app/bot
- Назначение: сценарий входящих Telegram: дедупликация по `update_id`, лимит частоты (`ratelimit.go`), учёт пользователя, реестр команд с контекстами и подсказкой в чужом контексте (`router.go`), регистрация чата по `my_chat_member`, диалоги в личке (`dialog*.go`: настройка игры, создание персонажа — фракция, никнейм, пол (B18), архетип, очки, описания; состояние в таблице `dialogs`; вопрос с кнопками ответов `question`, данные кнопки `@шаг ответ` применяются только на текущем шаге), нажатия inline-кнопок как команды или ответы диалога (ADR-0015: `dispatch`, снятие клавиатуры `ClearKeyboard` кроме отказа в правах `isRightsError`), ответы шаблонами `templates/`.
- Публичный вход: `New(Settings, Store, Dialogs, Telegram, *chat.Service, *game.Service, *round.Service, *llm.Service, Clock, logger)` (`Settings.OwnerID` — владелец бота для `/llm`, `Settings.GuideURL` — ссылки руководства под `/help`), `Service.Handle`, `Service.HandleChatMember`, `Service.RegisterMenu` (меню лички, группы для всех и владельцев с модераторами всех активных чатов, B20), `Service.Commands` (всё для `/help`), `Service.Menu` (меню Telegram по контексту и правам).
- Интерфейсы потребителя: `Store`, `Dialogs` (`adapter/postgres`), `Telegram` = `Messenger` (`SendText`, `SendKeyboard`, `ClearKeyboard`) + `ChatAPI` (`IsChatAdmin`, меню) (`adapter/telegram`), `Clock`, `Journal` (поле; входящие с пометкой дублей, `my_chat_member`, ответы и сбои сценариев в журнал чата, ADR-0012).
- Файлы: `cmd_basic.go` (`/start /help /me /ping /cancel`), `cmd_chat.go` (`/chat /mod /owner`), `cmd_game.go` (`/create /status /set /join /games`), `cmd_character.go` (`/character /create /bio /secret /knowledge`; краткая карточка с группой и числом знаний, описания — `/bio` или `/secret` без текста, знания полным списком частями `knowledgeMessages`, B28), `cmd_party.go` (`/party`: карточка группы без лидера и остальные группы; команд управления нет — группы назначает код, ADR-0017), `cmd_quests.go` (`/quests`: цель и квесты фракции персонажа, этапы ✓ / ▶ клетка и подсказка / ○; кнопок нет, пункт 28), `cmd_round.go` (`/begin /pause /finish /act` — `/begin` и `/finish` с подтверждением кнопками (`yes|no`), `/pause` с кнопкой «Возобновить», `/act` в личке и в группе, по ссылке варианта `#…` через `round.SubmitOption`, `implicitAct` для текста без команды в личке вне диалога; `/next /replay /round /reset` только при `Env == dev`; строки о раундах в `/status`), `cmd_llm.go` (`/llm` с подкомандами `use reset add test`, только владелец бота).
- Ошибки сценариев из списка `userErrors` уходят игроку текстом; остальные — «Что-то пошло не так» и возврат ошибки в лог.
- Правило: обработчики тонкие, игровой логики и SQL нет; ответы на команды синхронные (ADR-0006), игровые тексты через outbox. Реестр: [telegram-commands.md](../../../docs/architecture/telegram-commands.md).
- Тесты: сквозные сценарии на `adapter/postgres/fake` (`service_test.go`; кнопки — `TestButtons_*` через `harness.press`; группы — `TestParty_*`; квесты — `TestQuests_Card`).
