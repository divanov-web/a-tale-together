# app/bot/templates
- Назначение: тексты ответов бота на русском как `text/template` (`*.tmpl`, embed); логики сценариев нет, только `range`/`if` по готовым данным.
- Публичный вход: `Render(name, data) (string, error)`; имя без расширения.
- Правило: новый шаблон — новый файл; данные передаются картой или структурой из `app/bot`.
