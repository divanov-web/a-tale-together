# app/bot/templates
- Назначение: тексты ответов бота на русском как `text/template` (`*.tmpl`, embed); логики сценариев нет, только `range`/`if` по готовым данным.
- Публичный вход: `Render(name, data) (string, error)`; имя без расширения.
- Правило: новый шаблон — новый файл; данные передаются картой или структурой из `app/bot`; формат (B16): одно поле на строку, пустая строка между блоками, списки через «•». Шаблоны только для текстов без разметки (`chat`, `game_created`, `help`, `me`, `start`); карточки с ключами жирным (`/status`, `/character`) собираются кодом в `app/bot` через `model.TextBuilder` (B40, ADR-0030).
