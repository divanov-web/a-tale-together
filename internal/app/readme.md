# app
- Назначение: прикладные сценарии, связывающие сервисы и адаптеры: `bot` (команды и диалоги), `sim` (имитатор партии с ИИ-игроками, ADR-0034), `chat` (чаты и права), `game` (игра, участники, персонажи), `round` (жизненный цикл раунда: старт, заявки, заморозка, пропуск, пауза), `scheduler` (тик планировщика), `delivery` (воркер outbox), `llm` (профили провайдеров LLM, единый вход вызовов, учёт в `llm_runs`). Сценарии `bot`, `delivery`, `llm`, `round` пишут журнал чатов через поле `Journal` (`adapter/chatlog`, ADR-0012; nil — выключен).
- Правило: тонкие шаги без игровой логики и SQL; границы транзакций здесь (`InTx` через контекст, ADR-0008).
- Связи: [архитектура](../../docs/architecture/overview.md), [слои](../../docs/architecture/layers.md), [конвейер раунда](../../docs/architecture/round-pipeline.md).
