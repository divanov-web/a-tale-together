# migrations
- Назначение: SQL-миграции goose `NNNNN_<что>.sql`, `-- +goose Up/Down`: `00001` пользователи и дедупликация, `00002` чаты, модераторы, диалоги, `00003` справочники (сиды `basic_fantasy`, `fantasy`), игры, сезоны, фракции, участники, `00004` персонажи и характеристики, `00005` кворум раунда в `games.settings`, `00006` `max_players` → `max_round_players`.
- Правило: после коммита не правятся; `game_id` в каждой игровой таблице; типы PK по ADR-0005; справочные данные (жанры, модели) добавляются миграцией.
- Применение: `make migrate` или `MIGRATE_ON_START=true`; см. `.claude/rules/postgres.md`.
