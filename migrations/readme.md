- Правило: после коммита не правятся; `game_id` в каждой игровой таблице; типы PK по ADR-0005; справочные данные (жанры, модели) добавляются миграцией.
- Применение: `make migrate` или `MIGRATE_ON_START=true`; см. `.claude/rules/postgres.md`.
