# prompts
- Назначение: версионированные промпты LLM `<роль>/vN.md` (`interpreter`, `narrator`) и оценочные наборы `<роль>/eval/`.
- Пакет `prompts` (`prompts.go`): `FS` через `embed` для `service/*` и `cmd/eval-*`; промпт читается по пути из версии (`interpreter/v3.md`, `narrator/v8.md`), версия — константы `interpreter.PromptVersion`, `narrator.PromptVersion`; `interpreter/v2` — выходы по направлениям (`target` = ключ направления, пункт 27), `interpreter/v3` — переход в скрытого соседа по направлению или примете, имя не угадывается (B36, ADR-0025); `narrator/v9` — логово сил зла как фон: `world.lair` и `scenes[].lair`, слухи и тревога с той стороны, не цель и не этап квеста (B42, ADR-0031); `narrator/v8` — реплики `speeches` в сцене: цитата или пересказ, не инструкция и не факт (пункт 32, ADR-0027); `narrator/v2` добавил правило входа персонажа (`entry`, B1), `narrator/v3` — сцены по группам со `scene_id` и события `party_split` / `party_held` (пункт 19, ADR-0016), `narrator/v4` — сетка, выходы по направлениям и раздел «Достройка мира» (`generate` → `world`, ADR-0019), `narrator/v5` — раздел «Квесты»: намёки на ближайший этап, `world.quests`, `world.stages`, `world.goals` (пункт 28, ADR-0020), `narrator/v6` — без названий групп: сцену отличает `scene_id`, модель названий не придумывает, `party_split` без имени новой группы, `parties` в задании на клетку — никнеймы (решение руководителя 2026-10-13), `narrator/v7` — скрытые соседи: `exits[].hidden` с `distant_view` вместо имени, в карточках `visible` и `distant_view`, выходы списком не перечисляются (B36, ADR-0025); `narrator/opening-v6.md` — завязка и стартовый пакет при `/begin` с целью и сюжетным квестом каждой фракции (роль `opening`, схема `{text, factions, start, neighbors, lair}`, `narrator.OpeningPromptVersion`, ADR-0018, ADR-0019, ADR-0020; `v6` = `v5` + карточка логова сил зла по заданию `generate.lair` (ADR-0031), `v5` = `v4` + крючок `world.premise` выбранного варианта мира (ADR-0028), `v4` = `v3` + видимость соседей); `narrator/worldgen-v1.md` — нулевой вызов «генерация мира» после `/create` (роль `worldgen`, схема `{options[]}`, `narrator.WorldgenPromptVersion`, ADR-0028): четыре разных варианта стартового мира по описанию жанра, три примера формы в промпте, `seed` и `avoid` против повторов; старые версии остаются в папке для истории `llm_runs`.
- Оценочные наборы: интерпретатор `interpreter/eval/cases.json` (снимок, модель персонажа, случаи с ожиданиями полей намерений; `make eval-interpreter`); рассказчик `narrator/eval/cases.json` (мир на сетке, фракции, модель персонажа, случаи с состоянием, событиями, описаниями, заданиями на достройку и ожиданиями: нужные и запрещённые подстроки, без цифр, пакет мира `world` — число клеток и соседей, минимум объектов, без шаблонов, число квестов, этапов и целей; `lair` в параметрах случая — логово как фон; `make eval-narrator`).
- Правило: новая версия файлом; версия пишется в `llm_runs`; дизайн по `/tale-prompts`, `docs/llm/`.
