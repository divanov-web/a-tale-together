# prompts
- Назначение: версионированные промпты LLM `<роль>/vN.md` (`interpreter`, `narrator`) и оценочные наборы `<роль>/eval/`.
- Пакет `prompts` (`prompts.go`): `FS` через `embed` для `service/*` и `cmd/eval-*`; промпт читается по пути из версии (`interpreter/v2.md`, `narrator/v5.md`), версия — константы `interpreter.PromptVersion`, `narrator.PromptVersion`; `interpreter/v2` — выходы по направлениям (`target` = ключ направления, пункт 27); `narrator/v2` добавил правило входа персонажа (`entry`, B1), `narrator/v3` — сцены по группам со `scene_id` и события `party_split` / `party_held` (пункт 19, ADR-0016), `narrator/v4` — сетка, выходы по направлениям и раздел «Достройка мира» (`generate` → `world`, ADR-0019), `narrator/v5` — раздел «Квесты»: намёки на ближайший этап, `world.quests`, `world.stages`, `world.goals` (пункт 28, ADR-0020); `narrator/opening-v3.md` — завязка и стартовый пакет при `/begin` с целью и сюжетным квестом каждой фракции (роль `opening`, схема `{text, factions, start, neighbors}`, `narrator.OpeningPromptVersion`, ADR-0018, ADR-0019, ADR-0020); старые версии остаются в папке для истории `llm_runs`.
- Оценочные наборы: интерпретатор `interpreter/eval/cases.json` (снимок, модель персонажа, случаи с ожиданиями полей намерений; `make eval-interpreter`); рассказчик `narrator/eval/cases.json` (мир на сетке, фракции, модель персонажа, случаи с состоянием, событиями, описаниями, заданиями на достройку и ожиданиями: нужные и запрещённые подстроки, без цифр, пакет мира `world` — число клеток и соседей, минимум объектов, без шаблонов, число квестов, этапов и целей; `make eval-narrator`).
- Правило: новая версия файлом; версия пишется в `llm_runs`; дизайн по `/tale-prompts`, `docs/llm/`.
