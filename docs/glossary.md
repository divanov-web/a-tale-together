# Глоссарий

| Термин | Англ. в коде | Значение |
|---|---|---|
| Игра, мир, партия | game | Независимая кампания одной Telegram-группы: настройки, состояние, расписание, правила. Ключ изоляции `game_id` |
| Администратор | admin | Пользователь, создавший игру в группе; управляет настройками и расписанием |
| Игрок | player, game member | Пользователь Telegram, зарегистрированный в игре через приватный чат |
| Персонаж | character | Игровая сущность игрока: характеристики, HP, состояния, инвентарь, локация, знания |
| Локация | location | Место действия; у игры лимит одновременно активных локаций |
| Раунд | round | Логический шаг игры: окно приёма заявок, снимок, разрешение, публикация |
| Заявка | action submission | Сырой текст игрока с намерением на раунд; статус и время подачи |
| Снимок раунда | round snapshot | Замороженный набор заявок и версия состояния на дедлайн |
| Намерение | intent | Структурированный разбор заявки интерпретатором: тип, цель, параметры, неоднозначности |
| Каталог действий | action catalog | Конечный список типов действий, к которым сводится свободный текст |
| Конфликтная группа | conflict group | Намерения над одной сущностью или ресурсом, разрешаемые вместе |
| Проверка | check | Бросок d20 + модификатор против сложности; исходы: успех, успех с ценой, провал |
| Разрешённое действие | resolved action | Итог намерения: статус `resolved / rejected / deferred / ambiguous`, проверки, ссылки на события |
| Событие мира | world event | Атомарное изменение состояния с видимостью; журнал только добавляется |
| Видимость | visibility | Кому доступно событие: `public`, `location`, `private(character_ids)` |
| Движок | engine | Детерминированный код правил: проверки, конфликты, применение событий |
| Интерпретатор | interpreter | Вызов LLM: текст заявки → намерение JSON |
| Рассказчик | narrator | Вызов LLM: разрешённые события → публичная хроника и приватные итоги |
| Хроника | chronicle | Публичный текст раунда в группе |
| Приватный итог | private result | Личный текст игроку о результате его заявки |
| Outbox | messages outbox | Таблица исходящих сообщений для надёжной доставки |
| Провайдер LLM | llm provider | Реализация интерфейса `llm.Client`: `claude-cli`, `anthropic-api`, `openai-api`, `fake` |
| Профиль LLM | llm profile | Запись в БД: провайдер, модели для ролей, параметры; выбирается для бота или игры |
| Прогон LLM | llm run | Запись одного вызова модели: модель, версия промпта, токены, стоимость, ошибка |
| Версия правил | rules version | Версия каталога действий и таблиц проверок, закреплённая за игрой |
| ADR | ADR | Запись архитектурного решения в `docs/decisions/` |
| Сценарий | scenario | Эталонный пример раунда с ожидаемыми исходами; основа тестов движка |
