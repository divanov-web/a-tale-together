# ADR-0022: Ссылка на чат игры и объявление о новом участнике

- Статус: принято
- Дата: 2026-10-13
- Область: `adapter/telegram`, `app/chat`, `app/bot`, `app/game`, `chats`, `messages_outbox`; бэклог B24, B25

## Контекст
- Игрок вступает по ссылке `join_` в личке и может ещё не состоять в группе игры; после создания персонажа ему некуда перейти (B24).
- Группа не знает о новом участнике, пока рассказчик не введёт его в сцену по `entry=new` (B25).
- Ссылку на группу даёт только Telegram: `exportChatInviteLink` (отзывает прежнюю основную ссылку группы) или `createChatInviteLink` (дополнительная ссылка); обе требуют, чтобы бот был администратором с правом приглашать.

## Варианты
| Вариант | За | Против |
|---|---|---|
| `exportChatInviteLink` | одна основная ссылка | ломает ссылку, которую раздал администратор |
| `createChatInviteLink` на каждого игрока | ссылка всегда свежая | засоряет список ссылок группы |
| `createChatInviteLink` один раз, хранить в `chats.invite_link` | один вызов на чат, ссылки администратора не трогаются | отзыв ссылки вручную бот не видит до следующего `my_chat_member` |
| Объявление синхронным ответом | проще | правило: игровые тексты в группу только через outbox |
| Объявление через outbox в транзакции персонажа | атомарно с созданием, повтор не дублирует | — |

## Решение
- Ссылка: `createChatInviteLink` с именем «A Tale Together» при первом создании персонажа в чате, результат в `chats.invite_link` (миграция `00026`). Любое `my_chat_member` (смена статуса или прав бота) очищает ссылку, следующий персонаж получает новую. Отказ Telegram (нет прав, бот не админ) — запись в лог, кнопки нет, итог создания персонажа не ломается.
- Кнопка-ссылка «Перейти в чат игры» под итогом создания персонажа (ADR-0015 разрешает кнопки-ссылки, команды за ней нет: это переход, а не действие).
- Объявление: сообщение `character_joined` в `messages_outbox` в той же транзакции, что и персонаж (уникальность персонажа в сезоне исключает дубль): «Новый участник», никнейм, фракция и открытое описание; скрытое описание не попадает (принцип 6). Чат, из которого бот удалён, объявление не получает.

## Последствия
- `model.Chat.InviteLink`, `chat.Service.InviteLink`, `telegram.Client.CreateInviteLink`, `model.OutboxCharacterJoined`; `game.Store.EnqueueOutbox`.
- Руководство: `guide/` (создание персонажа, бот в группе — права администратора на приглашения).
