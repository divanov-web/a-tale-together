# ADR-0005: Идентификаторы в БД

- Статус: принято
- Дата: 2026-10-10
- Область: `migrations/`, `internal/model`, промпты LLM

## Контекст
ID попадают в промпты LLM (риски §4: короткие стабильные ID с понятными именами) и в уникальные ключи идемпотентности.

## Варианты
| Вариант | За | Против |
|---|---|---|
| `bigint identity` | компактны, читаемы в промптах, быстрые индексы | предсказуемы (неважно: ID не публикуются игрокам) |
| `uuid v7` | глобальная уникальность, можно генерировать в коде | длинные в промптах, дороже индексы |

## Решение
`bigint identity` для всех таблиц; в промптах LLM используются короткие алиасы вида `c12` (character 12), `a3` (action 3), генерируемые сборщиком контекста. Применено в `migrations/00001_init.sql`.
