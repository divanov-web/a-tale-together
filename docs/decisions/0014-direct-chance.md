# ADR-0014: Система проверок «Прямой шанс» (rules_version 1)

- Статус: принято
- Дата: 2026-10-11
- Область: `service/rules`, `service/engine`, `model.CheckInfo`, `character_models`, шаблон стартового мира, `docs/game/checks.md`, `guide/checks/`

## Контекст
- Прежняя система (Year Zero Engine) отклонена руководителем 2026-10-11 как не подходящая проекту: игрок не мог посчитать свой шанс в уме, а на стартовых числах специализация не работала: профильный и слабый персонаж проваливались почти одинаково часто. Механики прежней системы в документах не хранятся.
- Руководитель принёс спецификацию стартового баланса 80 % / 20 % (концепт от ChatGPT, коммит `163a665`) и выбрал её как замену; название — «Прямой шанс».
- Ограничения: движок — источник истины, детерминизм по seed, одна проверка на заявку, видимость чисел по режиму, `rules_version` закреплена за игрой (G10).

## Варианты
| Вариант | За | Против |
|---|---|---|
| Оставить прежнюю систему с перекалиброванными числами | минимум правок | шанс по-прежнему нельзя посчитать в уме; калибровка 80 % / 20 % недостижима без перебора таблиц |
| «Прямой шанс»: параметр − сложность, 10 % за очко, один бросок d100 | шанс виден до действия и считается в уме; геймдизайнер задаёт проценты напрямую; специализация 80 % против 20 % | линейный рост упирается в 95 % через +2 очка: новые сцены должны поднимать сложность |
| d20 + модификатор против порога | привычно по D&D | те же числа, но шаг 5 % и порог менее нагляден, чем процент |

## Решение
- Формула: `параметр = характеристика + навык + предметы (≤ 2) + помощь (≤ 2) − состояния`; `сложность = база + локация`; `шанс = clamp(50 + 10 × (параметр − сложность), 5, 95)`; успех при `d100 ≤ шанс`. Подход без характеристики и со сложностью 0 — без броска.
- Таблица риска свободного действия `normal / hard / extreme → 5 / 7 / 9`; потолок «повествования» 5; слова сложности: 5 обычно, 6–7 трудно, 8–9 очень трудно, 10+ героически.
- Форсирование остаётся однократным повторным броском с тем же шансом ценой «истощён» (замечание Claude принято руководителем); в «повествовании» автоматическое и без цены.
- Один алгоритм в движке: воспроизведение снимков версии 0 старым алгоритмом не реализуется — боевых миров нет, игры песочницы переводятся SQL на версию 1. `rules.Version = 1`; G10 остаётся на будущее.
- Модель персонажа `basic_fantasy` меняется на месте (без второго кода модели): характеристики 2–5 с суммой 14, навык `athletics`, пять билдов из спецификации, стартовые предметы без бонуса к проверкам (бонусные предметы появятся позже, поле бонуса `points` 1–2).
- Стартовый мир: одиннадцать подходов с итоговой сложностью 5 (подвал: база 4 + локация 1), новые подходы следопыта и дипломата с фактами в данных.
- Встречные проверки и урон (пункт 12) — той же формулой: шанс атакующего `50 + 10 × (параметр атакующего − параметр защищающегося)`.
- `CheckInfo`: `attribute`, `skill`, `param`, `difficulty`, `chance_pct`, `roll`, `pushed`, `push_roll`, `outcome`; поля `pool`, `dice`, `successes` удаляются.
