# ADR-0002: Стартовые правила из референса

- Статус: принято
- Дата: 2026-10-10
- Область: `docs/dev/coding-rules.md`, `docs/architecture/layers.md`, `.claude/rules/go.md`

## Контекст
На старте руководитель указал личный Go-проект как образец структуры и стиля. Полное копирование не нужно: часть решений устарела, часть не подходит серверному боту.

## Решение
Из референса один раз составлены [стартовые правила программирования](../dev/coding-rules.md) и [слоёная архитектура](../architecture/layers.md) под текущие требования проекта. Взято: разбиение `cmd/` + `internal/{config,app,service,adapter}`, `readme.md` в пакете, дефолты конфига + `.env`, ручная сборка зависимостей, краткие комментарии и краткие документы. Заменено: структурный логгер stdlib вместо сторонних, типизированные настройки вместо `any`, `Validate() error` вместо `panic`, без CLI-флагов, обязательные тесты логики, пакет `internal/model`.

К референсу больше не обращаемся: документы проекта самодостаточны, упоминания референса удалены из промптов и документации.

## Последствия
Изменение правил — правка `coding-rules.md` и `.claude/rules/go.md`; изменение слоёв — новый ADR.
