# ADR-0006: Ответы на команды синхронно, игровые тексты через outbox

- Статус: принято
- Дата: 2026-10-10
- Область: `internal/app/bot`, `internal/app/delivery`, `.claude/rules/telegram.md`

## Контекст
Правило Telegram требует все исходящие через `messages_outbox`: это защищает от дублей при повторе раунда. Но ответ на `/ping`, `/help` или ошибку ввода не связан с раундом, а outbox-воркер появится только в пункте плана 09.

## Варианты
| Вариант | За | Против |
|---|---|---|
| Всё через outbox | единый путь, повторы без дублей | задержка ответа, воркер нужен с первого дня, лишняя строка в БД на каждый `/ping` |
| Ответы на команды синхронно, игровые тексты через outbox | мгновенный ответ, простой код команд | два пути отправки |

## Решение
Ответы на команды (`/ping`, `/help`, ошибки ввода, подтверждения) отправляются синхронно из `app/bot` через `Sender`. Тексты раунда (хроника, приватные итоги, системные уведомления игры) пишутся в `messages_outbox` в транзакции фиксации и отправляются воркером `app/delivery`. Потеря синхронного ответа при сбое сети допустима: пользователь повторит команду.

## Последствия
`.claude/rules/telegram.md`: формулировка про outbox уточнена. `app/bot.Sender` — узкий интерфейс отправки текста.
