# ADR-0025: Скрытые соседи, разведка `/scout` и переход только текстом

- Статус: принято
- Дата: 2026-10-13
- Область: `internal/model`, `internal/service/{engine,narrator,interpreter}`, `internal/app/{round,bot}`, `internal/adapter/postgres`, `migrations/00029`, промпты `narrator/v7`, `narrator/opening-v4`, `interpreter/v3`; дополняет [ADR-0019](0019-world-generation.md) (сетка и карточки соседей), [ADR-0015](0015-telegram-buttons.md) (кнопки вариантов)

## Контекст
- Ручное тестирование (B36): кнопки «идти на север: Лес» в «Вариантах» загромождают чат, а список выходов в хронике раскрывает всю карту вокруг. Руководитель хочет, чтобы игрок сам писал, куда идёт (направление или название), а соседей узнавал командой «разведка»; не все соседи видны сразу — что видно, решает модель; скрытый сосед выглядит издалека («дым из леса») либо «неизведанная территория».
- Карточки соседей создаёт рассказчик (в раунде и при завязке); интерпретатор только сопоставляет текст игрока с выходами. Выходы по направлениям считает код (ADR-0019). Проходимость границ — пункт 36 плана, отдельно.

## Варианты
| Вариант | За | Против |
|---|---|---|
| Видимость в карточке соседа: у клетки `hidden` и `distant_view`, задаёт модель при создании карточки, снимается при входе | один источник (рассказчик), без нового вызова; интерпретатор и `/scout` читают флаг | скрытый сосед по имени недостижим: игрок пишет направление или описание вида |
| Отдельная таблица видимости по направлениям (как границы пункта 36) | общая форма с проходимостью | ранняя схема под неготовый пункт; видимость — свойство клетки, не ребра |
| Все соседи видны, убрать только кнопки | минимум правок | не отвечает замечанию: карта раскрыта списком выходов |
| Переходы: оставить в тексте «Вариантов», убрать только кнопки | игрок видит выходы | список выходов и есть раскрытие карты; `/scout` даёт то же по запросу |

## Решение
- Клетка получает `hidden` (bool, по умолчанию `false`) и `distant_view` (текст, пусто → «неизведанная территория»). Значения задаёт рассказчик в карточке соседа (`world.neighbors[].visible`, `distant_view`; завязка — то же в `neighbors`); код принимает `distant_view` только у скрытого соседа, обрезает до лимита карточки; шаблонный сосед «Неизведанные земли» виден. Клетка становится видимой при первом входе персонажа (`character_moved` → `hidden = false`); открытие издалека иным способом (осмотр, испытание) — вне этого решения, вопрос геймдизайну.
- Что видно о скрытом соседе — `Glimpse`: «неизведанная территория» или «неизведанная территория (дым над лесом)»; так подписывается выход (`Exit.Title`: «на север: неизведанная территория (дым над лесом)») для игрока, интерпретатора и движка. Переход в скрытую клетку возможен по направлению или по описанию вида (интерпретатор сопоставляет «иду на дым» с подписью); имя скрытого соседа игроку и интерпретатору не передаётся и в цели не сопоставляется (`ExitTo`, `matches`), чтобы знание имени не утекало.
- Рассказчик получает выход скрытого соседа как `hidden: true` + `distant_view` без имени и карточки (`narrator/v7`): описывает только вид издалека. При создании карточек модель решает видимость сама (ориентир — тип местности и рельеф, примерно половина соседей скрыта).
- Переходы исключены из «Вариантов» целиком: `narrator.Options` больше не возвращает `Move`, кнопок направлений нет, в тексте «Вариантов» только подходы объектов; подсказка «куда можно пойти — /scout» в личных сообщениях раунда. Ссылка кнопки `#раунд:локация:move:N` устарела и даёт «вариант недоступен».
- Команда `/scout` (одно слово, личка и группа, без аргументов): клетка персонажа и четыре направления — видимый сосед с именем (у карточки — её предложение), скрытый — вид издалека или «неизведанная территория», направление без клетки — «неизведанная территория»; вид преграды непроходимых границ добавит пункт 36. В личке — кнопка «Разведка» reply-клавиатуры (шестая, в пределах лимита ADR-0021); в меню группы для всех — рядом с `/status` и `/act`.
- Миграция `00029`: столбцы `locations.hidden`, `locations.distant_view`; существующие клетки видимы. Снимок раунда: `hidden`, `distant_view` с `omitempty` — старые снимки читаются как видимые.

## Последствия
- `model.Location.Hidden`, `DistantView`, `SnapshotLocation.Hidden`, `DistantView`, `Glimpse`, `UnknownTerritory`; `Exit.Title` и `ExitTo` учитывают скрытость; `engine.Apply` снимает `hidden` при входе и читает поля из `cell_generated`; снимок `app/round.snapshot` и `applyWorld`/`startPackage` переносят поля; `postgres` и `fake` хранят их.
- `narrator`: `GeneratedNeighbor.Hidden`, `DistantView`; `rawNeighbor`/`openingNeighbor` с `visible`, `distant_view` в схемах; `sceneExit` со скрытым видом; `Options` без переходов (`Option.Move`, `MoveObject` удалены); промпты `narrator/v7`, `narrator/opening-v4`. `interpreter`: промпт `interpreter/v3` (переход по направлению, имени видимого соседа или виду издалека), `exitsList` по `Glimpse`.
- `app/round`: `ScoutText`, `ErrNoLocation`; подсказки `/scout` в личных сообщениях раунда и в приветствии; `app/bot`: `cmd_scout.go`, реестр, кнопка «Разведка».
