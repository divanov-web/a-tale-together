# ADR-0038: Подсказка рассказчика по просьбе фракции

- Статус: принято
- Дата: 2026-10-17
- Область: `migrations/00040`, `internal/model`, `internal/adapter/postgres`, `internal/app/round`, `internal/app/bot`, `internal/service/narrator`, `assets/prompts/narrator/v14.md`

## Контекст
Игрок, который не знает, что делать, просит подсказку (`/hint`, кнопка «Подсказка» в личке; пункт 35, B35). Подсказка публичная — её даёт рассказчик в хронике ближайшего раунда для всей фракции (решение руководителя 2026-10-13); перезарядка 5 раундов на фракцию уже заведена в `cooldowns` (ADR-0033). Нужно: запомнить просьбу до хроники, передать её рассказчику, проверить выполнение кодом, не по тексту (принцип 2), не раскрыть секреты (принцип 6) и не потерять просьбу при сбое модели (принцип 7).

## Варианты
| Вариант | За | Против |
|---|---|---|
| Подсказку пишет код из контекста квеста (имя клетки этапа) сразу в ответ игроку | без модели, проверяемо | сухой текст вне хроники; приватный этап уходит в личку одному игроку, а решение руководителя — подсказка публичная |
| Флаг у фракции (`factions.hint_round`), фракции в снимке раунда, блок `hints` во входе рассказчика и поле `hints_given` в его ответе | один вызов модели (ADR-0011), подсказка вплетена в сцену, проверка по полю схемы, просьба переживает сбой | новая колонка, новая версия промпта |
| Отдельный вызов модели «подсказка» при `/hint` | ответ сразу | второй вызов на раунд, подсказка вне хроники, контекст собирать второй раз |

## Решение
Второй вариант. `/hint` (личка и группа, по решению руководителя 2026-10-17) при открытом раунде проверяет перезарядку `hint` фракции и флаг: просьба уже есть — «Подсказку уже просили: появится в ближайшей хронике»; перезарядка — «Подсказку уже просили, следующая через N раундов (с раунда M)»; иначе в одной транзакции `factions.hint_round = N` и `SetCooldown(hint, N)`. Заморозка кладёт фракции с флагом в снимок (`RoundSnapshot.Hints`, v6). Рассказчик получает `hints: [{faction, characters}]` (код фракции и никнеймы её присутствующих персонажей) и обязан в их сценах дать намёк, куда двигаться, только из данных входа (ближайший этап `quests[].next`, выходы и приметы сцены, объекты); код фракции возвращает в `hints_given`. Фракция без `hints_given` — замечание для дозапроса наравне с пропущенным событием; после дозапроса — считается не выполненной. Выполненная подсказка: флаг снимается, перезарядка переписывается раундом хроники, событие `hint_given` (public). Невыполненная (сбой модели, шаблонная хроника, пропущенный раунд): флаг остаётся, просьба уходит в следующую хронику; перезарядка не сгорает — она сдвинется на раунд выдачи.
