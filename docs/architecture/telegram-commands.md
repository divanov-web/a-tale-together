# Команды Telegram

Черновик MVP из концепта §9. Реестр обновляется вместе с `internal/app/bot`.

## Принципы

- Всё управление игрой — слеш-команды `/name [аргументы]` (решение руководителя). Кнопки и inline-клавиатуры Telegram отложены на поздний этап (пункт 14, после закрытой альфы); до этого никакой логики через callback-кнопки.
- У каждой команды объявлены контексты: группа, личка или оба; наборы в группе и личке пересекаются не полностью. Команда в чужом контексте получает подсказку, где её использовать.
- Меню команд Telegram (`setMyCommands`) регистрируется отдельно для личек и групп по этому реестру.
- Многошаговые сценарии (настройка игры, создание персонажа) — диалог в личке: бот задаёт вопрос, игрок отвечает текстом; каждый параметр также доступен отдельной командой (`/game_set <параметр> <значение>`).

| Контекст | Команда | Назначение | Статус |
|---|---|---|---|
| Любой | `/ping` | проверка: версия сборки, окружение, время сервера | готово |
| Группа | `/chat` | владелец, модераторы, статус бота, текущая игра | план |
| Группа, владелец | `/chat_mod add\|remove @user` | назначить или снять модератора чата | план |
| Группа, владелец | `/chat_owner @user` | передать владение чатом | план |
| Группа, владелец или модератор | `/game_create` | создать мир, запустить мастер настройки в личке админа | план |
| Группа | `/game_start` | начать кампанию, опубликовать стартовую сцену | план |
| Группа | `/game_pause` | пауза / возобновление | план |
| Группа | `/game_status` | состояние игры, тип, сезон, следующий раунд | план |
| Группа, администратор игры | `/game_finish` | завершить игру: финальная хроника, статус `finished` | план |
| Группа, администратор игры | `/season_new [название]` | сериал: закрыть сезон, открыть следующий стартовой сценой | план |
| Личка | `/start [deep link]` | открыть приватный канал (`users.started_at`), с кодом — присоединиться к игре | план |
| Личка | `/help` | команды по контексту | план |
| Личка | `/me` | кто я, открыта ли личка, чаты и игры | план |
| Личка | `/join` | присоединиться к игре по коду | план |
| Личка, администратор игры | `/game_set <параметр> <значение>` | задать параметр игры вне диалога настройки | план |
| Личка | `/character` | характеристики и состояние | план |
| Личка | `/act <текст>` | подать или заменить заявку текущего раунда | план |
| Личка | `/journal [full]` | последние приватные итоги; `full` — с числами проверок, где уровень баланса их скрывает | план |
| Личка | `/games` | выбрать активную игру при нескольких | план |
| Личка, владелец бота | `/llm`, `/llm use <profile> [game_id]`, `/llm add ...` | профили LLM: показать, переключить для бота или игры, добавить | план |

## Ограничения платформы

- Бот не пишет пользователю первым; доступ к игре после `/start`.
- Добавление и удаление бота в группе приходит как `my_chat_member`; команды в группе доступны и при включённом privacy mode.
- Лимит длины сообщения; длинные тексты делятся.
- Кнопки Telegram не используются до пункта 14; при их появлении каждая кнопка дублирует существующую команду.
