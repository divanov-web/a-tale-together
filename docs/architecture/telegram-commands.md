# Команды Telegram

Реестр команд MVP; обновляется вместе с `internal/app/bot`.

## Принципы

- Всё управление игрой — слеш-команды `/name [аргументы]` (решение руководителя). Кнопки и inline-клавиатуры Telegram отложены на поздний этап (пункт 14, после закрытой альфы); до этого никакой логики через callback-кнопки.
- У каждой команды объявлены контексты: группа, личка или оба; наборы в группе и личке пересекаются не полностью. Команда в чужом контексте получает подсказку, где её использовать.
- Меню команд Telegram (`setMyCommands`) регистрируется отдельно для личек и групп по этому реестру.
- Многошаговые сценарии (настройка игры, создание персонажа) — диалог в личке: бот задаёт вопрос, игрок отвечает текстом; состояние в таблице `dialogs` (ADR-0008); ответ «-» оставляет значение по умолчанию; каждый параметр также доступен отдельной командой (`/game_set <параметр> <значение>`).
- Лимиты входящих: 20 сообщений в минуту на пользователя, текст до 1000 символов. В группе неизвестные команды игнорируются (команды других ботов), в личке — подсказка `/help`.

| Контекст | Команда | Назначение | Статус |
|---|---|---|---|
| Любой | `/ping` | проверка: версия сборки, окружение, время сервера | готово |
| Группа | `/chat` | владелец, модераторы, статус бота, текущая игра | готово |
| Группа, владелец | `/chat_mod add\|remove @user` | назначить или снять модератора чата (пользователь должен быть известен боту) | готово |
| Группа, владелец | `/chat_owner @user` | передать владение чатом | готово |
| Группа, владелец или модератор | `/game_create` | создать мир (черновик, сезон 1, фракции жанра), запустить диалог настройки в личке админа или дать ссылку `start=setup_<код>` | готово |
| Группа | `/game_start` | начать кампанию, опубликовать стартовую сцену | план |
| Группа | `/game_pause` | пауза / возобновление | план |
| Оба | `/status` | состояние игры: формат, режим, сезон, настройки, кворум, участники, персонажи, фракции, следующий раунд или причина простоя (не запущена, пауза, пропуск раунда без кворума — пункт 05); в личке — текущая игра | готово; причина пропуска — план |
| Группа, администратор игры | `/game_finish` | завершить игру: финальная хроника, статус `finished` | план |
| Группа, администратор игры | `/season_new [название]` | сериал: закрыть сезон, открыть следующий стартовой сценой | план |
| Личка | `/start [deep link]` | открыть приватный канал (`users.started_at`); `join_<код>` — войти в игру и создать персонажа, `setup_<код>` — настройка игры админом | готово |
| Оба | `/help` | команды по контексту | готово |
| Личка | `/me` | кто я, открыта ли личка, чаты с правами, игры и персонажи | готово |
| Личка | `/join <код>` | присоединиться к игре по коду; затем диалог создания персонажа (фракция → никнейм → архетип → очки → описания) | готово |
| Личка | `/party`, `/party_create <имя>`, `/party_join <имя>`, `/party_leave` | группа персонажа для общей истории (на старте до 3 групп) | план |
| Личка, администратор игры | `/game_set <параметр> <значение>` | параметр текущей игры: `title genre round_minutes timezone play_window ends_at max_rounds max_players max_locations min_answers faction_good/evil/neutral`; без аргументов — список | готово |
| Личка | `/character` | карточка: никнейм, архетип, фракция, статус, HP, характеристики, навыки, инвентарь, описания | готово |
| Личка | `/character_create` | создать персонажа в текущей игре, если его нет | готово |
| Личка | `/cancel` | прервать диалог настройки или создания персонажа | готово |
| Личка | `/character_bio <текст>`, `/character_secret <текст>` | открытое и скрытое описание до 100 символов | готово |
| Личка | `/act <текст>` | подать или заменить заявку текущего раунда | план |
| Личка | `/journal [full]` | последние приватные итоги; `full` — с числами проверок, где режим игры их скрывает | план |
| Личка | `/goal`, `/goal_set <текст>`, `/goal_drop` | личная сюжетная цель и её шаги (пункт 17, поздний этап) | план |
| Личка | `/games [номер]` | мои игры; с номером — выбрать текущую (`users.current_game_id`) | готово |
| Личка, владелец бота | `/llm`, `/llm use <profile> [game_id]`, `/llm add ...` | профили LLM: показать, переключить для бота или игры, добавить | план |

## Ограничения платформы

- Бот не пишет пользователю первым; доступ к игре после `/start`.
- Добавление и удаление бота в группе приходит как `my_chat_member`; команды в группе доступны и при включённом privacy mode.
- Лимит длины сообщения; длинные тексты делятся.
- Кнопки Telegram не используются до пункта 14; при их появлении каждая кнопка дублирует существующую команду.
