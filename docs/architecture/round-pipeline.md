# Конвейер раунда

Источник: [раунд](../game/round.md), риски §5 «Возможный конвейер MVP». Исполнитель: `internal/app/round`.

| Шаг | Вход | Выход | Фиксация | Исполнитель |
|---|---|---|---|---|
| 1. Сбор | заявки до дедлайна | `rounds.status=frozen`, `snapshot`, `seed` | транзакция | планировщик |
| 2. Интерпретация | заявки снимка | намерения JSON; типовые команды без LLM | `resolved_actions.intent`, `llm_runs` | интерпретатор |
| 3. Разрешение | снимок + намерения + seed | статусы заявок, проверки, события | в памяти, детерминированно | движок |
| 4. Сюжетные предложения (позже) | рассчитанные итоги | события следующего раунда после валидации | | рассказчик + движок |
| 5. Фиксация | события, статусы | `world_events`, `resolved_actions`, состояние, `rounds.status=resolved` | одна транзакция | сценарий раунда |
| 6. Описание | события по видимости | приватные итоги, хроника | `messages_outbox` в той же или следующей транзакции, `rounds.status=published` | рассказчик |
| 7. Доставка | outbox | сообщения Telegram, `telegram_message_id` | воркер доставки, повторы | delivery |

## Правила

- Один раунд одного мира в один момент: блокировка строки `rounds` (`FOR UPDATE SKIP LOCKED`), запрет перекрытия.
- Повтор любого шага после сбоя безопасен: шаги 2 и 6 проверяют наличие результата, шаг 3 воспроизводится по снимку и seed.
- Сбой LLM на шаге 2: ограниченные повторы → статус `ambiguous` и шаблонный ответ игроку. Сбой на шаге 6: шаблонные приватные итоги, хроника откладывается, мир не откатывается.
- Поздние заявки после заморозки относятся к следующему раунду.
- Пауза останавливает планировщик; пропущенные раунды не догоняются.
- Измеряется: длительность каждого шага, токены и стоимость, число `ambiguous`, пропущенные ID.
