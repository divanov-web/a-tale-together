# 28. Квесты и цели фракций

- Статус: план
- Этап концепта: 3
- Зависит от: 27, [динамический мир](../../game/world.md); пункт [17](17-story-goals.md) (личные цели) остаётся независимым

## Цель
Мир сам порождает небольшое число линий с проверяемым прогрессом: цель у каждой фракции, сюжетные и побочные квесты с лимитом 2+2, выдача по счётчику открытых клеток, этапы привязываются к клеткам лениво, завершение считает код.

## Критерий готовности
При старте есть цель каждой фракции и один сюжетный квест; дополнительные квесты появляются после суммарно 1, 3 и 7 новых клеток; при четырёх активных выдачи нет; после завершения одного квеста следующий требует четыре новые клетки; этап материализуется в клетке входа после закрытия предыдущего; закрытие этапа и награда — только событиями, без дубля при повторе раунда; при сбое модели сюжетный квест создаётся из шаблона.
