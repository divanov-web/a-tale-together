# 28. Квесты и цели фракций

- Статус: план
- Этап концепта: 3
- Зависит от: 27, [динамический мир](../../game/world.md); пункт [17](17-story-goals.md) (личные цели) остаётся независимым

## Цель
Мир сам порождает небольшое число линий с проверяемым прогрессом: цель у каждой фракции, у фракции сюжетные и побочные квесты с лимитом 2+1, выдача по счётчику клеток, открытых фракцией, этапы привязываются к клеткам лениво, завершение считает код.

## Критерий готовности
При старте у каждой фракции есть цель и один сюжетный квест; квесты фракции появляются после суммарно 1 и 3 клеток, открытых её персонажами; при трёх активных у фракции выдачи нет; после завершения одного из трёх следующий требует две новые клетки; открытие одной клетки персонажами двух фракций засчитывается каждой по разу; счётчики фракций независимы; этап материализуется в клетке входа после закрытия предыдущего; закрытие этапа и награда — только событиями, без дубля при повторе раунда; при сбое модели сюжетный квест создаётся из шаблона.
