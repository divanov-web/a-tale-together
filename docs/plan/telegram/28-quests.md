# 28. Квесты и цели фракций

- Статус: готово (2026-10-12, [ADR-0020](../../decisions/0020-quests.md), миграция `00024`, промпты `narrator/v5`, `opening-v3`)
- Этап концепта: 3
- Зависит от: 27, [динамический мир](../../game/world.md); пункт [17](17-story-goals.md) (личные цели) остаётся независимым

## Цель
Мир сам порождает небольшое число линий с проверяемым прогрессом: цель у каждой фракции, у фракции сюжетные и побочные квесты с лимитом 2+1, выдача по счётчику клеток, открытых фракцией, этапы привязываются к клеткам лениво, завершение считает код.

## Критерий готовности
При старте у каждой фракции есть цель и один сюжетный квест; квесты фракции появляются после суммарно 1 и 5 клеток, открытых её персонажами; при трёх активных у фракции выдачи нет; после завершения одного из трёх следующий требует четыре новые клетки; открытие одной клетки персонажами двух фракций засчитывается каждой по разу; счётчики фракций независимы; этап материализуется в клетке входа после закрытия предыдущего; закрытие этапа и награда — только событиями, без дубля при повторе раунда; при сбое модели сюжетный квест создаётся из шаблона. Проверено: `TestBegin_QuestStart`, `TestScenario_S17_Lifecycle`, `TestSixSteps_North` (побочный после 1 клетки, сюжетный после ещё 4), `TestQuestPlan_*`, `TestQuestCheck_Conditions`, `TestNarrate_QuestPackage`, `TestOpening_Quests`, `TestQuests_Card`.

## Открытые вопросы
G17 (допущение: при старте по одному сюжетному на фракцию). Решено в реализации: закрытие этапа счётчик не трогает, завершение квеста обнуляет; выдача списывает порог (лишние открытия раунда переходят в следующий интервал); этап `visited` закрывается в раунде входа.
