# 37. Генерация мира: варианты стартового мира при создании игры

- Статус: готово (2026-10-14, [ADR-0028](../../decisions/0028-worldgen.md))
- Этап концепта: 3
- Зависит от: 03 (настройка), 27 (стартовый пакет), 28 (цели фракций), ADR-0024 (работа в тике)

## Цель
Нулевой запрос к модели при создании игры: по описанию жанра получить четыре разных стартовых мира с заголовками, коротко показать их администратору в личке и дать выбрать один кнопкой первым шагом настройки. Поля, которые были прибиты в шаблоне жанра (тон, фракции, стартовая клетка, крючок завязки, цели), берутся из выбранного варианта; шаблон остаётся запасным путём.

## Критерий готовности
После `/create` тик планировщика делает один вызов `worldgen` и присылает администратору четыре варианта с кнопками; выбор кнопкой или `/set scenario <номер>` меняет название мира, фракции и стартовую клетку, следующий шаг — название с предложенным значением; `/set scenario -` возвращает шаблон; при сбое модели три попытки, затем шаблон с сообщением; без модели шаг не показывается; завязка при `/begin` получает тон и крючок варианта, при сбое завязки стартовая сцена — крючок; повтор тика модель второй раз не зовёт.

## Что сделано
Роль `worldgen` и промпт `narrator/worldgen-v1` с примерами формы и требованием разнообразия; `narrator.Worldgen` с проверкой вариантов; `games.world_setups` (миграция `00032`); вызов в тике для игр `setup` (`round.worldgen`), сообщение с кнопками через outbox; параметр `scenario` первым шагом настройки (`game.setScenario`, `bot.scenarioQuestion`); завязка `opening-v5` с `world.premise`; `make eval-narrator EVAL_ARGS="-worldgen"`.

## Проверка
Выполнено: `make test`, `make test-integration`, `make lint`, миграция на `tale` и `tale_test`. Песочница (руководитель): `/create` → в личке «Стартовый мир. Придумываю…», через минуту сообщение с четырьмя кнопками → выбор → «Название мира. Сейчас: <название варианта>» → `/status` показывает фракции варианта → `/begin` даёт завязку по крючку. Живой прогон промпта: `make eval-narrator EVAL_ARGS="-worldgen"` — по решению руководителя (подписка).

## Открытые вопросы
Кнопка «ещё варианты» (повторная генерация по запросу, вход `avoid` готов) и второй жанр — по решению руководителя.
