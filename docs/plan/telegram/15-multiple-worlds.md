# 15. Несколько независимых миров

- Статус: план
- Этап концепта: 5
- Зависит от: 14

## Цель
Любой администратор группы запускает свою кампанию; миры изолированы по данным, лимитам и задачам; шаблоны миров и жанров.

## Критерий готовности
Несколько групп ведут кампании параллельно без взаимного влияния; тесты межмировых утечек проходят; антиспам и лимиты на мир работают.

## Шаги
| № | Шаг | Слой / пакеты | Артефакты | Статус |
|---|---|---|---|---|
| 1 | Тесты межмировых утечек: контекст LLM, выборки, outbox | тесты | | план |
| 2 | Справедливое планирование раундов между мирами; глобальная очередь LLM | `app/scheduler`, `app/round` | | план |
| 3 | Шаблоны миров и жанров; версии правил на мир | `service/rules`, `app/game` | | план |
| 4 | Антиспам и лимиты на мир и пользователя | `app/bot` | | план |
| 5 | Администрирование: список миров, стоимость, остановка мира | `app/bot` (владелец бота) | | план |
| 6 | Аналитика по мирам | docs, таблицы | | план |

## Проверка
Две группы параллельно на прод-боте; отчёт изоляции.

## Открытые вопросы
Тарифы и бюджеты только при реальной необходимости (этап 5 roadmap).
