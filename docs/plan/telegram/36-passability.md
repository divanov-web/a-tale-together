# 36. Проходимость клеток и подземелья

- Статус: план
- Этап концепта: 3
- Зависит от: 27 (сетка), B36 (видимость клеток, `/scout`)
- Было: B37 в [бэклоге](../backlog.md) (2026-10-13)

## Цель
Мир остаётся плоским. Подземелье — область клеток с местностью вроде «катакомбы» или «пещера», вход в неё — соседняя клетка. В такую область можно попасть только с одной стороны; с других она выглядит как непроходимые горы, чаща и т. п.

## Критерий готовности
Для каждого направления между соседними клетками хранится признак «можно пройти» и вид преграды; движок отклоняет `move` через непроходимую границу кодом (принцип 1); интерпретатор видит непроходимые направления в контексте и по правилу «спуск или подъём без подходящего соседа → испытание на месте, не `move`»; рассказчик при достройке задаёт границы и местность; `/scout` показывает вид преграды.
