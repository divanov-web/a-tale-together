# 08. Интерпретатор LLM

- Статус: готово (шаг 8 отложен до решения T1)
- Этап концепта: 2
- Зависит от: 06 (профили, `app/llm.Complete`, `claude-cli`), 07 (намерение, движок, снимок v2)

## Цель
Свободный текст заявки превращается в намерение по каталогу одним вызовом LLM на раунд после дедлайна; параметры свободного испытания (характеристика, навык, риск, эффекты обеих ветвей) назначает модель, сложность и бросок — движок; непонятная заявка получает безопасное толкование (решения руководителя 2026-10-10, G3).

## Критерий готовности
Eval-набор проходит на ≥ 90 %; попытки инструкций в тексте игрока не исполняются; невалидный ответ модели даёт безопасное толкование, а не падение раунда; раунд с 20 заявками разбирается одним вызовом в пределах таймаута; каждый вызов записан в `llm_runs` с `round_id`.

## Проверка
`make eval-interpreter`; раунд в песочнице со свободными заявками и живой моделью; `/replay` после раунда; счётчики токенов и `round_id` в `llm_runs`.

## Открытые вопросы
G8 (объём контекста). Объём допустимых эффектов свободного испытания: факт, переход и состояние персонажа, урон ≤ 2 разрешены, изменение объектов только через подходы из данных локации (допущение до ответа руководителя). Две транзакции вместо вызова модели под блокировкой игры — при реальной нагрузке (ADR-0010).
