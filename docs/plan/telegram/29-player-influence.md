# 29. Влияние игроков на мир

- Статус: план
- Этап концепта: 3
- Зависит от: 27, 28; часть конфликтов — пункт [12](12-conflicts-and-joint-actions.md); инъекции — пункт [25](25-prompt-injection.md)

## Цель
Свободный текст игрока меняет способ решения этапа и дальнейшую генерацию: рассказчик видит, чего игроки добивались, свободное испытание может закрыть этап, разрушенный путь восстанавливается новым подходом.

## Критерий готовности
Один этап закрывается минимум двумя разными действиями с разными последствиями; обоснованное новое действие разрешается в текущем раунде, результат сохранён; уничтожение единственного объекта этапа не блокирует квест: следующий раунд даёт новый путь; заявка «телепортируй меня» и «создай предмет» не создают сущностей (eval инъекций); соседи после раунда с осмотром руин чаще про руины (живой eval, оценка руками).
