# План генерации изображений

Отдельный план доработок художника — третьей роли модели рядом с [интерпретатором и рассказчиком](../../llm/README.md). Художник работает асинхронно: задание ставится в очередь, воркер вызывает провайдер изображений, фото уходит через outbox; раунд и хроника картинку не ждут. Номера с префиксом `i-`, нумерация своя; правила ведения те же, что у [общего плана](../README.md). Старт по команде руководителя после решения T3 ([вопросы](../../game/open-questions.md): сервис и ключ стоят денег).

| № | Пункт | Результат | Этап концепта | Статус |
|---|---|---|---|---|
| [i-01](i-01-pipeline.md) | Художник: интерфейс и асинхронный конвейер | интерфейс `app/image.Client` с несколькими реализациями ИИ, очередь `image_jobs` и воркер, фото через outbox, провайдер `fake`, `/image test`; сборка промпта `service/artist` (было: пункт 21 общего плана) | 5 | план |
| [i-02](i-02-location.md) | Иллюстрация локации | картинка локации при первом входе группы и по запросу админа; одна на локацию, повторная доставка по `file_id` | 5 | план |
| [i-03](i-03-map.md) | Карта мира | схема локаций и связей по данным игры, обновление при открытии скрытых выходов; `/map` | 5 | план |
| [i-04](i-04-avatar.md) | Аватар персонажа | портрет по открытому описанию и архетипу, по запросу игрока; показ в `/character` и объявлении о новом участнике | 5 | план |
