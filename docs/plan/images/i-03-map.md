# i-03. Карта мира

- Статус: план
- Этап концепта: 5
- Зависит от: i-01, i-02

## Цель
Схема локаций и видимых связей мира как картинка по данным игры; обновляется, когда открывается скрытый выход.

## Критерий готовности
`/map` в группе или личке отдаёт актуальную карту: только открытые локации и выходы; после события `link_revealed` следующий `/map` ставит новое задание; без изменений — повтор по `file_id`.

## Шаги
| № | Шаг | Слой / пакеты | Артефакты | Статус |
|---|---|---|---|---|
| 1 | Решение: рисовать карту кодом (граф локаций, SVG → PNG без ИИ) или художником по описанию; ADR | docs | ADR | план |
| 2 | Ключ идемпотентности: хеш открытых локаций и связей; устаревшая карта остаётся до готовности новой | `app/image` | тест | план |
| 3 | Команда `/map`; показ карты в завязке (`/begin`) при включённых изображениях | `app/bot`, `app/round` | | план |
| 4 | Документы и `guide/` | docs | | план |

## Проверка
Песочница: `/map` до и после открытия скрытого выхода — два разных задания; повтор `/map` без изменений — одно.

## Открытые вопросы
Нужна ли карта вообще при 3–4 локациях MVP; не раскрывает ли карта группам чужие локации (видимость по локации группы или вся карта).
