# i-04. Аватар персонажа

- Статус: план
- Этап концепта: 5
- Зависит от: i-01, T3

## Цель
Портрет персонажа по открытому описанию, полу и архетипу в тоне мира; по запросу игрока, показывается в карточке и при объявлении о новом участнике.

## Критерий готовности
`/avatar` в личке ставит задание `avatar` для персонажа; фото приходит игроку, сохраняется у персонажа; `/character` и объявление «К игре присоединился …» отправляются с фото; повтор `/avatar` ограничен лимитом на персонажа; `secret_bio` в промпт не попадает.

## Шаги
| № | Шаг | Слой / пакеты | Артефакты | Статус |
|---|---|---|---|---|
| 1 | Поле `characters.avatar_file_id`; задание `avatar` с ключом по персонажу и хешу `public_bio` | `model`, `migrations/`, `app/image` | тест | план |
| 2 | Промпт художника: никнейм не рисуется текстом, пол, архетип, открытое описание, тон мира; секрет исключён (принцип 6); текст игрока — данные (принцип 3) | `service/artist` | тест на утечку секрета | план |
| 3 | Команда `/avatar` (личка), лимит перегенераций в сутки; показ в `/character` и объявлении о новом участнике (B25) | `app/bot` | | план |
| 4 | Документы, `guide/character/` | docs, guide | | план |

## Проверка
Песочница с `fake`: `/avatar` → заглушка в личке; `/character` → с фото; смена `/bio` → новое задание по команде, не автоматически.

## Открытые вопросы
Модерация описаний перед отправкой провайдеру (ошибка модерации провайдера — окончательная, i-01 шаг 6); автоматическая генерация при создании персонажа или только по запросу.
