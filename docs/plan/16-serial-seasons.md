# 16. Сезоны сериала

- Статус: план
- Этап концепта: 3
- Зависит от: 10, [форматы игр](../game/game-formats.md)

## Цель
Игра типа «сериал» делится на сезоны: смена сезона закрывает историю, сохраняет персонажей и открывает новую стартовую сцену.

## Критерий готовности
`/season` в сериале закрывает сезон финальной хроникой, создаёт следующий, персонажи сохраняют характеристики, навыки и опыт, инвентарь сброшен до стартового, локации и контекст LLM начинаются заново; `/journal` показывает хронику прошлых сезонов.

## Шаги
| № | Шаг | Слой / пакеты | Артефакты | Статус |
|---|---|---|---|---|
| 1 | Сценарий смены сезона по решению G12 | геймдизайн | `docs/game/scenarios.md` | план |
| 2 | `/season`: закрытие сезона одной транзакцией, финальная хроника, новый сезон, события «сезон закрыт / открыт» | `app/game`, `app/round` | тесты | план |
| 3 | Персонаж между сезонами: HP восстановлен, состояния сняты, инвентарь сброшен до стартового, характеристики и опыт сохранены | `service/rules`, `service/engine` | тесты | план |
| 4 | Сводка прошлого сезона для контекста LLM; стартовая сцена нового сезона | `service/narrator`, промпты | | план |
| 5 | `/journal` и `/status` с сезонами | `app/bot` | шаблоны | план |

## Проверка
Два сезона по 3 раунда в песочнице; сверка персонажей до и после смены сезона.
