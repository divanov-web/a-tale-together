# 03. Игра и участники

- Статус: план
- Этап концепта: 1
- Зависит от: 02

## Цель
Группа ↔ игра, настройки мира, регистрация игроков через личку, статус игры.

## Критерий готовности
Админ создаёт игру в группе и настраивает её в личке; 5 пользователей присоединяются по deep link; `/game_status` показывает участников и настройки; второй `/game_create` в той же группе отклоняется.

## Шаги
| № | Шаг | Слой / пакеты | Артефакты | Статус |
|---|---|---|---|---|
| 1 | Таблицы `games`, `game_members` по модели данных; статусы игры `draft/active/paused/finished` | `migrations/`, `model` | | план |
| 2 | `/game_create` в группе: проверка прав админа чата, создание `draft`, ссылка в личку для настройки | `app/game`, `app/bot` | | план |
| 3 | Мастер настройки в личке: название, жанр, тон, лимит игроков, длительность раунда, окна, часовой пояс, лимит локаций; шаги с кнопками или командами | `app/bot`, `app/game` | `settings jsonb` | план |
| 4 | Deep link `t.me/<bot>?start=join_<code>`: `/start` с кодом → `game_members`, проверка готовности приватного канала | `app/game` | | план |
| 5 | `/join <code>` как запасной вход; `/games` и выбор активной игры | `app/game`, `app/bot` | | план |
| 6 | `/game_status` в группе: статус, участники, настройки, следующий раунд (пока «не запущен») | `app/game` | шаблон | план |
| 7 | Права: только админ игры меняет настройки и статус; безопасные параметры меняются между раундами | `app/game` | тесты | план |
| 8 | `/me` показывает игры и персонажей пользователя | `app/bot` | | план |

## Проверка
Сценарий «5 тестовых пользователей» руками в песочнице; юнит-тесты сценариев с фейковым Store.

## Открытые вопросы
G1 (несколько миров на пользователя). Формат мастера настройки: команды или inline-кнопки.
