Здесь только очередь: статусы `план | в работе`; закрытые пункты — в [`telegram-done.md`](telegram-done.md). Этапы концепта: [roadmap](../roadmap.md).

## Правила ведения плана

- Пункт в работе получает статус и дату начала; закрытие — по критерию готовности из файла пункта.
- Строка со статусом `готово` переезжает в [`telegram-done.md`](telegram-done.md) (та же таблица; в статусе дата закрытия и коммит, закрывший пункт; отложенный шаг — пометка в статусе, не блокер); порядок выполнения сохраняется, файл пункта остаётся в `telegram/` и ссылки на него не меняются (по аналогии с [`backlog.md`](backlog.md) → [`backlog-done.md`](backlog-done.md); решение руководителя 2026-10-15, B44).
- Новые требования добавляются шагом в файл пункта; новый крупный пункт — строкой здесь, с файлом по шаблону [`_template.md`](_template.md).
- Файл пункта: цель, критерий готовности, зависимости, шаги (таблица), проверка, открытые вопросы. Шаги не детализируются глубже, чем нужно для ближайшей работы.
- Номер пункта постоянен (на него ссылаются документы); порядок выполнения задаёт таблица, вставка между пунктами получает суффикс (`09а`).
- Большой план (бот, изображения, сайт) — файл `docs/plan/<план>.md` с таблицей пунктов и подпапка `docs/plan/<план>/` с файлами пунктов; префиксы номеров: бот без префикса, изображения `i-`, сайт `w-`; при выделении пункта в другой план номер остаётся в файле строкой «Было».
- Замечания ручного тестирования и баги вне текущего пункта — в [`backlog.md`](backlog.md) (только очередь); выполняются по команде руководителя между пунктами или в ближайшем подходящем пункте; строка со статусом `готово` переезжает в [`backlog-done.md`](backlog-done.md).
- Пункты 27–31 (динамический мир, [правила](../game/world.md)) — переделка рассказчика по решению руководителя 2026-10-12; 27 и 28 выполнены по команде руководителя ([ADR-0019](../decisions/0019-world-generation.md), [ADR-0020](../decisions/0020-quests.md)), остальные — по команде; пункт 13 сужен до того, что в них не вошло.
- Пункт 11 (прод-бот) выполняется после закрытой альфы (решение руководителя 2026-10-10): альфа идёт на тестовом боте; пункт можно сдвинуть раньше, если прод-стенд понадобится для проверки инфраструктуры.
