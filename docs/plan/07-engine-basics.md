# 07. Движок: базовые механики

- Статус: план
- Этап концепта: 0, 2
- Зависит от: `docs/game/rules.md`, `actions.md`, `scenarios.md` (этап 0 на бумаге); код — после 06

## Цель
Детерминированное разрешение простых действий без конфликтов: проверки, события, видимость, применение к состоянию. Сначала на бумаге, затем тестами, затем кодом.

## Критерий готовности
Сценарии S06 (воспроизведение) и S07 (никто не потерян) проходят тестами; `move`, `explore`, `interact`, `wait` разрешаются; состояние после раунда равно свёртке событий.

## Проверка
`make test` с тестами сценариев; ручной раунд в песочнице с типовыми командами; сравнение состояния и журнала.

## Открытые вопросы
Формат `Snapshot` (полный или ссылочный). Сценарий одного действия на трёх уровнях баланса.
