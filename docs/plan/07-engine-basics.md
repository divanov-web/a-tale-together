# 07. Движок: базовые механики

- Статус: готово (2026-10-10)
- Этап концепта: 0, 2
- Зависит от: `docs/game/checks.md`, `character.md`, `actions.md`, `scenarios.md`; код — после 06

## Цель
Детерминированное разрешение простых действий без конфликтов: проверки, события, видимость, применение к состоянию. Сначала на бумаге, затем тестами, затем кодом.

## Критерий готовности
Сценарии S06 (воспроизведение) и S07 (никто не потерян) проходят тестами; `move`, `explore`, `interact`, `wait` разрешаются; состояние после раунда равно свёртке событий.

## Открытые вопросы
Формат снимка — полный (решено). Сценарий одного действия в трёх режимах — покрыт S12 для двух режимов; «баланс» без чисел в итоге. Помощь пока без ограничения группой (группы — пункт 04 шаг 4а / пункт 12).
