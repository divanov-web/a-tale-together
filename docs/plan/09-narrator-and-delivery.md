# 09. Рассказчик и доставка

- Статус: план
- Этап концепта: 2
- Зависит от: 07, 08

## Цель
Из разрешённых событий формируются хроника в группу и приватные итоги в личку; доставка надёжна через outbox.

## Критерий готовности
После раунда каждый игрок получает приватный итог с упоминанием его заявки; хроника не содержит приватных фактов; сбой Telegram при отправке не теряет и не дублирует сообщения; `/journal` показывает последние итоги.

## Проверка
Раунд в песочнице с 3–5 персонажами; отключение сети во время доставки; проверка дублей по `telegram_message_id`.

## Открытые вопросы
G5 (сюжетные повороты ИИ); объём хроники на раунд.
