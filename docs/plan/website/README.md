# План: сайт игры (второй проект)

Большая стори с собственной подпапкой плана. Статус: замысел, старт не скоро, решение руководителя 2026-10-12. Отдельное приложение рядом с ботом; пункты (префикс `w-`), стек и схема появятся при старте.

## Назначение

| Часть | Содержание | Источник данных |
|---|---|---|
| Вики | Правила, персонаж, испытания, фракции, группы, каталог действий; основа — [руководство игрока](../../../guide/README.md) и [документы игры](../../game/README.md) | БД сайта |
| Информация из игры | Миры, персонажи, хроники раундов, статистика игр и игроков | БД игры (`tale`), только чтение |

## Границы

| Решение | Значение |
|---|---|
| Приложение | Второе, независимое от бота; свой процесс и выкат на том же сервере, что и прод-бот ([пункт 11](../11-prod-bot-deploy.md)) |
| Хранилище | Вероятно вторая БД для контента сайта (вики, пользователи сайта); подключение к БД игры для статистики — только чтение |
| Изоляция | Бот и его схема сайтом не меняются; сайт не пишет в БД игры |
| Приватность | Наружу только публичное: приватные события, секреты персонажей и личные итоги не публикуются (принцип приватности: у каждого события видимость, [модель данных](../../architecture/data-model.md)) |

## Открытые вопросы (к старту)

- Стек сайта: Go или другой; статика или серверный рендер.
- Доступ к БД игры: прямое подключение с ролью только на чтение, реплика или API бота (отложенные API-адаптеры [пункта 08](../08-interpreter.md)).
- Авторизация игроков на сайте через Telegram (Login Widget) и показ приватных данных своему владельцу.
- Нужен ли домен и TLS; связь с webhook прод-бота ([пункт 11](../11-prod-bot-deploy.md)).
