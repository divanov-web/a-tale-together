# 08. Интерпретатор LLM

- Статус: план
- Этап концепта: 2
- Зависит от: 06 (интерфейс, реестр, профили, `claude-cli`), 07

## Цель
Свободный текст заявки превращается в намерение по каталогу через LLM с валидацией; неоднозначность возвращается игроку.

## Критерий готовности
Eval-набор из сценариев проходит на ≥ 90 %; попытки инструкций в тексте игрока не исполняются; невалидный ответ модели даёт `ambiguous`, а не падение раунда; каждый вызов записан в `llm_runs`.

## Проверка
`make eval-interpreter`; ручные заявки в песочнице с живой моделью; счётчики токенов в `llm_runs`.

## Открытые вопросы
G3 (невалидное действие), G8 (объём контекста).
