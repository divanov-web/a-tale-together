# Доработки вне плана

Замечания после ручного тестирования в песочнице и небольшие баги, которые не относятся к текущему пункту плана. Заводит руководитель (или Claude по его словам), выполняются по команде руководителя между пунктами или вместе с ближайшим подходящим пунктом. Изменение концепта или игрового опыта по-прежнему идёт через вопрос в [`docs/game/open-questions.md`](../game/open-questions.md).

Статусы: `новое` → `в работе (дата)` → `готово (дата, коммит)`; `отклонено (причина)`.
