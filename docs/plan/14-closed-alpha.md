# 14. Закрытая альфа

- Статус: план
- Этап концепта: 4
- Зависит от: 13 (на тестовом боте; прод-бот — пункт 11 после альфы)

## Цель
Короткая кампания с 10–20 реальными игроками на тестовом боте (прод-бот — пункт 11 после альфы); измерения и обратная связь; переработка механик.

## Критерий готовности
Игроки понимают правила без постоянных объяснений и возвращаются на следующую сессию; метрики раннего теста (ниже) собраны; список изменений механик составлен.

## Шаги
| № | Шаг | Слой / пакеты | Артефакты | Статус |
|---|---|---|---|---|
| 1 | Метрики раннего теста в таблицах и отчёте (список ниже) | `app/round`, docs | | план |
| 2 | Сценарий кампании: жанр, стартовая сцена, зацепки на 5–10 раундов | геймдизайн | `docs/game/campaigns/` | план |
| 3 | Онбординг игроков: краткие правила в `/help`, примеры заявок | `app/bot` | | план |
| 4 | Журнал ошибок ИИ: пропущенные действия, путаница персонажей, утечки | диагностика | | план |
| 5 | Опрос игроков после 3–5 раундов и после кампании | руководитель | | план |
| 6 | Переработка механик и промптов по результатам; новые сценарии | геймдизайн, промпты | | план |

## Метрики раннего теста
| Метрика | Что показывает |
|---|---|
| Зарегистрировались и совершили первое действие | порог входа |
| Доля игроков с действием в каждом из первых 3–5 раундов | удержание внутри сессии |
| Возвращаемость в следующую сессию и через неделю | удержание между сессиями |
| Среднее время от заявки до личного результата | темп |
| Доля действий с осмысленным понятным последствием | влияние игрока |
| Ошибки и противоречия мира на 100 разрешённых действий | целостность |
| Доля действий, взаимодействующих с другими персонажами | общая история |
| Стоимость LLM за раунд, сессию и активного игрока | бюджет |

## Проверка
Отчёт по метрикам и опросу; решения в `open-questions.md` закрыты или переоткрыты.
