# 04. Персонаж

- Статус: план
- Этап концепта: 1
- Зависит от: 03, [персонаж](../game/character.md)

## Цель
Игрок создаёт персонажа в личке по правилам версии 0 и видит его состояние.

## Критерий готовности
У каждой пары (сезон, пользователь) ровно один персонаж (ADR-0007); персонаж во фракции; не более 3 групп в сезоне; `/character` показывает характеристики, HP, состояния, инвентарь, локацию; данные соответствуют `rules_version` игры.

## Шаги
| № | Шаг | Слой / пакеты | Артефакты | Статус |
|---|---|---|---|---|
| 1 | Таблицы `character_models` (базовая модель фэнтези), `characters` (`season_id`, `nickname`, `public_bio`, `secret_bio`, `status`, `faction_id`, `party_id`; ключ `(season_id, user_id)`, FK на `game_members`), `character_stats`; типы в `model` | `migrations/`, `model` | [персонаж](../game/character.md) | план |
| 2 | Модель персонажа как данные: характеристики, навыки, архетипы, стартовые очки, формула HP; валидация значений по модели | `service/rules` | тесты валидации | план |
| 3 | Создание в личке: диалог текстом никнейм → архетип → распределение очков → открытое описание (до 100) → скрытое описание (до 100, необязательно); без кнопок | `app/bot`, `app/game` | состояние диалога | план |
| 3а | Автораспределение очков и навыков по архетипу: по умолчанию в режиме «повествование», по выбору в «балансе», недоступно в «механике» ([режимы игр](../game/game-modes.md)) | `service/rules`, `app/game` | тесты по режимам | план |
| 4 | `/character`: карточка (никнейм, фракция, группа, характеристики, статус, описания); `/character_bio`, `/character_secret`; `/me` ссылается на неё | `app/bot` | шаблон | план |
| 4а | Таблица `parties`; `/party`, `/party_create`, `/party_join`, `/party_leave`; лимит числа групп `max_parties` = 3, размер группы не ограничен | `migrations/`, `app/game`, `app/bot` | [группы](../game/parties.md), тесты лимита | план |
| 5 | Стартовая локация из настроек игры; `locations` с минимальным набором (пункт 06 расширит) | `migrations/`, `app/game` | | план |
| 6 | Валидация никнейма (уникален в сезоне) и длины описаний; запрет создания после старта игры без разрешения админа; создание только активным участником (`game_members.status = active`) | `app/game` | тесты | план |

## Проверка
Создание персонажей 5 пользователями; попытка второго персонажа отклоняется; `make test`.

## Открытые вопросы
Нужна ли смена персонажа после смерти/выбытия (связано с G4).
