# 04. Персонаж

- Статус: в работе (с 2026-10-10)
- Этап концепта: 1
- Зависит от: 03, [персонаж](../game/character.md)

## Цель
Игрок создаёт персонажа в личке по правилам версии 0 и видит его состояние.

## Критерий готовности
У каждой пары (сезон, пользователь) ровно один персонаж (ADR-0007); персонаж во фракции; не более 3 групп в сезоне; `/character` показывает характеристики, HP, состояния, инвентарь, локацию; данные соответствуют `rules_version` игры.

Создание персонажей 5 пользователями; попытка второго персонажа отклоняется; `make test`.
