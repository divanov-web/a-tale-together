# 04. Персонаж

- Статус: план
- Этап концепта: 1
- Зависит от: 03, правила `docs/game/rules.md` (персонаж)

## Цель
Игрок создаёт персонажа в личке по правилам версии 0 и видит его состояние.

## Критерий готовности
У каждой пары (игра, пользователь) ровно один персонаж (ADR-0007); `/character` показывает характеристики, HP, состояния, инвентарь, локацию; данные соответствуют `rules_version` игры.

## Шаги
| № | Шаг | Слой / пакеты | Артефакты | Статус |
|---|---|---|---|---|
| 1 | Таблица `characters` с ключом `(game_id, user_id)` и FK на `game_members`; типы в `model` (Stats, Conditions, Inventory с `schema_version`) | `migrations/`, `model` | | план |
| 2 | Правила персонажа как данные: архетипы, распределение характеристик, стартовый инвентарь | `service/rules` | тесты валидации | план |
| 3 | Создание в личке: диалог текстом имя → архетип → распределение очков → предыстория (короткая); без кнопок | `app/bot`, `app/game` | состояние диалога | план |
| 4 | `/character`: карточка персонажа; `/me` ссылается на неё | `app/bot` | шаблон | план |
| 5 | Стартовая локация из настроек игры; `locations` с минимальным набором (пункт 06 расширит) | `migrations/`, `app/game` | | план |
| 6 | Валидация имени и длины предыстории; запрет создания после старта игры без разрешения админа; создание только активным участником (`game_members.status = active`) | `app/game` | тесты | план |

## Проверка
Создание персонажей 5 пользователями; попытка второго персонажа отклоняется; `make test`.

## Открытые вопросы
Нужна ли смена персонажа после смерти/выбытия (связано с G4).
