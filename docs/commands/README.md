# Команды бота

Справочник реализованных команд по контексту. Добавил команду в `internal/app/bot/router.go` — запиши её сюда в тот же день.

| Файл | Контекст |
|---|---|
| [chat.md](chat.md) | групповой чат |
| [private.md](private.md) | личка с ботом |

Деление на блоки:
- «Базовые» — нужны каждому игроку или участнику чата, прав не требуют.
- «Продвинутые» — требуют прав (владелец или модератор чата, администратор игры), меняют настройки или служат для диагностики.

Планируемые, ещё не реализованные команды и принципы устройства команд — в [реестре команд](../architecture/telegram-commands.md).
