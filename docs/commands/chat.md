# Команды в групповом чате

Контекст: группа, куда добавлен бот. Команда без прав получает отказ с подсказкой. Команды лички здесь дают подсказку, где их использовать.

## Базовые

| Команда | Что делает | Добавлена |
|---|---|---|
| `/help` | список команд, доступных в группе | пункт 02 |
| `/chat` | владелец, модераторы, статус бота в чате, текущая игра | пункт 02 |
| `/status` | состояние игры чата: формат, режим, статус, сезон, настройки (раунд, кворум, часовой пояс, окно), участники, персонажи, фракции, текущий раунд с дедлайном и числом заявок, предыдущий раунд, следующий раунд или причина простоя | пункт 03 (как `/game_status`), переименована в пункте 05; раунды — пункт 05 |

## Продвинутые

| Команда | Кому | Что делает | Добавлена |
|---|---|---|---|
| `/mod add @user` | владелец чата | назначить модератора; пользователь должен быть известен боту | пункт 03 |
| `/mod remove @user` | владелец чата | снять модератора | пункт 03 |
| `/owner @user` | владелец чата | передать владение чатом | пункт 03 |
| `/create` | владелец или модератор чата | создать мир в этом чате: черновик, сезон 1, фракции жанра; автор становится администратором игры; диалог настройки сразу в личке или ссылка `start=setup_<код>` | пункт 03 |
| `/begin` | администратор игры, владелец или модератор чата | начать кампанию: стартовая сцена и первый раунд в группу (вне игрового окна — время первого раунда); нужен хотя бы один персонаж | пункт 05 |
| `/pause` | те же | пауза и возобновление: на паузе раунды не открываются; открытый раунд ждёт и получает новый дедлайн при возобновлении | пункт 05 |
| `/next` | те же, только `APP_ENV=dev` | закрыть текущий раунд сейчас и открыть следующий (ускорение проверки) | пункт 05 |
| `/replay <номер>` | те же, только `APP_ENV=dev` | воспроизвести разрешённый раунд по снимку и seed, сравнить с журналом событий | пункт 07 |
| `/ping` | все | диагностика: версия сборки, окружение, время сервера | пункт 02 |

## Ещё не реализовано
