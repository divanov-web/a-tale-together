# Команды в личке

Контекст: приватный чат с ботом. Личка открывается командой `/start`; без неё игрок к игре не допускается. Команды относятся к текущей игре пользователя (`/games`).

## Базовые

| Команда | Что делает | Добавлена |
|---|---|---|
| `/start` | открыть личку с ботом и приветствие | пункт 02 |
| `/start join_<код>` | по deep link: войти в игру и сразу начать создание персонажа | пункт 03 |
| `/help` | список команд лички | пункт 02 |
| `/me` | кто я: id, username, открыта ли личка, чаты с правами, игры и персонажи | пункт 02 |
| `/join <код>` | войти в игру по коду (запасной вход вместо ссылки), затем диалог персонажа | пункт 03 |
| `/games` | мои игры с пометкой текущей | пункт 03 |
| `/games <номер>` | выбрать текущую игру | пункт 03 |
| `/status` | состояние текущей игры (то же, что в группе) | пункт 03, переименована в пункте 05 |
| `/character` | карточка персонажа: никнейм, архетип, фракция, статус, HP, характеристики, навыки, инвентарь, описания | пункт 04 |
| `/create` | создать персонажа в текущей игре: фракция → никнейм → архетип → очки → открытое описание → скрытое описание | пункт 04 |
| `/act <текст>` | заявка персонажа на открытый раунд текущей игры: до 500 символов, одна на раунд, изменить нельзя; ответ — номер раунда и дедлайн | пункт 05 |
| `/cancel` | прервать текущий диалог (настройка игры, создание персонажа) | пункт 03 |

## Продвинутые

| Команда | Кому | Что делает | Добавлена |
|---|---|---|---|
| `/start setup_<код>` | администратор игры | по ссылке из `/create`: запустить диалог настройки игры | пункт 03 |
| `/set` | администратор игры, владелец или модератор чата | список параметров с подсказками по формату | пункт 03 |
| `/set <параметр> <значение>` | те же | изменить параметр текущей игры: `title`, `genre`, `round_minutes` (10–60), `timezone`, `play_window` (`HH:MM-HH:MM` или `нет`), `ends_at` (`ГГГГ-ММ-ДД` или `нет`; только командой, в диалог не входит, по умолчанию «нет»), `max_rounds` (0 без границы), `min_answers` (кворум 1–20), `faction_good`, `faction_evil` | пункт 03; `min_answers` — пункт 05 |
| `/bio <текст>` | игрок с персонажем | открытое описание персонажа, до 100 символов | пункт 04 |
| `/secret <текст>` | игрок с персонажем | скрытое описание, видно только мастеру, до 100 символов | пункт 04 |
| `/ping` | все | диагностика: версия сборки, окружение, время сервера | пункт 02 |

## Ещё не реализовано
`/journal`, `/party*`, `/goal*`, `/llm` — см. [реестр команд](../architecture/telegram-commands.md).
