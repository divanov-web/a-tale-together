# Интерпретатор

Текст заявки → намерение по [каталогу действий](../game/actions.md). Не решает, не бросает, не создаёт.

## Схема ответа (черновик)
```json
{
  "actor_id": "c12",
  "action_type": "explore",
  "target_id": "o7",
  "location_id": "l2",
  "parameters": {"how": "ищу бумаги"},
  "approach_id": null,
  "risk": "normal",
  "fallback": {"action_type": "wait"},
  "ambiguities": ["какой из двух сундуков"]
}
```
- `action_type` только из каталога; неизвестное → `ambiguities` + `fallback`.
- `target_id` только из переданного списка доступных целей; иначе `ambiguities`.
- `approach_id` — выбранный подход из переданного списка; иначе `risk` (`normal / hard / extreme`) для свободного действия; число успехов назначает код по таблице правил.
- Цепочка действий → первое действие, остальное в `ambiguities` с пометкой `extra`.

## Контекст вызова
Персонаж (ID, локация, краткие характеристики), доступные цели и выходы локации, каталог, текст заявки в выделенном блоке данных. Чужие секреты не передаются.

## Валидация
JSON-схема → проверка ID и типов движком → невалидно: один повтор с ошибкой в промпте → `ambiguous`.

## Оценочный набор
`assets/prompts/interpreter/eval/`: заявки из сценариев S01–S08 с ожидаемыми намерениями, включая попытки инструкций в тексте игрока.
