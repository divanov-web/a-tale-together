# LLM: конвейер и бюджет

Две роли, два промпта, две схемы, не больше двух вызовов на раунд при любом числе игроков: интерпретатор после дедлайна и рассказчик после движка; пошаговая схема с входами и выходами — [round-calls.md](round-calls.md), при расхождениях с другими документами он приоритетен (решение руководителя 2026-10-10). Код: `internal/service/{interpreter,narrator}`, `internal/adapter/llm`; промпты `assets/prompts/<роль>/vN.md`. Провайдеры и профили: [providers.md](providers.md), [ADR-0003](../decisions/0003-llm-provider.md).

| Роль | Вход | Выход | Схема вызовов MVP |
|---|---|---|---|
| [Интерпретатор](interpreter.md) | все заявки раунда + контекст сцен (клетки, объекты с подходами, выходы по направлениям, каталог) | массив намерений JSON | один вызов на раунд после дедлайна на все заявки, включая выбранные из предложенных подходов (решение руководителя 2026-10-10); разбор типовых команд кодом — запасной путь при сбое модели |
| [Рассказчик](narrator.md): генерация мира | при `/create`: описание жанра (тон, фракции с кодами, стартовая клетка шаблона) как образец формы, лимиты, `seed`, `avoid` | четыре варианта стартового мира с заголовками: название, описание для админа, тон, крючок завязки, фракции с целями, стартовая клетка | нулевой вызов на игру в тике планировщика, роль `worldgen` на модели рассказчика; до трёх попыток, затем шаблон жанра ([ADR-0028](../decisions/0028-worldgen.md)) |
| [Рассказчик](narrator.md): завязка и стартовый пакет | при `/begin`: жанр, фракции, стартовая клетка, задания на соседей, открытые описания персонажей; тон и крючок `premise` из выбранного варианта мира | текст начала истории в группу, стартовая клетка с объектами, четыре карточки соседей | один вызов на игру, роль `opening` на модели рассказчика ([ADR-0018](../decisions/0018-opening-scene.md), [ADR-0019](../decisions/0019-world-generation.md)) |
| [Рассказчик](narrator.md) | публичные и локационные события раунда, задания на достройку мира | хроника в группу и пакет мира (клетки, объекты, карточки соседей) | один вызов на раунд; приватные итоги рассказчика исключены из плана (решение руководителя 2026-10-10), игроку уходит шаблонное уведомление о статусе заявки; ответ сохраняется по ключу задания, повтор раунда модель не вызывает |
| Художник ([план](../plan/images.md)) | описание локации, открытое описание персонажа, тон мира | картинка в чат | асинхронно, вне раунда: очередь заданий и воркер, провайдер изображений по профилю; в плане, после T3 |

## Бюджет
- Лимиты: токены на вызов, раунд, игру; значения в конфиге, превышение → режим деградации (шаблоны).
- Учёт: `llm_runs` (модель, версия промпта, токены, стоимость, длительность, ошибка).
- Контекст: состояние + релевантные факты + последние события адресата; без полной истории чата.
- Стабильный префикс (правила, схема, каталог) отделён для кэширования.

## Измерения
Прогон `make eval-interpreter` (`claude-cli`, подписка; 17 случаев = 17 вызовов, 20 заявок). Прогон `make eval-narrator` (11 случаев, до 2 вызовов на случай при дозапросе) на `opus` ещё не выполнялся: запуск по решению руководителя, строка добавляется сюда. После пунктов 27 и 28 промпты `interpreter/v2`, `narrator/v6` (`v5` без названий групп), `opening-v3` живым прогоном не измерялись (набор рассказчика — 12 случаев, добавлен `quest_generation`); после B36 — `interpreter/v3`, `narrator/v7`, `opening-v4` (скрытые соседи, ADR-0025; в набор интерпретатора добавлены `move-hidden-by-view`, `move-hidden-by-name`, 19 случаев) тоже не измерялись; после пункта 32 — `narrator/v8` (реплики `speeches` в сцене; набор рассказчика 14 случаев: `speech_quote`, `speech_injection`, ADR-0027) не измерялся; после B42 — `narrator/v9` и `opening-v6` (логово сил зла как фон, ADR-0031; набор рассказчика 15 случаев: `lair_background`; завязка `-opening` с заданием на логово) не измерялись.
