# Рассказчик

Разрешённые события → публичная хроника раунда в группу. Факты не меняет, исходы не пересчитывает. Приватные итоги рассказчика исключены из плана (решение руководителя 2026-10-10): игрок получает короткое шаблонное уведомление о статусе заявки без LLM ([раунд](../game/round.md)).

## Вызов
| Вызов | Вход | Выход | Проверка |
|---|---|---|---|
| Хроника | события `public` + `location` (сводно по локациям), последние 2–3 хроники кратко | текст до N символов, упоминание каждого значимого события по ID | все ID упомянуты; нет приватных фактов |

Один вызов на раунд, второй и последний после интерпретатора ([round-calls.md](round-calls.md): входы, выходы, пример). Выход структурирован по схеме: общий текст, блок на команду (группу) с упоминанием событий по ID; предлагаемые подходы следующего раунда с посчитанными кодом сложностью и шансом код добавляет к сообщению сам. Стандартные исходы (`wait`, провал без последствий) в хронику попадают сводной фразой или не попадают.

## Контекст
Только события, разрешённые видимостью `public` и `location`; стиль и жанр мира; фракции и их отношения; `public_bio` персонажей сцены как данные; `secret_bio` персонажа как данные для подачи его линии, в тексте не раскрывается; статус персонажа (`waiting` — присутствует, `inactive` — вывести из сюжета, `dead` — выбытие и возврат по [смерти](../game/death.md)); без характеристик и инвентаря целиком. Хроника строится по группам ([группы](../game/parties.md)): блок на группу плюс общие события локации. Предлагаемые подходы сцены с посчитанной кодом сложностью и шансом: рассказчик оформляет, числа не меняет. Режим игры `mode` задаёт стиль ([режимы игр](../game/game-modes.md)): блок стиля на режим в промпте; в режиме «механика» хроника по фактам, в режиме «повествование» числа в промпт не попадают, исход передаётся словами.

Поздний этап (пункт 17): ближайший шаг сюжетной цели каждого персонажа сцены как подсказка; в ответе поле `realized_steps`, проверяется кодом.

## Проверка текста
Код сверяет упоминание ID; выборочно — соответствие исхода (успех/провал) по ключевым словам; расхождения логируются для ручного разбора.

## Оценочный набор
`assets/prompts/narrator/eval/`: события из сценариев с ожидаемыми ограничениями (что не должно появиться в хронике).
