# Рассказчик

Разрешённые события → публичная хроника и приватные итоги. Факты не меняет, исходы не пересчитывает.

## Вызовы
| Вызов | Вход | Выход | Проверка |
|---|---|---|---|
| Хроника | события `public` + `location` (сводно), последние 2–3 хроники кратко | текст до N символов, упоминание каждого значимого события по ID | все ID упомянуты; нет приватных фактов |
| Приватный итог | события персонажа (`private` + его локация), статус заявки, доступные варианты | краткий текст + 2–3 подсказки следующего действия | ID заявки упомянут; исход совпадает со статусом |

Стандартные исходы (провал проверки без последствий, `wait`) — шаблоном без LLM.

## Контекст
Только события, разрешённые видимостью адресата; стиль и жанр мира; без характеристик и инвентаря целиком.

## Проверка текста
Код сверяет упоминание ID; выборочно — соответствие исхода (успех/провал) по ключевым словам; расхождения логируются для ручного разбора.

## Оценочный набор
`assets/prompts/narrator/eval/`: события из сценариев с ожидаемыми ограничениями (что не должно появиться в хронике).
