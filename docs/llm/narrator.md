# Рассказчик

Разрешённые события → публичная хроника раунда в группу. Факты не меняет, исходы не пересчитывает. Приватные итоги рассказчика исключены из плана (решение руководителя 2026-10-10): игрок получает короткое шаблонное уведомление о статусе заявки без LLM ([раунд](../game/round.md)). Реализация: пункт 09, [ADR-0011](../decisions/0011-narrator-call.md), `internal/service/narrator`, вызов из `app/round.narrate`.

## Вызов
| Вызов | Вход | Выход | Проверка |
|---|---|---|---|
| Завязка и стартовый пакет | при `/begin`: название, жанр, тон, режим, фракции с отношениями, стартовая клетка шаблона (описание, местность, названия объектов как подсказка), задания на недостающих соседей по направлениям, ключи модели персонажа, персонажи только с открытыми данными | `{text, start, neighbors[]}` | текст 80–3000 символов, без цифр вне «механики», каждый персонаж упомянут по никнейму (один дозапрос, затем объём вне границ → шаблон жанра, [ADR-0018](../decisions/0018-opening-scene.md)); клетка и соседи по правилам пакета мира ([ADR-0019](../decisions/0019-world-generation.md)): без валидных объектов остаются объекты шаблона, пропущенный сосед — «Неизведанные земли» |
| Хроника и пакет мира | события `public` + `location` по сценам (группа в локации или персонажи без группы в локации, пункт 19), состояние после свёртки, описания персонажей как данные, выжимка последних 3 хроник; задания на достройку (`generate`, пункт 27) | `{chronicle, scenes[{scene_id, text, event_seqs}], world{cells[], neighbors[]}}`; код хранит `scenes[{location_id, party, text, event_seqs}]`, где `party` — подпись сцены | все ID упомянуты; сцены по `scene_id` и `seq` из входа; скрытые описания не раскрыты; без цифр в «повествовании»; пакет мира только по заданиям и лимитам, остаток — шаблон без дозапроса |

Один вызов на раунд, второй и последний после интерпретатора ([round-calls.md](round-calls.md): входы, выходы, пример). Общий текст плюс блок на сцену: группа в локации («Группа (Локация)») либо персонажи без группы в локации (название локации); в одной локации может быть несколько сцен, общие события локации упоминаются в одной из них ([группы](../game/parties.md), [ADR-0016](../decisions/0016-parties.md)). Подходы следующего раунда считает код (`narrator.Options`: сложность по пресету режима плюс локация, шанс каждого присутствующего по параметру; переходы по направлениям к соседям, пункт 27) и приписывает к сцене строкой «Варианты: …» (в «повествовании» шанс словами, без сложности); модель получает подходы без шансов, чтобы обозначить, что перед персонажами, и числа не меняет. Ответ хранится в `rounds.narration`; ответ модели сохраняется по ключу задания в `generation_jobs` (повтор раунда берёт его без вызова, ADR-0019).

## Пакет мира (`world.go`, пункт 27)
| Что | Правило |
|---|---|
| Задания (`PlanTasks`) | занятые присутствующими клетки стадии `card` → детализация (до `model.MaxCellsPerRound` = 4, остальные шаблон без участия модели); недостающие соседи занятых клеток → карточки; сосед проверяется по всей карте игры, не только по снимку |
| Вход | блок `generate`: клетки (`location_id`, `x`, `y`, имя, местность, карточка, кто вошёл), соседи (`x`, `y`, направление, от какой клетки), лимиты, ключи характеристик и навыков модели персонажа; без заданий блока нет и ответ ждёт пустой `world` |
| Клетка (`validateCell`) | имя до 60 символов (пустое — имя карточки), описание до 600 (пустое — карточка), сложность 0–2, местность из задания; объекты до 2: ключ latin snake_case (из `key`, иначе из названия), название до 60, `state`, `hidden` → `hidden_until_revealed` |
| Подход (`validateApproach`) | `explore` или `interact`; характеристика и навык только из модели персонажа (без характеристики — без броска); сложность 1–9; `on_success`: `state`, `reveal` на скрытый объект той же клетки, `fact`; `on_fail`: `condition` из списка состояний, `damage` ≤ 2, `fact`; до 3 подходов, невалидный отброшен с замечанием |
| Сосед (`validateNeighbor`) | имя, местность одним словом, карточка одним предложением; пустое имя или нет ответа — шаблон «Неизведанные земли» |
| Шаблон (`TemplateWorld`) | сбой модели, нет провайдера, бюджет: клетка «Дорога» (имя карточки, если было) без объектов, соседи «Неизведанные земли»; `WorldPackage.Templated` считает закрытые шаблоном задания (метрика `world_templated`) |
| Запись (`app/round.applyWorld`) | строки клеток и объектов в транзакции раунда, события `cell_generated` (`source`: `model` / `template`) и `object_created` за событиями движка, свёртка в состояние; подписи сцен обновляются по новым именам |

## Контекст (`BuildInput`)
| Блок | Содержание |
|---|---|
| Мир | название, тон жанра, режим, номер раунда, фракции с отношениями, выжимка прошлого: завязка истории (`games.opening_scene`, до 1200 символов) первой строкой, затем общий текст последних 3 хроник (до 400 символов каждая, от старых к новым) |
| Сцены | по группам внутри локаций (`scene_id`, `party` — имя группы, пусто у персонажей без группы; группы раньше одиночек; лидер не передаётся) с присутствующими (не `inactive` и не `dead`, B13): название, описание, координаты, стадия и местность, выходы по направлениям с именем соседа и карточкой неописанного соседа, объекты с состоянием словами; персонажи — никнейм, пол `gender` (`male`/`female`, без поля — не указан; B18), статус, отметка входа `entry` (`new` — первый замороженный раунд персонажа, `returned` — заявка после `leaving` или `inactive`; считает код при заморозке, B1), `public_bio`, `secret_bio` как данные для подачи линии, состояния словами |
| События | только `public` и `location`: `seq`, тип, локация, актёр, фраза кодом (`narrator.Describe`), для проверок исход словами и признак форсирования; числа броска только в режиме «механика»; у `party_split` и `party_held` актёр — группа, фраза называет направление и желавших иначе, лидера не называет |
| Подходы | видимые объекты сцен: название, характеристика и навык словами, сложность (не передаётся в «повествовании») |

Приватные события (`fact_learned`, `condition_added`, `hp_changed`, `character_waited`, `help_given`, `action_rejected`) в контекст не попадают; `check_rolled` имеет видимость `location` (ADR-0011). Вход (`entry`): промпт `v3` (`v2` + сцены по группам и правила `party_split` / `party_held`) требует ввести нового персонажа в сцену и описать именно его действие из событий, вернувшегося — объяснить одной фразой; без отметки персонаж уже в истории. Статусы: `waiting` — присутствует без действий, `leaving` — выводится из сюжета в этом раунде (один раунд на пороге пропусков, B13), `inactive` в сцены не попадает, `dead` — только через `character_died` / `character_returned` ([смерть](../game/death.md)); `party_split` / `party_held` объясняются сюжетом без упоминания лимита ([группы](../game/parties.md)). Режим игры задаёт блок стиля в промпте ([режимы игр](../game/game-modes.md)): «механика» — сухой отчёт с числами, «баланс» — литературно без чисел, «повествование» — без чисел и терминов механики. Бюджет контекста `narrator.MaxInputBytes` (60 КБ): больше — шаблонная хроника без вызова.

Поздний этап (пункт 17): ближайший шаг сюжетной цели каждого персонажа сцены как подсказка; в ответе поле `realized_steps`, проверяется кодом.

## Проверка текста (`validate.go`)
Схема → сцены только из входа по `scene_id`, по одному блоку на сцену → `seq` только из входа; пара событий перехода (от и до) считается одним упоминанием → скрытые описания (от 8 символов) не встречаются в тексте → в «повествовании» нет цифр → объём не больше 6000 символов. Замечания → один дозапрос с полным повтором ответа; оставшиеся пропущенные события дописываются кодом строкой `Describe` в первую сцену их локации (`Narration.Patched`), оставшаяся утечка → `ErrLeak` → шаблонная хроника. Выборочно по ключевым словам: сцена с провалами без слов неудачи попадает в лог (`outcome wording suspect`).

## Сбой
Нет провайдера, ошибка или таймаут, ответ не по схеме, бюджет, утечка → `app/round` публикует шаблонную хронику (`chronicleText`: события словами) с теми же подходами; раунд `published`, мир не откатывается, `rounds.narration` пуст. Хроника длиннее лимита Telegram делится на части outbox (`part` 1..N, подпись «(продолжение)»).

## Завязка и стартовый пакет (`Opening`)
Один вызов на игру при `/begin` ([ADR-0018](../decisions/0018-opening-scene.md), [ADR-0019](../decisions/0019-world-generation.md)): роль `opening` на модели рассказчика профиля, промпт `assets/prompts/narrator/opening-v2.md`, схема `{text, start, neighbors}`. Модель придумывает начало по тону жанра, названию мира, фракциям, стартовой клетке и открытым описаниям персонажей: представляет каждого в сцене, оставляет открытую угрозу, не решает за персонажей, не называет чисел вне «механики»; описывает стартовую клетку с объектами (подсказка — объекты шаблона) и даёт карточки недостающих соседей по направлениям. Текст уходит сообщением «начало истории» в группу, хранится в `games.opening_scene` и даётся хроникам первой строкой выжимки; клетка и соседи записываются кодом (`app/round.startPackage`). Сбой, ответ не по схеме или объём вне границ после дозапроса → стартовая сцена и клетка шаблона жанра, соседи «Неизведанные земли». Живая проверка: `make eval-narrator EVAL_ARGS="-opening"` (печатает завязку, клетку с объектами и соседей по миру первого случая набора, замечания кода, токены). Измерение 2026-10-11 (`opening-v1`, только текст) на `opus`/`low`: один вызов, 2 510 / 808 токенов, 12 с; `opening-v2` с пакетом ещё не измерялся.

## Оценочный набор
`assets/prompts/narrator/eval/cases.json`: общий мир «Серая башня» на сетке и 11 случаев — пример round-calls (дверь, провал с форсированием, переход), секрет прямой и пересказом, «повествование» без цифр, инструкция в открытом описании, смерть и возврат, статусы `leaving` / `waiting` (а `inactive` в сценах и тексте отсутствует), «механика» с числами, тихий раунд, `party_held`, связность по выжимке, достройка мира (`world_generation`: группа вошла в карточку «Опушка», задание на клетку и трёх соседей; ожидание `world`: одна клетка хотя бы с одним объектом, три соседа, без шаблонов). Проходит случай, где модель сама упомянула все события (`Patched = 0`), нужные никнеймы есть, запрещённых подстрок нет, пакет мира по ожиданию. Прогон на живом `claude-cli`: `make eval-narrator` (`EVAL_ARGS="-v -case имя -model sonnet -effort low"`; модель по умолчанию `opus`, как в профиле `local-claude`), порог 90 %; результаты в [README](README.md).
