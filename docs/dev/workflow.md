# Рабочий процесс

## Роли
Руководитель: концепт, игровой опыт, ключи и платные сервисы, приёмка. Claude: всё остальное (архитектура, код, тесты, промпты LLM, документация, система промптов Claude Code).

## Задача
1. Запрос руководителя в чат Claude Code.
2. Claude классифицирует (`.claude/skills/tale-team/SKILL.md`, «Рабочий цикл»), при необходимости ADR или сценарий.
3. Код → `make test` → `make lint` → документы.
3а. Применить локально: `make restart` (бот в фоне, лог `logs/bot.log`); при миграциях `make migrate` на обе базы и правка данных уже запущенных игр, если схема `settings` или умолчания изменились.
4. Отчёт: сделано, проверено, осталось, решения.
5. Коммит делает руководитель или Claude по просьбе. `git push` только руководитель вручную; Claude не пушит.

## Git
Одна ветка `master` до появления второго участника; коммиты по задачам; push в `origin` делает только руководитель; `.env`, `bin/`, `.idea/` в `.gitignore`.

## Вопросы
Изменения концепта: `docs/game/open-questions.md`. Технические: ADR. Срочное: в чат.
