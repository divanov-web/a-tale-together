# Рабочий процесс

## Роли
Руководитель: концепт, игровой опыт, ключи и платные сервисы, приёмка. Claude: всё остальное (архитектура, код, тесты, промпты LLM, документация, система промптов Claude Code).

## Задача
1. Запрос руководителя в чат Claude Code.
2. Claude классифицирует (`.claude/skills/tale-team/SKILL.md`, «Рабочий цикл»), при необходимости ADR или сценарий.
3. Код → `make test` → `make lint` → документы.
3а. Применить локально: при миграциях Claude делает `make migrate` на обе базы и правит данные уже запущенных игр, если схема `settings` или умолчания изменились; бота Claude перезапускает сам — `make restart` и проверка `make logs` ([go_commands.md](../go_commands.md)), бот в фоне, лог `logs/bot.log`.
4. Отчёт: сделано, проверено, осталось, решения.
5. Коммит делает Claude сам по завершении каждой задачи. `git push` только руководитель вручную; Claude не пушит.

## Git
Одна ветка `master` до появления второго участника; коммиты по задачам: Claude коммитит сам по завершении каждой задачи, включая мелкие правки (решение 2026-10-13, прежнее правило «только большие изменения» от 2026-10-10 отменено); в коммит идут только файлы задачи; push в `origin` делает только руководитель; `.env`, `bin/`, `.idea/` в `.gitignore`.

## Вопросы
