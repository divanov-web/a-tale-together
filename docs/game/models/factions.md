# Модель фракций

Поведение: [фракции](../factions.md). На старте две стороны конфликта с кодами `good` и `evil`; имена и описания по сюжету. Шаблон жанра задаёт имена по умолчанию, администратор переименовывает. Фракции, созданные рассказчиком по сюжету, получают произвольный код (латиница, до 20 символов) и идут в списках после стартовых.

## Поля фракции
| Поле | Тип | Назначение |
|---|---|---|
| `code` | `good`, `evil` или код от рассказчика | стабильный ключ для правил и промптов |
| `title` | строка ≤ 40 | имя по сюжету («Орден Рассвета», «Гильдия теней») |
| `description` | строка ≤ 200 | кто это и чего хотят; в промпт рассказчика |
| `tone` | строка ≤ 100 | как рассказчик подаёт сторону (не «злодеи», а «вторая сторона конфликта») |
| `relations` | карта `code → ally / neutral / hostile` | отношения к другим фракциям; симметричность не требуется |

## Эффекты отношений (гипотеза)
| Отношение актора к фракции цели | `persuade` | `trade` | `attack` |
|---|---|---|---|
| `ally` | +1 кубик | без ограничений | требует подтверждения (PvP-режим, G4) |
| `neutral` | 0 | без ограничений | по правилам PvP |
| `hostile` | −1 кубик | только через встречную проверку убеждения | по правилам PvP |

## Пример в шаблоне жанра
```json
{
  "factions": [
    {"code": "good", "title": "Орден Рассвета", "description": "Хранители города, верят в закон и свет.", "tone": "строгие, не безгрешные", "relations": {"evil": "hostile"}},
    {"code": "evil", "title": "Гильдия теней", "description": "Контрабандисты и шпионы; хотят свободы от Ордена.", "tone": "сторона конфликта, не злодеи", "relations": {"good": "hostile"}}
  ]
}
```

Строки `factions` игры создаются из этого шаблона при `/create`; `relations` хранятся в `factions.relations jsonb`.
