# Модель фракций

Поведение: [фракции](../factions.md). Три стороны конфликта с кодами `good`, `evil`, `neutral`; имена и описания по сюжету. Шаблон жанра задаёт имена по умолчанию, администратор переименовывает.

## Поля фракции
| Поле | Тип | Назначение |
|---|---|---|
| `code` | `good / evil / neutral` | стабильный ключ для правил и промптов |
| `title` | строка ≤ 40 | имя по сюжету («Орден Рассвета», «Гильдия теней», «Вольные») |
| `description` | строка ≤ 200 | кто это и чего хотят; в промпт рассказчика |
| `tone` | строка ≤ 100 | как рассказчик подаёт сторону (не «злодеи», а «вторая сторона конфликта») |
| `relations` | карта `code → ally / neutral / hostile` | отношения к другим фракциям; симметричность не требуется |

## Эффекты отношений (гипотеза)
| Отношение актора к фракции цели | `persuade` | `trade` | `attack` |
|---|---|---|---|
| `ally` | +1 кубик | без ограничений | требует подтверждения (PvP-режим, G4) |
| `neutral` | 0 | без ограничений | по правилам PvP |
| `hostile` | −1 кубик | только через встречную проверку убеждения | по правилам PvP |

## Пример в шаблоне жанра
```json
{
  "factions": [
    {"code": "good", "title": "Орден Рассвета", "description": "Хранители города, верят в закон и свет.", "tone": "строгие, не безгрешные", "relations": {"evil": "hostile", "neutral": "neutral"}},
    {"code": "evil", "title": "Гильдия теней", "description": "Контрабандисты и шпионы; хотят свободы от Ордена.", "tone": "сторона конфликта, не злодеи", "relations": {"good": "hostile", "neutral": "neutral"}},
    {"code": "neutral", "title": "Вольные", "description": "Торговцы и наёмники, выгода превыше флага.", "tone": "циничные посредники", "relations": {"good": "neutral", "evil": "neutral"}}
  ]
}
```

Строки `factions` игры создаются из этого шаблона при `/create`; `relations` хранятся в `factions.relations jsonb`.
