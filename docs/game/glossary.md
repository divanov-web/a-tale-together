# Глоссарий игры

Термины, которые видят игроки и администраторы: роли, мир, цикл игры. Технические термины: [глоссарий проекта](../glossary.md).

Термины вводит руководитель и может ошибаться в выборе слова. Если термин неточен, конфликтует с другим или есть общепринятый аналог (в настольных RPG, в Telegram), Claude заменяет его на более подходящий во всех документах, промптах и коде, указывает замену в отчёте по задаче и в колонке «Было». Значение термина без руководителя не меняется.

| Термин | Англ. в коде | Значение | Было |
|---|---|---|---|
| Команда | command | Слеш-команда `/name [аргументы]`, единственный способ управления игрой до появления кнопок; у команды объявлены контексты: группа, личка или оба | |
| Чат | chat | Telegram-группа, куда добавили бота; хранит владельца, модераторов, статус бота; у чата не более одной незавершённой игры | |
| Владелец чата | chat owner | Пользователь, добавивший бота в группу; может передать роль; создаёт игры и назначает модераторов | |
| Модератор чата | chat moderator | Пользователь из ручного списка владельца с правами на создание и управление играми чата, кроме назначения модераторов; админы Telegram-группы прав не имеют | |
| Игра, мир, партия | game | Независимая кампания одной Telegram-группы: настройки, состояние, расписание, правила | |
| Тип игры | game kind | Выбор при создании: глобальная игра, рассказ, сериал ([типы игр](game-types.md)); задаёт границы жизни игры, сбросы истории и судьбу прокачки | |
| Глобальная игра | global game | Игра без конца, привязанная к чату; история пишется непрерывно, прокачка персонажа сохраняется постоянно | |
| Рассказ | story game | Одна большая партия с границами, заданными администратором; прокачка живёт только внутри неё | |
| Сериал | serial game | Игра без конца с историей, разбитой на сезоны; характеристики, навыки и опыт сохраняются между сезонами, инвентарь сбрасывается | |
| Сезон | season | Отрезок истории сериала со своей стартовой сценой и финалом; у других типов единственный сезон | |
| Администратор игры | game admin | Участник с ролью `admin` (создатель игры); управляет настройками и расписанием вместе с владельцем и модераторами чата | |
| Участник, игрок | game member, player | Пользователь, зарегистрированный в игре через приватный чат; роль `admin` или `player` | |
| Персонаж | character | Персонаж пользователя в конкретной игре, один на пару (игра, пользователь): характеристики, HP, состояния, инвентарь, локация, знания | |
| Баланс истории и механики | story mode | Настройка мира с тремя уровнями: механика, баланс, история; каждый уровень — пресет доступных механик, стиля рассказчика и создания персонажа | процент 0–100 с четырьмя полосами, упрощено руководителем до трёх уровней |
| Сюжетная цель | story goal | Личная цель игрока, которую игра ведёт к достижению через 10 шагов, вплетаемых в сюжет; приватна; поздний этап ([сюжетные цели](story-goals.md)) | |
| Шаг цели | goal step | Одно сюжетное событие на пути к цели; отмечается реализованным после попадания в хронику, по порядку | |
| Локация | location | Место действия; у игры лимит одновременно активных локаций | |
| Раунд | round | Логический шаг игры: окно приёма заявок, снимок, разрешение, публикация | |
| Заявка | action submission | Сырой текст игрока с намерением на раунд; статус и время подачи | |
| Каталог действий | action catalog | Конечный список типов действий, к которым сводится свободный текст | |
| Проверка | check | Бросок пула d6 (характеристика + навык + предмет), каждая «6» — успех; успехов нужно не меньше сложности; исходы: успех, успех с ценой, провал | d20 + модификатор против порога; заменено руководителем на Year Zero Engine |
| Пул кубиков | dice pool | Число d6 в проверке: характеристика + навык + бонус предмета − штрафы состояний | |
| Сложность | difficulty | Требуемое число успехов в проверке (1–4) плюс сложность локации | |
| Сложность локации | location difficulty | Число 0–2 у локации, прибавляемое к сложности всех проверок в ней | |
| Форсирование | push | Однократный переброс кубиков без «6» после неудачи ценой состояния «истощён»; успех после него — успех с ценой | |
| Шанс | chance | Вероятность набрать нужное число успехов при данном пуле; показывается игроку вместе со сложностью | |
| Подход | approach | Предлагаемый способ действия с объектом сцены: действие, характеристика, навык, сложность; необязателен | |
| Конфликтная группа | conflict group | Намерения над одной сущностью или ресурсом, разрешаемые вместе | |
| Видимость | visibility | Кому доступно событие: `public`, `location`, `private(character_ids)` | |
| Хроника | chronicle | Публичный текст раунда в группе | |
| Приватный итог | private result | Личный текст игроку о результате его заявки | |
| Сценарий | scenario | Эталонный пример раунда с ожидаемыми исходами; основа тестов движка | |
