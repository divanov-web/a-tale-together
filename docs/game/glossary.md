# Глоссарий игры

Термины, которые видят игроки и администраторы: роли, мир, цикл игры. Технические термины: [глоссарий проекта](../glossary.md).

Термины вводит руководитель и может ошибаться в выборе слова. Если термин неточен, конфликтует с другим или есть общепринятый аналог (в настольных RPG, в Telegram), Claude заменяет его на более подходящий во всех документах, промптах и коде, указывает замену в отчёте по задаче и в колонке «Было». Значение термина без руководителя не меняется.

| Термин | Англ. в коде | Значение | Было |
|---|---|---|---|
| Команда | command | Слеш-команда `/name [аргументы]`, единственный способ управления игрой до появления кнопок; у команды объявлены контексты: группа, личка или оба | |
| Чат | chat | Telegram-группа, куда добавили бота; хранит владельца, модераторов, статус бота; у чата не более одной незавершённой игры | |
| Владелец чата | chat owner | Пользователь, добавивший бота в группу; может передать роль; создаёт игры и назначает модераторов | |
| Модератор чата | chat moderator | Пользователь из ручного списка владельца с правами на создание и управление играми чата, кроме назначения модераторов; админы Telegram-группы прав не имеют | |
| Игра, мир, партия | game | Независимая кампания одной Telegram-группы: настройки, состояние, расписание, правила | |
| Формат игры | game format | Выбор при создании: глобальная игра, рассказ, сериал ([форматы игр](game-formats.md)); задаёт границы жизни игры, сбросы истории и судьбу прокачки | «тип игры»; переименовано, чтобы не путать с режимом игры |
| Глобальная игра | global game | Игра без конца, привязанная к чату; история пишется непрерывно, прокачка персонажа сохраняется постоянно | |
| Рассказ | novel | Одна большая партия с границами, заданными администратором; прокачка живёт только внутри неё | |
| Сериал | series | Игра без конца с историей, разбитой на сезоны; характеристики, навыки и опыт сохраняются между сезонами, инвентарь сбрасывается | |
| Сезон | season | Отрезок истории сериала со своей стартовой сценой и финалом; у других типов единственный сезон | |
| Администратор игры | game admin | Участник с ролью `admin` (создатель игры); управляет настройками и расписанием вместе с владельцем и модераторами чата | |
| Участник, игрок | game member, player | Пользователь, зарегистрированный в игре через приватный чат; роль `admin` или `player` | |
| Жанр | genre | Запись справочника с шаблоном: модель персонажа, тон, стартовая сцена, имена фракций по умолчанию | |
| Модель | model | Описание сущности как данных: поля, ограничения, значения по умолчанию, пример JSON ([модели](models/README.md)); движок валидирует, LLM не меняет | |
| Модель персонажа | character model | Справочник характеристик, навыков, архетипов и стартовых очков; задаётся жанром; значения персонажа хранятся по её ключам | |
| Никнейм | nickname | Имя персонажа в конкретной игре | |
| Открытое описание | public bio | До 100 символов о персонаже, видно всем, попадает в промпты как данные | |
| Скрытое описание | secret bio | До 100 символов, видно только игроку и рассказчику; скрытое влияние на подачу своей линии | |
| Статус персонажа | character status | `active` / `waiting` (1–2 пропуска) / `leaving` (3 пропуска, один раунд: рассказчик выводит из повествования) / `inactive` (дальше, в контекст не попадает) / `dead` (выбыл по режиму смерти до возврата) | |
| Режим смерти | death mode | Настройка игры `death_mode`: `none` (не умирают), `fake` (ненастоящая смерть: выбытие на `death_days`, по умолчанию), `real` (теряют персонажа); реализуется только `fake` ([смерть](death.md)) | |
| Ненастоящая смерть | fake death | Выбытие персонажа из игры на срок (10 дней, счётчик `death_rounds_left` в раундах) с объяснением рассказчика и возвратом | |
| Счётчик возврата | death rounds left | Поле персонажа `death_rounds_left`: раундов до возвращения после ненастоящей смерти; уменьшается каждым замороженным раундом | «осталось дней смерти»: срок задаётся в днях, а считается раундами |
| Фракция | faction | Сторона конфликта в игре; на старте две (добро и зло) с именами по сюжету ([фракции](factions.md)) | |
| Группа | party | Обязательное объединение персонажей любого размера, для которых рассказчик пишет общую историю; назначается кодом, игрок не выбирает; на старте в сезоне до 4 групп, это же лимит занятых локаций; совместные испытания только внутри группы ([группы](parties.md)); не путать с чатом и конфликтной группой | |
| Разделение группы | party split | Создание новой группы из участников, чьи решения ведут в другую локацию; только пока активных групп меньше `max_parties`; событие `party_split` | |
| Удержание группы | party hold | При достигнутом лимите групп группа идёт туда, куда заявил скрытый лидер (без лидера — большинство), заявки на другое направление получают исход «удержан»; событие `party_held`, рассказчик объясняет сюжетом | |
| Игровое окно | play window | Время ежедневного начала и окончания (`play_from`, `play_to`), внутри которого открываются раунды; необязательно | |
| Персонаж | character | Персонаж пользователя в сезоне игры, один на пару (сезон, пользователь): никнейм, фракция, группа, характеристики, HP, состояния, инвентарь, локация, знания | |
| Режим игры | game mode | Настройка мира с тремя режимами: механика, баланс, повествование; каждый режим — пресет доступных механик, стиля рассказчика и создания персонажа ([режимы игр](game-modes.md)); не путать с форматом игры | «баланс истории и механики», «тип игры»; процент 0–100 с четырьмя полосами упрощён до трёх режимов; уровень «история» → «повествование» |
| Сюжетная цель | story goal | Личная цель игрока, которую игра ведёт к достижению через 10 шагов, вплетаемых в сюжет; приватна; поздний этап ([сюжетные цели](story-goals.md)) | |
| Шаг цели | goal step | Одно сюжетное событие на пути к цели; отмечается реализованным после попадания в хронику, по порядку | |
| Локация, клетка | location, cell | Место действия: квадрат сетки с координатами `(x, y)` от стартовой `(0,0)`, четыре направления; имя — подпись, не ключ; стадии `none` / `card` / `detailed`; занятых клеток не больше `max_parties`, карта не ограничена ([динамический мир](world.md)) | «локация» без координат, лимит активных локаций |
| Карточка соседа | neighbor card | Клетка в стадии `card`: тип местности, имя и одно предложение; подробности создаются при входе; клетка без строки в БД — стадия «none» | |
| Направление | direction | Одна из четырёх сторон света на сетке (`north`, `south`, `west`, `east`): цель перехода словом («на север») или именем соседа; выходы считает код по существующим соседям | «выход по имени» (`links`) |
| Пакет мира | world package | Блок `world` в ответе рассказчика по заданиям кода: детализированные клетки с объектами и карточки соседей; проверяется по заданиям и лимитам, невалидное отбрасывается, пропущенное закрывает шаблон («Дорога», «Неизведанные земли») | |
| Квест | quest | Линия фракции с проверяемым прогрессом: сюжетный (связан с целью, 3–6 этапов) или побочный (2–4); у фракции до 2 сюжетных и 1 побочного; появляется при старте и по счётчику открытых клеток, кнопки «взять» нет ([динамический мир](world.md), [модель](models/quest.md)) | |
| Этап квеста | quest stage | Шаг квеста с условием-результатом из каталога (`object_state`, `fact`, `visited`), расстоянием от предыдущего и наградой; проявляется в клетке, куда группа пришла на нужном расстоянии; закрывает код событием `quest_stage_done` | |
| Цель фракции | faction goal | Формулировка того, чего добивается фракция, со стадией и версией; задаётся завязкой, пересматривается по закрытию сюжетного квеста; видна в `/quests` | |
| Открытие клетки | cell discovery | Первый вход персонажа фракции в клетку (событие `cell_discovered` с фракцией); одна клетка — по одному открытию на фракцию; карточка соседа и стартовая клетка открытием не считаются | |
| Счётчик исследования | exploration counter | Число клеток, открытых фракцией с последнего сброса; сброс после выдачи фракции нового квеста и после завершения любого её квеста; порог 1 / 4 по числу активных квестов фракции | |
| Цель фракции | faction goal | Формулировка того, чего добивается фракция, с версией; без конечной точки; меняется по значимым событиям и закрытию сюжетного квеста | «основная цель игры» |
| Квест | quest | Линия из этапов, существующая в мире без кнопки «взять»; принадлежит фракции: сюжетный (связан с её целью, 3–6 этапов) или побочный (2–4); лимит на фракцию 2 сюжетных + 1 побочный; отказа нет | |
| Этап квеста | quest stage | Шаг квеста с условием-результатом, которое проверяет код (состояние объекта, факт, посещение, предмет, NPC); привязывается к клетке лениво при входе группы после предыдущего этапа | «испытание квеста» |
| Объект | world object | Сущность клетки с состоянием и подходами ([модель](models/location.md)); «ничего полезного» — флаг `searched`, не предмет | |
| Предмет | item | Переносимая сущность с владельцем: клетка, объект-контейнер или персонаж; передаётся событием | |
| NPC | npc | Персонаж мира без игрока: состояние, отношение и знания хранит код, реплики пишет рассказчик ([модель](models/npc.md)) | |
| Раунд | round | Логический шаг игры: окно приёма заявок, снимок, интерпретация, разрешение, публикация; не больше двух вызовов LLM ([схема](../llm/round-calls.md)) | |
| Кворум раунда | round quorum | Минимум заявок (`min_round_answers`, по умолчанию 2, в разработке 1), без которого раунд пропускается: заявки переходят в следующий раунд, причина простоя в `/status`; в prod бот молчит, в dev пишет «Недостаточное количество участников. Раунд пропущен» | |
| Заявка | action submission | Сырой текст игрока на раунд: выбранный из предложенных подходов или своё действие; одна на раунд; все заявки идут через интерпретатор | |
| Каталог действий | action catalog | Конечный список типов действий, к которым сводится свободный текст | |
| Проверка | check | Один бросок d100 против шанса `50 + 10 × (параметр − сложность)` в границах 5–95 %; исходы: успех, успех с ценой, провал ([испытания](checks.md)) | d20 против порога, затем Year Zero Engine: отклонён руководителем 2026-10-11 как не подходящий проекту |
| Прямой шанс | direct chance | Название системы проверок ([ADR-0014](../decisions/0014-direct-chance.md)): шанс виден до действия и считается в уме, каждое очко разницы — 10 % | «общая шкала» в спецификации баланса |
| Параметр | parameter | Число персонажа в проверке: характеристика + навык + бонус предметов (≤ 2) + помощь (≤ 2) − штрафы состояний | «пул кубиков» |
| Сложность | difficulty | Число, с которым сравнивается параметр: база подхода или риска (4 обычно, 7 трудно, 9 почти невозможно) плюс сложность локации | |
| Сложность локации | location difficulty | Число 0–2 у локации, прибавляемое к сложности всех проверок в ней | |
| Форсирование | push | Однократный повторный бросок с тем же шансом после неудачи ценой состояния «истощён»; успех после него — успех с ценой | |
| Шанс | chance | Процент успеха по параметру и сложности; показывается игроку в уведомлении, в группе только сложность | |
| Подход | approach | Предлагаемый способ действия с объектом сцены из данных локации: действие, характеристика, навык, сложность, исходы; в начале раунда сообщение в группе перечисляет подходы сцены со сложностью и шансом каждого персонажа; необязателен | |
| Свободное действие | free action | Заявка вне предложенных подходов; интерпретатор назначает ей характеристику, навык, риск и исходы обеих ветвей, движок считает ([round-calls.md](../llm/round-calls.md)) | «кастомное действие» |
| Конфликтная группа | conflict group | Намерения над одной сущностью или ресурсом, разрешаемые вместе | |
| Видимость | visibility | Кому доступно событие: `public`, `location`, `private(character_ids)` | |
| Завязка | opening scene | Начало истории при `/begin`: текст рассказчика по жанру, фракциям, стартовой локации и открытым описаниям персонажей (при сбое — стартовая сцена шаблона жанра); хранится у игры, идёт первой строкой выжимки в хроники | «стартовая сцена» в старых документах |
| Хроника | chronicle | Публичный текст раунда в группе одним вызовом рассказчика: общий текст и блок на сцену (локацию; с группами — на группу); код приписывает подходы следующего раунда со сложностью и шансами, длинный текст делится на части | |
| Уведомление о заявке | submission notice | Короткое шаблонное сообщение игроку в личку о статусе и исходе его заявки без LLM; приватные итоги рассказчика исключены из плана (решение руководителя 2026-10-10) | «приватный итог» |
| Сценарий | scenario | Эталонный пример раунда или спорного хода с ожидаемыми исходами; основа тестов движка | «кейс» в речи руководителя |
| Совместное действие | joint action | Одинаковые заявки нескольких персонажей на одну цель в одном раунде, объединяемые движком в одну проверку: ведущий и участники, вклады по разнице параметров, итог не ниже параметра слабейшего | |
| Ведущий | leader | Персонаж с наибольшим параметром в совместном действии; несёт цену форсирования | |
| Лидер группы | party leader | Участник группы, чьё направление движок засчитывает при расхождении заявок на перемещение под лимитом групп или локаций ([группы](parties.md)); скрыт от игроков до пункта 23, где его выбирают голосованием и показывают. Не путать с ведущим совместного действия | |
