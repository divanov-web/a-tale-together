# Личные сюжетные цели

Поздний этап (план [17](../plan/17-story-goals.md)). Игрок выбирает личную сюжетную цель; игра ведёт к ней в несколько этапов, выстраивая драматическую или приключенческую линию.

## Как работает

| Шаг | Что происходит |
|---|---|
| Выбор цели | игрок в личке `/goal_set <текст>`; цель хранится у персонажа, статус `active` |
| Разбиение | LLM разбивает цель на 10 шагов (структурированный ответ, валидация кодом: ровно 10, каждый шаг — одно сюжетное событие); шаги хранятся со статусом `pending` |
| Вплетение | при подготовке сцены рассказчик получает ближайший `pending` шаг каждого персонажа в сцене как подсказку сюжета; шаг — предложение, не обязанность |
| Отметка «шаг реализован» | рассказчик возвращает в структурированном ответе список шагов, вошедших в хронику; код проверяет, что шаг принадлежит персонажу сцены и является ближайшим; записывается событие `goal_step_done` с видимостью `private`, шаг получает `done` и ссылку на раунд |
| Достижение | последний шаг `done` → цель `achieved`, событие `goal_achieved`, игроку приватное сообщение с поздравлением и предложением выбрать следующую цель (необязательно) |
| Несколько целей | у персонажа может быть несколько активных целей; лимит в настройках игры `max_active_goals`, на старте 1 |

## Ограничения

- Шаги реализуются по порядку; пропуск шага невозможен, но шаг может «висеть» несколько раундов.
- Шаг не создаёт фактов мира сам по себе: предметы, NPC и места для шага появляются только через события движка (принцип 2).
- Цель и шаги приватны: в публичную хронику попадает событие, но не формулировка цели.
- Цель можно отказаться (`abandoned`); число смен цели ограничено настройкой.

## Открыто

Пересборка оставшихся шагов, если сюжет ушёл в сторону (перегенерация с учётом реализованных). Цели в сериале: переносятся ли в следующий сезон (по умолчанию да).
