# Фракции

Стороны конфликта внутри игры. Мир начинается с двух: `good` и `evil` (добро и зло условно: «зло» может быть второй стороной конфликта, а не злодеями). Имена задаёт администратор по сюжету. Число фракций — внутренняя механика бота: администратор его не настраивает, новые фракции появляются по ходу повествования (решение руководителя 2026-10-10).

| Правило | Черновик |
|---|---|
| Создание | две записи `factions` создаются вместе с игрой; имена по умолчанию из шаблона жанра; администратор переименовывает (`/set faction_good <имя>`, `/set faction_evil <имя>`) |
| Новая фракция по сюжету | рассказчик возвращает событие «создана фракция» (код, имя, описание, отношения); движок валидирует и создаёт запись; игрокам видна с момента появления в хронике; план 13 |
| Выбор | игрок выбирает фракцию при входе в игру (`/join`, диалог) из существующих на этот момент; смена — только через сюжет (событие), не командой. На время тестовых прогонов выбор выключен: бот собирается с `bot.Settings.AutoFaction = good`, шаг пропускается, все персонажи во фракции добрых (решение руководителя 2026-10-12; вернуть выбор — убрать настройку в `cmd/bot/main.go`) |
| В промптах | рассказчик знает фракции и их отношения; интерпретатор — фракцию актора и цели |
| Видимость | фракция персонажа открыта всем участникам (этап 1) |
| Логово | у `evil` опорная клетка — случайный угол `(±3, ±3)`, выбирается кодом при `/create` и хранится у фракции (`factions.lair_x`, `lair_y`); на карте появляется при `/begin` скрытой карточкой с именем и обликом под сеттинг от завязки; для рассказчика фон (слухи, угроза с той стороны), не цель и не этап квеста ([динамический мир](world.md), [ADR-0031](../decisions/0031-evil-lair.md), S22). У `good` и фракций по сюжету логова нет |
| Цель | у каждой фракции цель в истории (`faction_goals`, [модель квеста](models/quest.md), S17): чего сторона добивается и где она сейчас, без конечной точки и без срока — ни дедлайна, ни счётчика, ни отсчёта времени («до зимы», «за три дня», «пока не взойдёт луна»): игра идёт раундами без внутриигрового времени, срок недостижим и недоказуем кодом (решение руководителя 2026-10-15, B43). Правило в промптах, где цель рождается: `worldgen-v2` (`goal` варианта мира), `opening-v7` (первая версия), `narrator/v10` (пересмотр); код текст цели не проверяет — цель текст, не факт движка; проверка — eval-случай `goal_timeless` |
| Расширение | тайная принадлежность — после закрытой альфы |
