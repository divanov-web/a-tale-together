# Фракции

Стороны конфликта внутри игры. Мир начинается с двух: `good` и `evil` (добро и зло условно: «зло» может быть второй стороной конфликта, а не злодеями). Имена задаёт администратор по сюжету. Число фракций — внутренняя механика бота: администратор его не настраивает, новые фракции появляются по ходу повествования (решение руководителя 2026-10-10).

| Правило | Черновик |
|---|---|
| Создание | две записи `factions` создаются вместе с игрой; имена по умолчанию из шаблона жанра; администратор переименовывает (`/set faction_good <имя>`, `/set faction_evil <имя>`) |
| Новая фракция по сюжету | рассказчик возвращает событие «создана фракция» (код, имя, описание, отношения); движок валидирует и создаёт запись; игрокам видна с момента появления в хронике; план 13 |
| Выбор | игрок выбирает фракцию при входе в игру (`/join`, диалог) из существующих на этот момент; смена — только через сюжет (событие), не командой |
| В промптах | рассказчик знает фракции и их отношения; интерпретатор — фракцию актора и цели |
| Видимость | фракция персонажа открыта всем участникам (этап 1) |
| Расширение | тайная принадлежность — после закрытой альфы |
