# Фракции

Стороны конфликта внутри игры. На этапе 1 ровно три: `good`, `evil`, `neutral` (добро, зло, нейтралитет). Точные имена задаются по сюжету: «зло» может быть не злом, а второй стороной конфликта.

| Правило | Черновик |
|---|---|
| Создание | три записи `factions` создаются вместе с игрой; имена по умолчанию из шаблона жанра; администратор переименовывает и описывает (`/game_set faction_<code> <имя>`) |
| Выбор | игрок выбирает фракцию при входе в игру (`/join`, диалог); смена — только через сюжет (событие), не командой |
| В промптах | рассказчик знает фракции и их отношения; интерпретатор — фракцию актора и цели |
| Видимость | фракция персонажа открыта всем участникам (этап 1) |
| Расширение | больше трёх фракций и тайная принадлежность — после закрытой альфы |
