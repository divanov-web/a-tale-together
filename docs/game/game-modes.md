# Режимы игры: баланс истории и механики

Настройка мира «режим игры» (`games.mode`): один из трёх режимов, выбирается при создании, меняется между раундами. По умолчанию `balanced`. Не путать с форматом игры ([форматы игр](game-formats.md)): формат — долговечность истории. Механики, на которые ссылаются пресеты: [испытания](checks.md), [персонаж](character.md). Режим — пресет: набор доступных механик в правилах и стиль рассказчика в промпте. Содержимое пресетов предварительное, до сценариев.

| `mode` | Режим | Доступные механики | Стиль рассказчика | Персонаж |
|---|---|---|---|---|
| `mechanics` | механика | полный каталог действий; проверка в каждом значимом действии, сложности по таблице +1 за особые условия; форсирование с ценой; столкновения с HP и уроном; инвентарь с тегами; встречные проверки; помощь | сухой отчёт: параметр, бросок, сложность, шанс и исход в уведомлении о заявке; хроника по фактам | ручное распределение очков; выбор навыков обязателен |
| `balanced` | баланс | каталог действий и проверки по правилам; столкновения и инвентарь включены | исход и степень успеха словами в уведомлении о заявке; хроника литературная, факты точные | ручное или автораспределение на выбор |
| `narrative` | повествование | проверки только для рискованных действий, сложность не выше обычной (5) плюс локация; форсирование без цены; столкновения без счёта HP (исход «ранен / выведен из строя»); инвентарь как заметные предметы без лимита; провал заменяется «успехом с ценой», кроме явно гибельных действий | повествование без чисел в публичном тексте (хроника, «Варианты» в группе, «Шанс был» в итоге); личные «Варианты» с параметром, сложностью и шансом в процентах, как в других режимах (B19); больше описаний мира и персонажей; подсказки следующего шага сюжетные | автораспределение по умолчанию; навыки как черты |

Инварианты: движок считает каждую проверку в любом режиме и пишет бросок в событие; режим определяет, какие механики доступны и как исход подаётся, но не источник истины. Смена режима между раундами не меняет уже записанные события.
