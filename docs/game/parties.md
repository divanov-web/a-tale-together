# Группы

Группа (party) — логическое объединение персонажей, для которых рассказчик пишет общую историю. Не путать с Telegram-группой (чат) и с конфликтной группой движка.

| Правило | Черновик |
|---|---|
| Размер | до 3 персонажей (`settings.max_party_size`); лимит растёт по мере понимания ограничений промптов |
| Состав | персонаж не более чем в одной группе сезона; группа привязана к сезону; участие без группы допустимо (одиночная линия) |
| Создание и вход | `/party_create <имя>`, `/party_join <имя>`, `/party_leave` в личке; вход по согласию группы не требуется на этапе 1 |
| Испытания | совместные действия и помощь — только внутри группы ([испытания](checks.md)); пересечение групп в одном испытании — только по сюжету рассказчика (встречные проверки между группами допустимы) |
| Хроника | рассказчик пишет историю по группам: блок на группу плюс общие события локации; одиночки — отдельные короткие блоки |
| Локация | участники группы держатся одной локации; `move` одного участника — предложение группе, иначе выход из группы по сценарию |
