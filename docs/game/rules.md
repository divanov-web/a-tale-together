# Правила (rules_version: 1)

Ориентир: собственная упрощённая система, D&D как вдохновение. Правила — данные с версией `rules_version`; движок — источник истины. Числа предварительные, уточняются после сценариев.

| Документ | Содержание |
|---|---|
| [Персонаж](character.md) | характеристики, навыки, HP, состояния, инвентарь, знания, награды и прогрессия |
| [Испытания](checks.md) | «Прямой шанс»: параметр, сложность и шанс, форсирование, предлагаемые действия, совместное действие, встречная проверка |
| [Режимы игр](game-modes.md) | какие механики и стиль включены в режиме: механика, баланс, повествование |
| [Форматы игр](game-formats.md) | глобальная, рассказ, сериал; сезоны; границы рассказа |
| [Фракции](factions.md) | три стороны конфликта, выбор при входе |
| [Группы](parties.md) | группы персонажей для общей истории (на старте до 3 групп), границы совместных испытаний |
| [Модели](models/README.md) | форма данных сущностей: модели персонажа, фракции, группа, жанр, локация, NPC |
| [Каталог действий](actions.md) | типы действий, параметры, проверки, эффекты |
| [Раунд](round.md) | окно, дедлайн, снимок, фазы разрешения |
| [Сюжетные цели](story-goals.md) | личные цели из 10 шагов; поздний этап |

Версия правил поднимается при изменении любого из документов и закрепляется за игрой (G10).

## Открыто
Числа и исходы проверяются [сценариями](scenarios.md); вопросы игрового опыта в [open-questions](open-questions.md).
