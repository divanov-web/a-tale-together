# Правила (rules_version: 0, черновик)

Ориентир концепта §7; система проверок — Year Zero Engine (пул d6) по решению руководителя. Какие механики включены в каждом режиме игры: [режимы игр](game-modes.md). Числа предварительные, уточняются после сценариев.

## Персонаж
| Поле | Черновик |
|---|---|
| Имя, архетип | свободные, архетип из списка жанра (воин, плут, маг, дипломат, следопыт) |
| Характеристики | Сила, Ловкость, Разум, Воля: от 2 до 4 на старте, сумма 12 |
| Навыки | 0–3; на старте 6 очков по архетипу, не более 3 в один; список навыков по жанру (например, воровство, внимательность, убеждение, выживание) |
| HP | 4 + Сила; при 0 «выведен из строя», смерть по решению руководителя (вопрос G4) |
| Состояния | ранен (−1 кубик ко всем проверкам), истощён (−1 кубик, снимается отдыхом), скрыт, задержан |
| Инвентарь | до 6 предметов; предметы — записи с тегами, не свободный текст; предмет может давать +1…+2 кубика к подходящей проверке |
| Знания | факты, доступные персонажу; фиксируются событиями с видимостью |

## Проверка (Year Zero Engine)
Решение руководителя: вместо d20 против порога — пул кубиков. Превышение параметра над сложностью не гарантирует успех, лишь повышает шанс.

- Пул = характеристика + навык + бонус предмета (0–2) − штрафы состояний; бросаются d6, каждая «6» — успех.
- Сложность = требуемое число успехов: 1 обычная, 2 трудная, 3 очень трудная, 4 героическая.
- Сложность локации (`locations.difficulty` 0–2) прибавляется к требуемому числу успехов: трудные места остаются трудными без роста уровня.
- Исходы: успехов ≥ сложности — успех; иначе игрок может форсировать бросок (перебросить все кубики без «6» один раз), получив состояние «истощён»; успех после форсирования — успех с ценой; иначе провал.
- Встречная проверка (PvP, преследование, защита): оба бросают, успехи защищающегося вычитаются из успехов атакующего; равенство — защищающийся.
- Помощь: +1 кубик помогаемому за каждого помощника (не более +2); помогающий тратит своё действие.
- Игроку показываются сложность и шанс успеха для его пула (без форсирования); в режиме «повествование» — словами («легко», «рискованно», «почти невозможно»).

Шанс хотя бы N успехов по размеру пула (ориентир для отображения и подбора сложностей):

| Пул | ≥1 | ≥2 | ≥3 | ≥4 |
|---|---|---|---|---|
| 2 | 31 % | 3 % | 0 % | 0 % |
| 4 | 52 % | 13 % | 2 % | 0 % |
| 6 | 67 % | 26 % | 6 % | 1 % |
| 8 | 77 % | 40 % | 13 % | 3 % |
| 10 | 84 % | 52 % | 22 % | 7 % |

## Предлагаемые действия
В описании сцены программа предлагает действия с открытой сложностью; предложения необязательны. Пример для запертой двери:

| Подход | Характеристика / навык | Сложность |
|---|---|---|
| выбить | Сила | 2 |
| отпереть | Ловкость / воровство | 1 |
| найти потайной рычаг | Разум / внимательность | 3 |

- Подходы хранятся у объектов локации как данные (`approaches`: действие, характеристика, навык, сложность); движок добавляет сложность локации и считает шанс для каждого персонажа сцены; рассказчик только оформляет.
- Игрок может описать своё действие вне списка: интерпретатор сводит его к типу каталога и оценивает риск (`normal / hard / extreme`), число успехов назначает таблица правил (1 / 2 / 3) плюс сложность локации. LLM сложность не назначает.

## Совместное действие
Несколько персонажей выполняют одно действие над одной целью в одном раунде (сценарий S09). Проверка одна на группу.

- Ведущий — персонаж с наибольшим пулом; остальные — участники.
- Участник с пулом, близким к ведущему, добавляет кубики (действия складываются); участник с пулом заметно слабее мешает и отнимает кубики (толпа у замка).
- Итоговый пул не ниже пула самого слабого участника: плохой напарник ухудшает шанс ведущего, но не ниже того, что слабый сделал бы один.
- Черновик формулы: вклад участника = +1 при разнице пулов ≤ D1, 0 при D1 < разница ≤ D2, −1 при разнице > D2; итог = max(пул ведущего + Σ вкладов, минимальный пул группы). Пороги D1, D2 подбираются симуляцией (план [12](../plan/12-conflicts-and-joint-actions.md)).
- Исход общий для группы; событие с участниками; цена форсирования ложится на ведущего.
- Отличие от `help`: помощь — заявка «помочь N», всегда +1 кубик; совместное действие — одинаковые заявки на одну цель, объединяются движком.

## Столкновение
Без карты и инициативы по клеткам. Атака = встречная проверка: пул Силы или Ловкости атакующего против пула Ловкости защищающегося; каждый чистый успех снимает 1 HP, оружие добавляет +1 к урону при успехе. Форсирование разрешено обеим сторонам.

## Награды и прогрессия
Минимум в MVP: опыт за раунд с результатом; каждые 5 опыта +1 к одной характеристике (до +4). Пересмотр после этапа 3.
