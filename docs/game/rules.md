# Правила (rules_version: 0, черновик)

Ориентир концепта §7. Числа предварительные, уточняются после сценариев.

## Персонаж
| Поле | Черновик |
|---|---|
| Имя, архетип | свободные, архетип из списка жанра (воин, плут, маг, дипломат, следопыт) |
| Характеристики | Сила, Ловкость, Разум, Воля: от −1 до +3 на старте, сумма +4 |
| Навыки | по архетипу 2 навыка, дающих +2 к проверкам своей области |
| HP | 10 + Сила; при 0 «выведен из строя», смерть по решению руководителя (вопрос G4) |
| Состояния | ранен (−1 ко всем проверкам), скрыт, задержан, истощён |
| Инвентарь | до 6 предметов; предметы — записи с тегами, не свободный текст |
| Знания | факты, доступные персонажу; фиксируются событиями с видимостью |

## Проверка
- `d20 + характеристика + навык + ситуативный модификатор` против сложности: лёгкая 8, средняя 12, трудная 16.
- Исходы: ≥ сложность — успех; сложность − 4 ≤ бросок < сложность — успех с ценой; ниже — провал.
- Встречная проверка (PvP, преследование): оба бросают, выше побеждает; равенство — защищающийся.
- Помощь: +2 помогающему исходу, помогающий тратит своё действие.

## Столкновение
Без карты и инициативы по клеткам. Атака = проверка Силы или Ловкости против сложности защиты цели (10 + Ловкость); успех снимает `d6 + Сила` HP; успех с ценой — урон обеим сторонам.

## Баланс истории и механики
Настройка мира `story_mode`: один из трёх уровней, выбирается при создании, меняется между раундами. По умолчанию `balanced`. Уровень — пресет: набор доступных механик в правилах и стиль рассказчика в промпте. Содержимое пресетов предварительное, до сценариев.

| `story_mode` | Уровень | Доступные механики | Стиль рассказчика | Персонаж |
|---|---|---|---|---|
| `mechanics` | механика | полный каталог действий; проверка в каждом значимом действии, сложности выше; столкновения с HP и уроном; инвентарь с тегами; встречные проверки; помощь | сухой отчёт: бросок, модификаторы, сложность и исход в приватном итоге; хроника по фактам | ручное распределение очков; выбор навыков обязателен |
| `balanced` | баланс | каталог действий и проверки по правилам; столкновения и инвентарь включены | исход и степень успеха словами; числа по `/journal full`; хроника литературная, факты точные | ручное или автораспределение на выбор |
| `story` | история | проверки только для рискованных действий, сложности сжаты (8/10/12); столкновения без счёта HP (исход «ранен / выведен из строя»); инвентарь как заметные предметы без лимита; провал заменяется «успехом с ценой», кроме явно гибельных действий | повествование без чисел; больше описаний мира и персонажей; подсказки следующего шага сюжетные | автораспределение по умолчанию; навыки как черты |

Инварианты: движок считает каждую проверку на любом уровне и пишет бросок в событие; уровень определяет, какие механики доступны и как исход подаётся, но не источник истины. Смена уровня между раундами не меняет уже записанные события.

## Награды и прогрессия
Минимум в MVP: опыт за раунд с результатом; каждые 5 опыта +1 к одной характеристике (до +4). Пересмотр после этапа 3.
