# Персонаж (rules_version: 0, черновик)

Часть [правил](rules.md). Проверки и пулы: [испытания](checks.md); автораспределение и черты по режиму: [режимы игр](game-modes.md). Числа предварительные.

## Поля
| Поле | Черновик |
|---|---|
| Привязка | сезон игры (в рассказе сезон один); у пользователя один персонаж на сезон |
| Никнейм | имя персонажа в этой игре, 2–30 символов, уникально в сезоне |
| Архетип | из модели персонажа жанра (пример фэнтези: воин, плут, маг, дипломат, следопыт) |
| Открытое описание | до 100 символов; попадает в промпт интерпретатора и рассказчика как данные; видно другим игрокам |
| Скрытое описание | до 100 символов; попадает в контекст рассказчика как данные для подачи линии этого персонажа и в хронике не раскрывается; игрок скрыто влияет на подачу своей линии; фактов мира не создаёт |
| Фракция | одна из фракций игры ([фракции](factions.md)); выбирается при входе |
| Группа | не более одной группы сезона ([группы](parties.md)); может отсутствовать |
| Модель персонажа | справочник `character_models`: список характеристик, навыков, архетипов, стартовые очки и формула HP; задаётся жанром; значения персонажа хранятся по ключам модели |
| Характеристики | по модели; базовая модель: Сила, Ловкость, Разум, Воля от 2 до 4 на старте, сумма 12 |
| Навыки | по модели, 0–3; на старте 6 очков по архетипу, не более 3 в один (базовая модель: воровство, внимательность, убеждение, выживание, скрытность, бой) |
| HP | 4 + Сила; при 0 «выведен из строя»; дальнейшее по режиму [смерти персонажа](death.md): по умолчанию «ненастоящая смерть» — выбытие на срок со счётчиком `death_rounds_left` |
| Состояния | ранен (−1 кубик ко всем проверкам), истощён (−1 кубик, снимается отдыхом), скрыт, задержан |
| Инвентарь | до 6 предметов; предметы — записи с тегами, не свободный текст; предмет может давать +1…+2 кубика к подходящей проверке |
| Знания | факты, доступные персонажу; события `fact_learned` (осмотр, подходы с `fact`), хранятся в `characters.knowledge`, последние 5 в `/character` |

## Статус
| Статус | Условие | Рассказчик | Испытания |
|---|---|---|---|
| `active` | заявка в последнем раунде или пропусков меньше 3 | упоминает, ведёт линию | доступны |
| `waiting` | 1–2 раунда подряд без заявки | ещё упоминает как присутствующего (занят, ждёт) | недоступны, защитное положение |
| `inactive` | 3 раунда подряд без заявки | придумывает, что случилось с персонажем, и выводит его из повествования (событие `character_sidelined`) | недоступны; не цель для PvP |
| `dead` | HP 0 в режиме «ненастоящая смерть» ([смерть](death.md)) | объясняет выбытие (`character_died`), по истечении `death_rounds_left` возвращает (`character_returned`) | недоступны; заявки не принимаются; пропуски не копятся |

Возврат: заявка в любом раунде → `active`, рассказчик возвращает персонажа в сюжет (событие `character_returned`). Числа (3 раунда) — настройка `settings.inactive_after_rounds`. Переходы считает `app/round` при заморозке раунда (пункт 05); события `character_sidelined` / `character_returned` — с журналом событий (пункт 07).

## Награды и прогрессия
Минимум в MVP: опыт за раунд с результатом; каждые 5 опыта +1 к одной характеристике (до +4). Пересмотр после этапа 3.
