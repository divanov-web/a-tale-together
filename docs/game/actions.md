# Каталог действий (rules_version: 0, черновик)

Свободный текст сводится интерпретатором к одному типу из каталога; что не сводится — `ambiguous` с уточнением игроку. Одна основная заявка на персонажа за раунд.

| Тип | Параметры | Проверка | Эффект при успехе | Видимость события |
|---|---|---|---|---|
| `move` | `location_id` | нет, если есть связь; иначе `rejected` с объяснением | смена локации | location (обе) |
| `explore` | `target` (объект/место) | Разум или Ловкость, сложность по объекту | факт-знание персонажу, возможно предмет | private; след — location |
| `interact` | `target`, `how` | по ситуации | изменение объекта (дверь, механизм) | location |
| `persuade` | `target_npc`, `goal` | Воля против сложности NPC | NPC меняет отношение или даёт факт | private |
| `attack` | `target` | встречная | урон, состояния | location |
| `help` | `target_character` | нет | +2 к проверке цели в этом раунде | private обоим |
| `sneak` | `goal` | Ловкость против наблюдателей | состояние «скрыт», действие без свидетелей | private |
| `wait` | `until` (опц.) | нет | продолжение занятия, защитное положение (+2 к защите) | нет |
| `trade` | `target_character`, `give`, `take` | согласие обеих сторон в одном раунде | обмен предметами | private обоим |

## Правила каталога
- Условные действия только формы «если X недоступно, то Y» внутри каталога; циклы условий не поддерживаются.
- Действие над одной сущностью несколькими персонажами образует конфликтную группу ([раунд](round.md)).
- Расширение каталога — по журналу `ambiguous` после пробных партий, через сценарий и ADR при изменении движка.
