# Каталог действий (rules_version: 1)

Свободный текст сводится интерпретатором к одному типу из каталога; что не сводится — `ambiguous` с безопасным толкованием (G3), причина в уведомлении о заявке. Одна основная заявка на персонажа за раунд. Реализовано движком (пункт 07): `move`, `explore`, `interact`, `wait`, `help`; `attack`, `sneak`, `trade` — пункт 12, `persuade` — пункт 13; до тех пор интерпретатор заменяет их безопасным толкованием с указанием пункта в примечании к итогу (`persuade` с испытанием — осмотр с тем же испытанием, иначе запасное действие или `wait`), отказ движка остаётся только для намерений, минующих интерпретатор ([ADR-0036](../decisions/0036-unsupported-actions-safe.md), B46). Типовые команды без LLM (`service/rules.ParseTyped`: `идти`, `осмотреть`, `открыть` и другие глаголы взаимодействия, `помочь`, `ждать`) остаются запасным путём при сбое модели: все заявки идут через интерпретатор (решение руководителя 2026-10-10, пункт 08).

| Тип | Параметры | Проверка | Эффект при успехе | Видимость события |
|---|---|---|---|---|
| `move` | направление (`north`/`south`/`west`/`east`) или имя соседа | нет, если сосед существует; иначе `rejected` с перечнем выходов по сторонам света | смена клетки; первый вход фракции — открытие клетки (`cell_discovered`, private); расхождение участников группы — разделение или удержание группы ([группы](parties.md)); карточка соседа детализируется рассказчиком в том же раунде ([динамический мир](world.md)) | location (обе) |
| `explore` | `target` (объект/место) | Разум или Ловкость (+ внимательность), сложность по объекту | факт-знание персонажу, возможно предмет | private; след — location |
| `interact` | `target`, подход или свободное испытание | подход из `approaches` объекта или оценка риска интерпретатором | изменение объекта (дверь, механизм) | location |
| `persuade` | `target_npc`, `goal` | Воля (+ убеждение), сложность по NPC | NPC меняет отношение или даёт факт | private |
| `attack` | `target` | встречная | урон, состояния | location |
| `help` | `target_character` | нет | +1 к параметру проверки цели в этом раунде (не более +2) | private обоим |
| `sneak` | `goal` | Ловкость (+ скрытность) встречно против наблюдателей | состояние «скрыт», действие без свидетелей | private |
| `wait` | `until` (опц.) | нет | продолжение занятия, защитное положение (+1 к параметру защиты) | нет |
| `trade` | `target_character`, `give`, `take` | согласие обеих сторон в одном раунде | обмен предметами | private обоим |

## Правила каталога
- Проверка по [испытаниям](checks.md): параметр против сложности подхода плюс сложность локации, один бросок d100; предлагаемые подходы с открытой сложностью и шансом.
- Условные действия только формы «если X недоступно, то Y» внутри каталога; циклы условий не поддерживаются.
- Действие над одной сущностью несколькими персонажами образует конфликтную группу ([раунд](round.md)).
- Окраска и цепочка ([ADR-0039](../decisions/0039-action-flavor.md), S24): заявка даёт движку одно действие каталога; что требует броска, перехода, объекта или другого персонажа сверх него — второе действие, отбрасывается с пометкой «extra» в примечании итога; что механики не требует (манера, деталь без исхода, слова и просьбы к спутникам или рассказчику) — окраска `flavor`, уходит рассказчику и в примечание не попадает. Заявка без действия с механикой — `wait` с окраской.
- Расширение каталога — по журналу `ambiguous` после пробных партий, через сценарий и ADR при изменении движка.
