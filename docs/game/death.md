# Смерть персонажа

Решение руководителя 2026-10-10: смерть персонажа — настройка игры с тремя режимами. Реализуется только режим по умолчанию «ненастоящая смерть»; остальные — поздние этапы. Смерть не пересекается с HP и состояниями ([персонаж](character.md)): HP 0 означает «выведен из строя», а что происходит дальше, решает режим смерти.

## Режимы
| Режим | Код | Что происходит при HP 0 | Этап |
|---|---|---|---|
| Персонажи не умирают | `none` | рассказчик не имеет возможности убить персонажа; персонаж ослаблен (дебафф придумать позже) | поздний |
| Ненастоящая смерть (по умолчанию) | `fake` | персонаж исключается из игры на `death_days` (10 дней, настройка разработчика); рассказчик придумывает, как персонаж выбывает и как возвращается; HP и состояния при возврате восстанавливаются | пункты 07 и 09 |
| Персонажи умирают | `real` | игрок полностью теряет персонажа; продолжить игру можно только новым персонажем | поздний |

## Ненастоящая смерть
| Правило | Значение |
|---|---|
| Срок | `settings.death_days` = 10 дней; настройка разработчика, администратору не показывается |
| Счётчик | при смерти персонаж получает `death_rounds_left` = `death_days` × раундов в сутки по расписанию игры (окно и `round_minutes`; без окна — сутки целиком); каждый замороженный раунд уменьшает счётчик на 1; при 0 персонаж возвращается |
| Статус | `dead`: заявки не принимаются (`/act` отвечает «персонаж выбыл до …»), пропуски не копятся, в `/status` и `/character` виден срок возврата |
| Рассказчик | событие `character_died` → в хронике и приватном итоге объясняет выбытие; событие `character_returned` → возвращает персонажа в сюжет; факты не меняет |
| Возврат | HP полный, состояния сняты, инвентарь, характеристики и опыт сохранены; локация — стартовая локация игры или по решению рассказчика в событии |
| Выбор режима | `settings.death_mode` = `fake`; параметр `/set death` появится вместе с режимами `none` и `real` |

## Связи
PvP и кражи у игроков — вопрос G4 в [открытых вопросах](open-questions.md); смерть от действий других игроков следует тому же режиму. Сезоны сериала: умерший персонаж возвращается в новом сезоне ([форматы игр](game-formats.md)).
