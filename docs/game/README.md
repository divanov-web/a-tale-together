# Игра: правила и сценарии

Собственная упрощённая система (концепт §7): D&D как вдохновение, не стандарт. Правила — данные с версией `rules_version`; движок — источник истины.

| Документ | Содержание |
|---|---|
| [Глоссарий](glossary.md) | роли, мир, цикл игры; термины руководителя с колонкой «Было» |
| [Типы игр](game-types.md) | глобальная игра, рассказ, сериал; сезоны; границы рассказа |
| [Правила](rules.md) | персонаж, характеристики, проверки, HP, состояния, инвентарь, прогрессия |
| [Каталог действий](actions.md) | типы действий, параметры, проверки, эффекты, цена |
| [Раунд](round.md) | окно, дедлайн, снимок, лимиты, бездействие, пауза, фазы разрешения |
| [Сценарии](scenarios.md) | эталонные раунды для проверки правил на бумаге и тестов движка |
| [Вопросы руководителю](open-questions.md) | решения, которые меняют концепт или игровой опыт |

Правило принято, когда для него есть сценарий, разрешимый без произвольных решений. Процесс: скилл `/tale-gamedesign`.
