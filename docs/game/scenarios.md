## S01. Один предмет
- Снимок: локация «казначейство», предмет `ключ казначея` (1 шт.), персонажи Вор (Ловкость +3) и Паладин (Ловкость 0) в локации.
- Заявки: Вор `explore(ключ)`, Паладин `explore(ключ)`.
- Ожидание: конфликтная группа по предмету; встречная проверка Ловкости; победитель получает предмет (событие `item_taken`, private победителю + location «кто-то взял ключ» при провале скрытности); проигравший `resolved` с исходом «предмета уже нет». Инвентарь: ключ ровно у одного.
- Видимость: оба видят факт «ключ забрали»; кто — только победитель, если не было свидетелей.

## S09. Совместный взлом
- Снимок: локация «подвал» (сложность 1), объект `дверь` с подходом «отпереть» (Ловкость / воровство, сложность 1 → итого 2), персонажи Вор (пул 6) и Кузнец (пул 2) в локации.
- Заявки: Вор `interact(дверь, отпереть)`, Кузнец `interact(дверь, отпереть)`.
- Ожидание: одна конфликтная группа «совместное действие»; ведущий Вор; вклад Кузнеца по порогам D1/D2 (разница 4 → предположительно −1); итоговый пул max(6 − 1, 2) = 5; одна проверка против 2; событие `door_opened` или провал для обоих; оба получают `resolved` с одинаковым исходом и указанием ведущего.
- Вариант: пулы 6 и 5 → вклад +1, итоговый пул 7: совместная работа выгодна.
- Видимость: location.

## Снимок «башня» (S06, S07, S10–S12)
- Локации: «Зал башни» (выход «вниз в подвал», скрытый «тайный ход», объект `statue`); «Подвал башни» (сложность 1, выход «наверх в зал», объект `cellar_door` `locked` с подходами «выбить» Сила 2 (провал → истощён), «отпереть» Ловкость/воровство 1, «найти рычаг» Разум/внимательность 3 → `reveal hidden_lever`; объект `hidden_lever` скрыт до раскрытия, подход без броска → дверь `open`).
- Персонажи: Вор (Ловкость 4, воровство 3, отмычки +1) и Кузнец (Сила 4) в подвале; Маг (Разум 4, внимательность 3) и Паладин в зале; Призрак — `dead` со счётчиком 0.

## S06. Повтор раунда
- Заявки: как в S07. Ожидание: два прогона с одним seed дают одинаковые события и итоги (включая кубики); другой seed — другие кубики хотя бы в одной проверке.

## S07. Никто не потерян
- Заявки: Вор `interact(дверь, отпереть)`, Кузнец `interact(дверь, выбить, force)`, Маг `move(подвал)`, Паладин `attack(Вор)`, Призрак `wait`, Паладин `explore` с неоднозначностью.
- Ожидание: шесть итогов, у каждого ровно один статус: `resolved` (Вор: пул 8, сложность 2; Кузнец: пул 4, сложность 3; Маг переходит), `rejected` (атака — пункт 12; Призрак выбыл), `ambiguous` (Паладин); у каждого итога есть события по ссылкам; события пронумерованы подряд; последнее событие — возврат Призрака (`character_returned`, public).

## S10. Перемещение
- Заявки: Маг `move(Подвал башни)`, Паладин `move(тайный ход)`, Вор `move(крыша)`.
- Ожидание: Маг `resolved`, два события `character_moved` (location: зал и подвал); скрытый и несуществующий выходы `rejected` с перечнем выходов; свёртка событий ставит Мага в подвал.

## S11. Осмотр
- Заявки: Маг `explore()` (локация), Паладин `explore(статуя)`, Вор `explore(рычаг)` (скрыт).
- Ожидание: факт о локации (выходы и объекты) только Магу (`fact_learned`, private); факт о статуе Паладину; рычаг не найден → `rejected`.
- Варианты следующего раунда (B8): «осмотреть статую» остаётся, пока в зале есть кто-то, кому факт о статуе неизвестен; когда его знают все присутствующие, подход не предлагается. Открытая дверь не предлагает «отпереть».

## S12. Запертая дверь
- Механика: Кузнец выбивает с форсированием: при провале первого броска перебрасываются кубики без «6», добавляется «истощён», успех после форсирования — «успех с ценой».
- Повествование: тот же бросок без форсирования — провал заменяется «успехом с ценой», состояние не добавляется, сложность не выше 1 + локация.
- Рычаг раскрыт → `interact(рычаг)` без броска открывает дверь (`object_changed` на `cellar_door`); свёртка даёт `open`.

## S13. Свободное действие (пункт 08)
- Снимок: «Зал башни», персонаж Паладин (Ловкость 3) без подходящего объекта.
- Заявка: «перепрыгиваю ров с разбега, чтобы попасть к башне». Интерпретатор: `interact`, цель пустая, Ловкость, риск `hard`, `on_success` факт «ров преодолён, тропа к башне», `on_fail` состояние «ранен», `push` нет.
- Ожидание: сложность 2 + локация; при успехе `check_rolled` + `fact_learned` (private), при провале `check_rolled` + `condition_added`; объекты локации не меняются; хроника описывает исход.

Остальные сценарии (S01–S05, S08, S09) заполняются по этому образцу перед пунктом 12.

## S14. Разделение группы
- Снимок: группа «Ночной дозор» (Вор, Кузнец, Паладин) на «площади», выходы «коридор» и «рынок»; `max_parties` = 3.
- Заявки: Вор и Кузнец `move(коридор)`, Паладин `move(рынок)`.
- Ожидание при 2 активных группах: оба перемещения `resolved`; событие `party_split`: Паладин в новой группе (имя предлагает рассказчик, код проверяет уникальность); хроника объясняет расставание.
- Ожидание при 3 активных группах: движок меняет исход так, чтобы группа осталась вместе — перемещение меньшинства (Паладин) `resolved` с исходом «остался с группой», группа целиком в «коридоре»; событие `party_held` с причиной `party_limit`; хроника объясняет сюжетом, лимит игроку не называется; уведомление о заявке Паладину указывает, что группа не разделилась.
- Видимость: `party_split` и `party_held` — location.
