# Эталонные сценарии

Каждый сценарий: снимок, заявки, ожидаемые статусы и события, что видит каждый. Источник: риски §8–9. ID сценария = имя теста движка.

| ID | Проверяет | Статус |
|---|---|---|
| S01 | Один предмет, два претендента: предмет не дублируется, единственная запись результата | черновик |
| S02 | Помощь и совместная атака: общий расчёт зависимой группы | черновик |
| S03 | Встречные действия: открыть дверь и забаррикадировать её | черновик |
| S04 | Секрет: приватная находка не попадает в хронику и чужие приватные итоги | черновик |
| S05 | Устаревшая заявка: цель ушла из локации до разрешения | черновик |
| S06 | Повтор раунда: воспроизведение по снимку и seed даёт те же события | черновик |
| S07 | Никто не потерян: 5 заявок, 5 статусов, 5 приватных итогов | черновик |
| S08 | Неоднозначный текст → `ambiguous`, безопасное толкование после дедлайна | черновик |
| S09 | Совместное действие: сильный и слабый взломщики у одной двери; слабый ухудшает шанс, но не ниже своего | черновик |

## S01. Один предмет
- Снимок: локация «казначейство», предмет `ключ казначея` (1 шт.), персонажи Вор (Ловкость +3) и Паладин (Ловкость 0) в локации.
- Заявки: Вор `explore(ключ)`, Паладин `explore(ключ)`.
- Ожидание: конфликтная группа по предмету; встречная проверка Ловкости; победитель получает предмет (событие `item_taken`, private победителю + location «кто-то взял ключ» при провале скрытности); проигравший `resolved` с исходом «предмета уже нет». Инвентарь: ключ ровно у одного.
- Видимость: оба видят факт «ключ забрали»; кто — только победитель, если не было свидетелей.

## S09. Совместный взлом
- Снимок: локация «подвал» (сложность 1), объект `дверь` с подходом «отпереть» (Ловкость / воровство, сложность 1 → итого 2), персонажи Вор (пул 6) и Кузнец (пул 2) в локации.
- Заявки: Вор `interact(дверь, отпереть)`, Кузнец `interact(дверь, отпереть)`.
- Ожидание: одна конфликтная группа «совместное действие»; ведущий Вор; вклад Кузнеца по порогам D1/D2 (разница 4 → предположительно −1); итоговый пул max(6 − 1, 2) = 5; одна проверка против 2; событие `door_opened` или провал для обоих; оба получают `resolved` с одинаковым исходом и указанием ведущего.
- Вариант: пулы 6 и 5 → вклад +1, итоговый пул 7: совместная работа выгодна.
- Видимость: location.

Остальные сценарии заполняются при этапе 0 по этому образцу.
