# Типы игр

Тип выбирается при создании игры (`games.kind`) и не меняется. Все типы: одна игра привязана к одному чату; у игрока ровно один персонаж в игре (ADR-0007). Разница — в границах жизни игры, сбросах истории и судьбе прокачки персонажа.

| `kind` | Тип | Жизнь игры | История | Прокачка персонажа |
|---|---|---|---|---|
| `global` | глобальная игра | без конца; завершается только вручную владельцем чата | пишется непрерывно, регулярных сбросов нет | сохраняется постоянно, пока жива игра |
| `story` | рассказ | одна большая партия; границы задаёт администратор: дата окончания, число раундов или `/game_finish` | одна линия от старта до финала | сохраняется только внутри этой игры; после `finished` персонаж остаётся в архиве |
| `serial` | сериал | без конца, как глобальная | делится на сезоны: `/season_new` закрывает текущий сезон и открывает новый стартовой сценой | сохраняется между сезонами |

## Сезон (сериал)

- Таблица `seasons`: номер, название, статус, даты; у раунда ссылка на сезон (у остальных типов — единственный сезон 1, создаётся автоматически, чтобы запросы были едиными).
- Смена сезона (допущение, вопрос G12): персонаж сохраняет характеристики, навыки, опыт и инвентарь; HP восстанавливается, состояния снимаются; локации сезона закрываются, новый сезон получает стартовую сцену; контекст LLM начинается с краткой сводки прошлого сезона.
- Хроника прошлых сезонов доступна через `/journal`, в контекст LLM целиком не попадает.

## Границы рассказа

`settings.ends_at` (дата), `settings.max_rounds` (число раундов) или ручное `/game_finish`; при достижении границы планировщик не открывает новый раунд, а рассказчик публикует финальную хронику. Игра переходит в `finished`; после этого в чате можно создать новую.

## Открыто

Что именно сбрасывается при смене сезона (G12). Нужна ли «новая игра с тем же персонажем» для рассказа (перенос прокачки между рассказами) — пока нет.
