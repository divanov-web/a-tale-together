# Go: тесты

- Юнит-тесты обязательны для `internal/service/**` (движок, правила, видимость, сборка контекста) и для разбора и валидации JSON от LLM. Адаптеры: интеграционные тесты с `//go:build integration`.
- Табличные тесты, `t.Run` с именами на английском; `t.Parallel()` при отсутствии общего состояния.
- Только `testing` из stdlib; сравнение структур `reflect.DeepEqual` или `go-cmp` (добавить при первой необходимости).
- Детерминизм: фиксированный seed, инъекция `Clock`; `time.Sleep` запрещён.
- Эталонные сценарии `docs/game/scenarios.md` реализуются тестами движка один к одному; имя теста содержит ID сценария (`TestScenario_S01_SameItem`).
- Интеграционные тесты Postgres: БД из `DATABASE_URL_TEST`; каждый тест в транзакции с откатом; миграции применяются перед прогоном.
- LLM в тестах не вызывается: фейк-адаптер с записанными ответами из `testdata/`.
- Запуск: `make test` (юнит), `make test-integration`.
