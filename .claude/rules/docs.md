# Документация

- Язык русский; термины по глоссариям: игровые в `docs/game/glossary.md`, технические в `docs/glossary.md`; термин из двух файлов добавляется в глоссарий. Неудачный термин руководителя Claude заменяет на общепринятый везде и фиксирует замену в колонке «Было» и в отчёте.
- Строгий Markdown: заголовки и краткие тезисы, таблицы вместо абзацев, без вводных слов. Один файл — одна тема.
- Относительные ссылки `[Название](путь.md)`; индекс `docs/README.md` обновляется при добавлении файла.
- Readme пакета (`readme.md` строчными): назначение, зависимости, публичный вход, связи. Обновляется в той же задаче, что и код; это место для фактов реализации, которых нет в правилах `.claude/rules`.
- ADR в `docs/decisions/NNNN-<тема>.md` по `_template.md`; статусы `предложено | принято | заменено`. Принятое решение не правится задним числом: новый ADR со ссылкой на старый.
- `docs/concept/` не источник правды: источник — `docs/` и код. В концепт смотрят только за нереализованными механиками; реализованная механика адаптируется, переносится в профильный документ и удаляется из концепта. Номера разделов концепта не цитируются; расхождения — в `docs/game/open-questions.md`.
- Планы `docs/plan/`: `README.md` — индекс; у плана файл `<план>.md` с таблицей пунктов и подпапка `<план>/` с файлами пунктов по `_template.md` (бот `telegram`, изображения `images` с префиксом `i-`, сайт `website` с `w-`); шаги и статусы правятся по ходу работы, новый пункт — строка в таблице + файл.
- Устаревшее удаляется, не помечается; история в git.
