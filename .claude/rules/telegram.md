# Telegram

- Библиотека `github.com/go-telegram/bot` (ADR-0004). Long polling в разработке; webhook позже.
- Каждый update сначала дедуплицируется по `update_id`, затем обрабатывается.
- Бот не пишет пользователю первым: приватный канал появляется после `/start` или deep link; без него игрок к игре не допускается.
- Контекст команды: групповой чат → `game_id` по `chat_id`; приватный чат → активная игра пользователя, при нескольких явный выбор.
- Все исходящие через `messages_outbox`: запись в транзакции, отправка воркером, хранение `message_id`, повтор при неопределённом исходе без дублей.
- Длинные тексты делятся по лимиту Telegram; название мира и номер раунда в каждом игровом сообщении.
- Лимит частоты и длины входящих: спам не доходит до LLM.
- Команды MVP: группа `/game_create /game_start /game_pause /game_status`; личка `/join /character /act /journal /games`. Реестр `docs/architecture/telegram-commands.md` обновляется вместе с кодом.
- Обработчики в `internal/app/bot` тонкие: разбор команды → сценарий → ответ; игровой логики нет.
