# Руководство игрока

- `guide/` — материалы для игроков и ведущих игры со стороны пользователя; источник правды по поведению остаётся код и `docs/`, руководство его пересказывает.
- Язык русский, обращение на «вы», термины игрового глоссария (`docs/game/glossary.md`) без технических: никаких номеров пунктов плана, названий пакетов, таблиц БД, ADR.
- Наглядность: путь пользователя шагами, таблицы «хочу → пишу», примеры команд целиком с аргументами; короткие абзацы, без вводных слов.
- Один файл — одна тема; индекс `guide/README.md` обновляется при добавлении файла.
- Новая или изменённая команда в `internal/app/bot/router.go` — в тот же день строка в `guide/commands.md`; планируемые команды — в `docs/architecture/telegram-commands.md`.
- Служебные и dev-команды описываются кратко в конце, без подробностей настройки.
