# Система промптов Claude Code

- Иерархия: `CLAUDE.md` (импорт главного скилла) → `.claude/skills/tale-*/SKILL.md` (процессы и роли, по описанию или `/имя`) → `.claude/rules/*.md` (области решений, по `paths`). Нижний уровень не ссылается на верхний.
- Правило = область решений, привязанная к файлам: `paths` обязателен. Скилл = процесс или роль.
- Текст для ИИ: короткие императивы, таблицы, точные имена файлов и команд, без повторов и вводных. Каждое утверждение проверяемо.
- Лимиты: SKILL.md до 150 строк, правило до 60 строк; справочники в `references/` рядом со SKILL.md, подключаются ссылкой из текста.
- `description` скилла: что делает + ключевые слова запроса, когда подключать; вместе с `when_to_use` до 1 500 символов.
- Добавление, переименование, удаление файла → обновить карту в `.claude/skills/tale-team/SKILL.md` и `docs/README.md`.
- Противоречия недопустимы: при правке файла перечитать главный скилл и соседние правила.
- Субагенты `.claude/agents/` не создаются до отдельного ADR.
- Домашняя ИИ-команда `~/projects/ai-team` здесь не используется; `/ai-dev*` не вызывать.
