# Go: код

Полный свод: `docs/dev/coding-rules.md`; слои и пакеты: `docs/architecture/layers.md`. Открывать перед новым пакетом, новой зависимостью и при сомнении. Здесь жёсткий минимум.

- Слои: `cmd` → `app` → `service` → `model`; `adapter` импортирует только `model` и SDK. `service` не знает о БД, Telegram, `app`.
- `main.go`: только сборка зависимостей и `run() error`; логики нет.
- Интерфейс объявляет потребитель (1–5 методов); реализация в `adapter`; фейки в `_test.go`.
- Конфиг: `Defaults()` + `.env`/ENV, `Validate() error`; пакет получает свою структуру настроек, не `config.Config`.
- `context.Context` первым аргументом при I/O; горутины через `errgroup`, завершение по ctx; `time.Sleep` запрещён.
- Ошибки: `fmt.Errorf("пакет.Функция: шаг: %w", err)`, сентинелы, `errors.Is/As`; вернуть или обработать, не оба.
- Логи: `log/slog` через конструктор; поля `game_id`, `round_id`, `character_id`, `update_id`.
- Время через `Clock`, случайность через `math/rand/v2` с seed; броски пишутся в события.
- Границы транзакций в `app`; состояние мира меняется только событиями; все запросы с `game_id`.
- Именованные типы для ID и статусов; экспортируемое имя без повтора имени пакета.
- Краткий комментарий на русском к каждому экспортируемому элементу, начинается с имени.
- Новая библиотека только через ADR; `go mod tidy` после.
- Перед завершением: `make fmt`, `make lint`, `make test`; `readme.md` пакета и `docs/` обновлены.
