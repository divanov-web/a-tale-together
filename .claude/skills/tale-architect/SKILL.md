# Архитектор

## Источники

- `docs/architecture/`: `layers.md` (слои, пакеты MVP, интерфейсы, транзакции), `overview.md`, `project-layout.md`, `data-model.md`, `round-pipeline.md`, `telegram-commands.md`.
- `docs/dev/coding-rules.md`: стартовые правила программирования.
- `docs/decisions/`: принятые ADR; `_template.md`.
- [Обзор архитектуры](../../../docs/architecture/overview.md) — источник правды; риски §5, §7 (`docs/concept/`, не источник правды) — гипотезы для нереализованного: изоляция миров, идемпотентность, атомарность, приватность, наблюдаемость, бюджет.

## Принцип достаточности

Слои и пакеты существуют ровно под требования текущего этапа roadmap (`docs/architecture/layers.md`, раздел «Что сознательно не вводим»). Новый пакет — при втором потребителе или когда существующий перерос ~500 строк; новый слой, библиотека, инфраструктурный компонент — только через ADR с ответом «какое требование этапа этого требует».

## Процесс решения

1. Вопрос и ограничения: требование концепта, этап roadmap, стоимость, тестируемость.
2. Два-три варианта кратко; выбор по критериям: простота MVP, тестируемость, принципы продукта.
3. ADR по `docs/decisions/_template.md`, статус «принято», строка в `docs/decisions/README.md`.
4. Обновить документы архитектуры; при новой области кода — правило в `.claude/rules/` и карта в главном скилле.
5. Реализация или постановка задачи разработки.

## Правила проектирования

- Слои по `layers.md`: `cmd` → `app` → `service` → `model`; `adapter` реализует интерфейсы потребителей и импортирует только `model`.
- Интерфейс объявляет потребитель; реализация в adapter; фейк рядом с тестами потребителя.
- Состояние мира меняется только событиями; снимок раунда + журнал событий; воспроизведение раунда без LLM.
- Новая сущность: модель в `internal/model`, таблица с `game_id`, репозиторий в `internal/adapter/postgres`, миграция, строка в `data-model.md`.
- Новый внешний сервис: адаптер + фейк + учёт стоимости и ошибок.
- Без брокеров, кэшей и микросервисов в MVP: Postgres как очередь (outbox, `SKIP LOCKED`).
- Отступление от концепта — не решение Claude: вопрос в `docs/game/open-questions.md`, работа по безопасному допущению.
