# Геймдизайнер

## Источники

- Концепт §4, §5, §7, §14 и риски §1–3, §6, §9 (`docs/concept/`): требования, гипотезы, открытые вопросы.
- `docs/game/`: `rules.md` (индекс правил), `character.md` (персонаж), `checks.md` (испытания), `game-modes.md`, `game-formats.md`, `actions.md` (каталог), `round.md` (цикл раунда), `scenarios.md` (эталоны), `open-questions.md` (вопросы руководителю).

## Границы решений

- Решает Claude в рамках концепта: механики, числа, каталог действий, порядок разрешения, формат ответов игроку. Фиксирует в `docs/game/`.
- Решает руководитель: игровой опыт (PvP, смерть, жанр, темп, объём текста игроку), всё из §14 концепта. Claude предлагает вариант с рекомендацией в `open-questions.md` и работает по безопасному допущению.
- Правило принято только с эталонным сценарием, разрешимым на бумаге без произвольных решений.

## Процесс

1. Проблема → найти в рисках концепта; нет — записать в `open-questions.md` или решить здесь.
2. Правило: условие, проверка, исходы, события, видимость, цена для игрока.
3. Сценарий в `scenarios.md`: снимок состояния, заявки, ожидаемые статусы и события, что видит каждый адресат.
4. Обновить документ правил (`character.md`, `checks.md`, `actions.md`, …); поднять `rules_version` в `rules.md`.
5. В движок: тест по сценарию, затем код (`rules/engine.md`, `rules/go-tests.md`).

## Ориентир минимальной системы MVP

- Персонаж: имя, архетип, 4 характеристики (2–4), навыки (0–3), HP, состояния, инвентарь, локация.
- Сцена: предлагаемые подходы к объектам с открытой сложностью (данные объекта), свободное действие игрока получает сложность от таблицы правил по риску, не от LLM.
- Проверка (Year Zero Engine): пул d6 = характеристика + навык + предмет, успех — «6»; сложность = нужное число успехов + сложность локации; форсирование броска за состояние «истощён»; исходы: успех, успех с ценой (после форсирования), провал. Игроку показываются сложность и шанс. Превышение параметра не гарантирует успех.
- Действия: каталог универсальных типов (переместиться, исследовать, взаимодействовать, убедить, атаковать, помочь, скрытно, ждать); свободный текст сводится интерпретатором к каталогу.
- Раунд: снимок заявок по дедлайну; одна основная заявка на персонажа; конфликтные группы; фазы разрешения.
- Бездействие: продолжение занятия или ожидание; защитное автодействие.
